# Продолжение разработки Termux Job’s

Текущий релиз: v0.2.17, versionCode 1033, com.termux, прежняя подпись. APK и SHA-256 описаны в docs/fork/VALIDATION.md. Основная ветка fork/base, базовый Termux v0.118.3.

Добавлены SSH и интеграция Codex: среды Termux/Ubuntu, три режима доступа, новый чат/выбор/ID, карточка статуса/лимитов, модель → поведение → подтверждение. Черновики отдельные по TerminalSession.mHandle, только в памяти. Пользователь подтвердил работу v0.2.17.

Границы работы: AGENTS.md. Не изменять установленную среду и пользовательские процессы, не устанавливать APK без отдельной задачи. Локальные инструменты/ключ подписи остаются вне Git. Для следующих публикаций соблюдать docs/fork/RELEASING.md и актуализировать README/руководство/проверки.

Будущие проверки: другие версии CLI, устройства и чистые установки; неизвестные меню модели требуют ручного выбора. Android/proot не гарантируют sandbox. Профиль Bash не сохраняет живой процесс, историю Codex хранит сам Codex.
