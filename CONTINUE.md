# Termux Job’s v1.0

Текущая версия: v1.0, versionName 1.0.0 / versionCode 1037, пакет com.termux, прежний сертификат, ARM64 и Android 7+, формат библиотеки v8. Публикация GitHub разрешена пользователем после передачи APK. Исходники выпуска связаны с тегом v1.0; документация и проверки: docs/fork/RELEASE-v1.0.md и docs/fork/VALIDATION-v1.0.md.

После v0.2.17 добавлены проектные папки/файлы, базовый Terminal, стопка сессий, выбор всех чатов Codex с подтверждением другого каталога, исправления иконок/фильтров и RU/EN/System. Язык меняется глобусом рядом с шестерёнкой; верхние плитки того же размера, только центрированные векторы. Пользовательские данные и вывод программ не переводятся. Terminal закрывается только вместе с приложением; ограничения Android и лимит восемь терминалов сохраняются.

APK проверен: 228 unit tests, localization checker, release/lintVital, ZIP, пакет/ABI/версия, прежний сертификат и SHA-256. Агент не устанавливал приложение и не изменял работающие пользовательские сессии. Подробный протокол устройства не предоставлен; DPI/клавиатура/полный lifecycle требуют проверки на телефоне.

Следующие изменения не публиковать и не устанавливать без авторизации в текущей задаче. При следующем релизе обновить README, changelog, release notes, validation, usage/compatibility и прочую затронутую документацию по docs/fork/RELEASING.md. Не помещать личные данные, ключи, токены, локальные инструменты или Desktop Alpha в репозиторий/артефакты.
