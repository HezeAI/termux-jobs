# Продолжение разработки Termux Job’s

Актуально на 13 октября 2026 года. Основной проект `/root/termux-fork`, ветка `fork/base`, репозиторий [HezeAI/termux-jobs](https://github.com/HezeAI/termux-jobs). Основа — Termux v0.118.3.

## Текущий выпуск

v0.2.6, пакет `com.termux`, versionCode 1022, ARM64, Android 7+. Пользователь разрешил публикацию именно этого APK и исходников с обновлением MD. Сертификат прежний. APK в `/sdcard/Download/Termux-Jobs-v0.2.6-arm64.apk`. Проверено 176 тестов и lintVitalRelease. Релиз опубликован и проверен: Latest, draft=false, prerelease=false. Серверные SHA-256 assets совпадают с локальными, скачанный SHA256SUMS совпадает побайтно. Последующие релизы требуют отдельной задачи пользователя.

Все локальные изменения v0.2.2–v0.2.6 включены в выпуск: явное сохранение обычных сессий, очистка несохранённых профилей после выхода, заметки и формат v5, общий поиск и две панели библиотеки, единый стиль окон, журнал 50 с повторами, адаптивная высота панелей, команды/заметки в звёздочке, отсутствие троеточий журнала. Адаптацию пользователь подтвердил на Samsung; полная проверка всех моделей не выполнена.

## Границы дальнейшей работы

Читать AGENTS.md. Не устанавливать APK, не менять работающие терминалы, установленный Termux или окружение без отдельной инструкции. Инструменты/сборки изолировать в репозитории; APK копировать в Download. Ключ подписи локален, исключён из Git и не должен меняться при обновлении. Перед каждой публикацией обновлять README и затронутые документы.

Обычные сессии сохраняются явно. Вставка текста не отправляет его. Снимков вывода нет. Title не пересоздаёт страницы. Формат workspace-v1.json — v5 с чтением v1–v4; откат на старую версию может оставить библиотеку только для чтения. Перезапуск профиля не возобновляет живой процесс. История Codex отдельно в .codex.

Desktop Alpha и личный Job’s AI — отдельные эксперименты, не входят в основной релиз. Макет компактных уведомлений с переходом на фоновую вкладку показан пользователю, но внедрение отложено; код уведомлений не изменять по текущему запросу.
