# Ретро-макеты XFCE для Termux Job’s

Три PNG-концепта: Retro 98, Retro XP, Retro Dark. Встроенный image_gen,
отдельный вызов на каждый вариант; точные промпты — prompts.json.
Нижняя панель и её значки увеличены относительно предыдущего концепта.
Копии трёх PNG сохранены в /sdcard/Download с теми же именами.

Это макеты, не установленная тема. Код, APK, установленный XFCE и настройки
пользователя не изменены. Оболочка Android в макетах приблизительная;
предложение касается оформления вложенного рабочего стола. Достичь похожего
вида можно темами GTK/XFWM, ресурсами значков, фоном и настройкой панели.
Приложения с собственным оформлением могут выглядеть иначе.

PNG проверены по сигнатуре, CRC всех блоков и распаковке IDAT. Все три
результата визуально просмотрены. Размеры и SHA256 — outputs.json.
