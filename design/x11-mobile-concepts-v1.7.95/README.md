# Три идеи мобильного рабочего стола Termux Job’s

Это PNG-концепты для обсуждения. Код, APK, установленные окружения и текущая
Kali-inspired тема не изменены. Копии итоговых PNG — в /sdcard/Download.
Генератор — встроенный image_gen, отдельный вызов на каждый вариант.
Точные промпты — prompts.json; размеры/хеши итоговых файлов — outputs.json.

1. Native Mint: развитие языка приложения — графит, мятные контуры,
   спокойный фон и крупная нижняя панель. Ближе к обычному оформлению XFCE;
   карточки/детали проводника в концепте не считаются готовым кодом GTK.
2. Touch Workspace: крупные карточки и панели для пальцев. Это предложение
   отдельной мобильной оболочки/экранов, не просто новый цвет окон XFCE.
3. Aurora Glass: пейзаж, полупрозрачные поверхности и мягкие эффекты.
   Реализацию и стоимость прозрачности/размытия нужно исследовать отдельно.

Все три результата необходимо оценивать как визуальные идеи, а не обещание
точного воспроизведения всех компонентов штатных Linux-приложений.
