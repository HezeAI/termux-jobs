# Три Linux-концепта для XFCE Termux Job’s

PNG: Ubuntu-inspired (светлый/фиолетовый/оранжевый), Kali-inspired
(тёмный/синий/дракон), Parrot-inspired (тёмный/бирюзовый/птица).
Это оригинальные стилизации для сравнения, не точные скриншоты дистрибутивов
и не рейтинг популярности. Большие значки и Menu со знаком >_ сохранены.

Использован встроенный image_gen, отдельный вызов на вариант. Точные промпты
в prompts.json; результаты проверены по PNG/CRC/IDAT и визуально просмотрены.
Копии трёх PNG — /sdcard/Download с теми же именами. SHA256 — outputs.json.
Код приложения, APK, установленный стол и активная тема Retro XP не менялись.
Возможное воплощение потребует собственной темы GTK/XFWM/значков/панелей.

Официальные ориентиры, просмотренные 2026-10-23:

- [Ubuntu Desktop](https://ubuntu.com/download).
- [Назначение Kali](https://www.kali.org/docs/introduction/what-is-kali-linux/)
  и [XFCE](https://www.kali.org/docs/general-use/xfce-faq/).
- [Окружения Parrot](https://parrotsec.org/docs/configuration/desktop-environments/).
  В актуальной документации default — KDE; этот концепт адаптирован для XFCE
  и не изображает default-интерфейс Parrot.
