# Termux Job’s

**Termux с удобным интерфейсом, библиотекой команд и заметок, пресетами запуска и AI Agents.**

Неофициальный форк [Termux](https://github.com/termux/termux-app), созданный HezeAI.
Основан на Termux v0.118.3. Текущий выпуск — **v1.0.18**, Android 7+, ARM64.

## Главное в v1.0.18

С предыдущего публичного v1.0.4 добавлены **AI Agents: Codex, OpenCode, Claude Code
и Gemini CLI**, диагностика сессий и обновлённые элементы управления терминалом.
**Интеграции AI Agents экспериментальные:** наличие агента в меню не означает,
что все способы авторизации, модели и восстановление истории проверены на телефоне.
Статус каждого агента указан ниже; известные проблемы не скрыты.

- **AI Agents:** выбор агента, проекта, нового чата или истории/ID там, где это
  поддерживает CLI. Компоненты OpenCode/Claude/Gemini проверяются при создании и
  запуске сессии, устанавливаются в отдельные каталоги выбранной Ubuntu.
- **Диагностика:** долгий тап по названию сессии → «Диагностика сессии».
  Автоматический базовый сбор, расширенная опция в создании сессий/пресетов,
  пауза/продолжение, копирование пути отчёта и экспорт `.txt` в Download.
- **Управление:** общая шестерёнка на всех вкладках содержит язык и настройки.
  Только в терминале — векторные кнопки интерактивного ввода и дополнительных
  клавиш, с подсветкой включённого режима.
- **Запуск:** «Сохранённые сессии» переименованы в **«Пресеты запуска»**.
  Кнопка отмены следующих шагов внутри плашки текущей сессии показывает команды
  и запрашивает «Да/Нет»; текущая команда продолжает работу. Поддерживаются
  пользовательские последовательности Termux/Ubuntu, не SSH/автоматический запуск AI.

## Чем отличается от набора скриптов в обычном Termux

Скрипты остаются полезны: этот форк добавляет управление ими в приложении.
Сохранённую команду можно найти по имени/категории, посмотреть и вставить в нужный
терминал, не запуская новую вкладку. Пресет связывает папку, среду и последовательность
запуска. Проектные файлы, редактор, пакеты, состояние Codex и диагностика доступны
рядом с терминалом. Ввод и терминал работают на исходном движке Termux.

Если хватает обычного Termux и своих скриптов, переход не обязателен. Цель форка —
сократить действия на телефоне при работе с несколькими проектами и агентами.

## Возможности

- Верхние вкладки «Главная», «Команды/Заметки», «Терминал», русский и английский UI.
- Главная: независимые прокручиваемые панели последних 50 отправленных команд и
  пресетов. Повторы сохраняются отдельно; журнал можно очистить с подтверждением.
- Команды/заметки: общий поиск, отдельные списки, избранное и категории; выбор
  существующей категории или ввод новой при создании и редактировании.
- Звёздочка у поля ввода: команды и заметки с поиском, вставка в текущую вкладку.
  Поле многострочное, Enter переносит строку; черновики независимы для терминалов.
- Несколько терминалов, список сессий, рабочие каталоги, до трёх шагов запуска.
  Базовая Terminal не закрывается. Сохранение пресета — явное действие.
- Проекты и файлы Termux/Ubuntu: навигация, просмотр, передача файлов и редактор
  UTF-8/Markdown до256КБ с проверкой внешних изменений перед сохранением.
- Пакеты Termux/Ubuntu: поиск, описание, установленные/обновления/доступные версии,
  выбор версии и подтверждение операции в свободной оболочке или новой вкладке.
  Установленные пакеты остаются в окружении после закрытия вкладки.
- SSH-сессии: сервер, порт, каталог, ключ или пароль; опциональный пароль защищён
  Android Keystore. Команды запуска выполняются на сервере.

## AI Agents: что проверено и что осталось

| Агент | Окружение | Возможности и границы проверки |
| --- | --- | --- |
| Codex | Termux / Ubuntu | Прежняя интеграция: история/ID, проект, штатные права, модель/поведение/лимиты. Вход и история относятся к выбранной среде. |
| OpenCode | Ubuntu | Подключения аккаунтов/провайдеров, build/plan, режимы доступа, история. Пользователь подтвердил смену модели через переоткрытие с тем же чатом. Мерцание/рывки при resize и переключении **не считаются исправленными**. |
| Claude Code | Ubuntu | Отдельный официальный runtime, модель/режим, новый чат/выбор/ID. Версия/help и изолированные проверки пройдены; реальный вход, ответы и вся история не проверены полностью. |
| Gemini CLI | Ubuntu | Отдельные компоненты, API/Google/native выбор, модель/режим, история. Google отключил личный OAuth для Gemini CLI; API-key интерфейс открыт пользователем, успешный ответ и квота не подтверждены. |

**Google-вход Gemini:** официальный личный вход отключён с18июня2026, включая
Free/Pro/Ultra. Перенос файла auth в приватный каталог исправляет локальный отказ
читать настройки, но не отменяет ограничение Google. См.
[официальное объявление](https://github.com/google-gemini/gemini-cli/discussions/28017).
API-ключ и организационные способы доступа имеют отдельные условия.
Antigravity исследован, **в приложение не включён**.

Для OpenCode/Claude/Gemini нужна уже установленная Ubuntu через proot-distro;
автоматическая подготовка агента не устанавливает сам дистрибутив. Авторизация
выполняется пользователем штатным способом. Аккаунты, подписки и бесплатные квоты
не входят в APK. Полный доступ агента не предоставляет Android root.

## Что содержит диагностика

Журнал собирается и при закрытом окне: запуск, выход процесса, события и
наблюдаемые категории/коды ошибок. Расширенный режим добавляет активность вывода,
у Gemini также включает штатный `--debug` до запуска. Внутренние HTTP-трассы
других агентов не подключены. Упоминание ошибки в терминале может быть цитатой,
поэтому диагностический сигнал не доказывает сбой конкретного API-запроса.

Отчёт не записывает ввод, полный диалог/вывод, команды пользователя, переменные
окружения, URL, ключи или токены. Лимиты:2МиБ на профиль,32МиБ суммарно;
старые записи вытесняются. Журнал в памяти не переживает завершение app-процесса,
явно сохранённые отчёты остаются. Остановка коллектора не останавливает терминал
и не выключает уже запущенный native debug Gemini.

## Установка и обновление

1. Скачайте `Termux-Jobs-v1.0.18-arm64.apk` из [релиза](https://github.com/HezeAI/termux-jobs/releases/tag/v1.0.18).
2. Проверьте SHA-256 по `SHA256SUMS`. Разрешите установку из выбранного источника.
3. Для обновления прежних Termux Job’s с тем же сертификатом установите APK поверх.
   Удалять приложение не требуется. Формат библиотеки остаётсяv8; новые поля
   опциональны. Сохраните резервную копию среды перед сменой источника установки.

Пакет **`com.termux`**: рядом с другим приложением с этим пакетом установить нельзя.
APK с другой подписью поверх не обновится. Специальный резервный APK code1100
старше по versionCode, чем этот code1055; его нельзя понизить обычным обновлением.
Подробности: [подпись и совместимость](FORK.md).
