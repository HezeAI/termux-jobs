# Termux Job’s v1.1.0

## Главное — бета-тест резервного копирования

**Шестерёнка справа сверху → «Резервное копирование · бета».**
Теперь можно создать свой бэкап и проверить/импортировать распознаваемый бэкап
обычного Termux или совместимого форка. Это **бета**, а не универсальный перенос1:1.

- Выбор библиотек и настроек, HOME, PREFIX и установленных Ubuntu/proot.
  Новые архивы, SHA-256, проверка целостности, инструкция и restore.sh.
- Проверка чужого архива до применения: структура, безопасные пути/ссылки,
  архитектура, поддерживаемый формат и свободное место; выбор компонентов.
- Ubuntu восстанавливается отдельно под новым именем, с isolated пресетом запуска.
  HOME/PREFIX извлекаются в новую папку; работающая среда не заменяется.
- Команды, заметки и пресеты: выбор, объединение/замена, обработка дубликатов.
  Простые aliases и shell-скрипты можно выбрать для добавления в команды.
  Пресеты из бэкапа требуют проверки настроек перед первым запуском.
- Отдельный раздел пакетов: текущая и сохранённая версия, отсутствующие пакеты,
  выбор и предварительный план APT. Только после подтверждения — отдельный
  терминал для установки, где актуальный план APT надо подтвердить ещё раз.

Нужен Python в Termux, а для отдельного восстановления Ubuntu — современный
Python proot-distro и подтверждённая архитектура. Неизвестные форматы блокируются.
**Реальное полное восстановление на другом телефоне ещё не подтверждено.**
Испытывайте сначала на тестовой копии; не присылайте бэкапы в Issues — в них секреты.
[Подробный порядок и ограничения](BACKUP-RESTORE.md).

## Отдельно: обновление через приложение

**Шестерёнка → «Проверить обновления».** Показываются главные изменения и
совместимость, APK скачивается с прогрессом/отменой, проверяются размер/SHA-256/
пакет/версия/подпись, затем открывается системное подтверждение Android.

Автопроверка включается/выключается в шестерёнке: при открытии приложения, если
прошло10часов с последней попытки. Пока приложение закрыто, специально не
запускается. Без popup и скрытой загрузки APK — только точка на шестерёнке и
версия в меню. **Ручная проверка всегда остаётся.**

Локальная v1.0.19 уже умеет получить этот релиз через приложение. Для более старых
версий первый APK с updater нужно установить вручную. Релиз включает update.json
для встроенного обновления; дальнейшие релизы сохраняют этот механизм.
[Как работает updater](UPDATES.md).

## Другие изменения после публичной v1.0.18

- Убран дублирующий пункт аккаунтов/API OpenCode из общих настроек; подключения
  доступны в создании/настройках сессий и пресетов.
- Стандартный лог приложения — «Выключено (default)»: прежний NORMAL однократно
  меняется на OFF. DEBUG/VERBOSE и дальнейший ручной выбор сохраняются.
  Собственный журнал сессий работает независимо.

## Совместимость и данные — до установки

**Очистка команд, заметок, пресетов и истории не требуется.** Пакет com.termux,
прежний сертификат, библиотекаv8, версия1.1.0/code1057, Android7+/ARM64.
Обычное обновление поверх сохраняет данные. Не удаляйте приложение для обновления.
Перед установкой завершите важные задачи: Android может остановить процессы.
Специальная резервная сборка code1100 выше этого кода и обычного downgrade не допускает.

Ограничения **восстановления на чистой установке**: Android Keystore/разрешения и
живые процессы не переносятся, сохранённые SSH-пароли надо ввести заново; внешние
цели ссылок не архивируются. Live-базы не гарантированно согласованы. Это не
объявление потери авторизации при обычном обновлении APK. Мультикомпонентное
восстановление не является общей транзакцией; PREFIX не активируется автоматически.
Отдельная среда не исправляет несовместимую архитектуру. Понижение на старые версии
может потерять optional review-метку импортированных пресетов и не проверялось.

AI Agents остаются экспериментальными; мерцание OpenCode не объявлено исправленным.
[Проверки APK и тестов](VALIDATION-v1.1.0.md). Реальный upgrade v1.0.19→v1.1.0
через системный установщик и real-device restore предстоит проверить пользователю;
агент установку/восстановление на работающем телефоне не запускал.

## English highlights

Main feature: **beta backup creation and import of compatible Termux/fork backups**,
available from the top-right gear. Inspect before restoring, select components,
stage HOME/PREFIX separately, restore Ubuntu under a fresh isolated launch preset,
select libraries/aliases/scripts and compare Termux package versions with an APT
preview before confirmation. Not a universal1:1 migration; real-device restore is
not yet validated. [Backup guide](BACKUP-RESTORE.md).

**In-app updates are now available:** manual check, localized highlights and
compatibility, verified download and Android confirmation. Optional checks on app
open at least10hours apart, gear badge, no automatic APK download. v1.0.19 users
can update through the app; older versions need one manual update first.

No clearing of commands, notes, presets or history is required. Package/signing
identity and libraryv8 retained. Finish important jobs before installation; do
not uninstall. Backup limitations include unportable Android Keystore/passwords,
live processes, external link targets and database consistency. AI Agent and
OpenCode limitations remain. Tests/build verification do not replace device tests.
