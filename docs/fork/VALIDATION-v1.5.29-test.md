# v1.5.29-test — Gemini sign-in choices

Private update to1.5.28-test/code1186. New code1187, com.termux,
Android8+/API26, ARM64; same certificate. No data reset, schema remains8.
Google sign-in is visible but dimmed/disabled in both session and preset editors,
with a localized explanation of the current CLI's individual-account rejection.
Disabled selection is guarded both by adapter and listener. New profiles default
to Gemini API key. Existing Google/auto/API settings are preserved, not migrated
or logged out. The native terminal menu remains upstream-owned.

The former Choose in terminal choice is replaced with Vertex AI · Google Cloud.
Legacy auto profiles retain their behavior and show an explanation in the editor;
their auth value does not change until the user chooses another method.
Vertex reveals cloud project/location fields, separately from working directory.
Empty values inherit environment; default location is global. Input validates IDs,
locations, paths, newline/control syntax, then quotes values in the own session
command. Editing the connection fields of a running session is blocked, as with
other connection edits. Preset copy/reload preserves the new metadata and history.

The private per-run native policy enforces vertex-ai; no Gemini key fallback.
Cloud project/location override only that child's environment; caller environment
and other agents are unchanged. ADC/service-account credentials or a Vertex
Express GOOGLE_API_KEY must already be configured in Ubuntu. The application
neither installs gcloud nor creates a Cloud project/billing setup. No keys are
entered into the metadata fields or saved by this feature. Existing external
system policy refusal, private0600 policy and cleanup are retained.

## Compatibility

Forward updates retain current sessions/history/presets. This feature does not
modify running sessions, installed Termux/Ubuntu/auth files, server, shared SDK,
other agent adapters or existing APKs. New vertex auth values may not be understood
by older builds: before a deliberate downgrade, switch Vertex profiles back to
API using this version and back up the library. Old auto/Google values remain
valid on forward load. No automatic clearing/reset is implemented.
