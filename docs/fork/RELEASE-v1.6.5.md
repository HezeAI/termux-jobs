# v1.6.5 fix — чаты, фокус ввода и карточки

Исправления и улучшения относительно публичной **v1.6.0**.

- **Codex:** исправлена загрузка больших историй, из-за которой чат мог терять
  соединение при запуске. Устранено ложное состояние готовности после ошибки.
- **Ввод:** новые сообщения и обновления карточек больше не переводят фокус
  с поля ввода на текст чата. Исправление общее для Codex, OpenCode, Gemini и Claude.
- **Карточки:** компактная раскрываемая хронология действий, понятные статусы,
  названия инструментов и просмотр исходных подробностей. Русский и английский.
  Рассуждения и подтверждения сохраняют свои места в переписке.
- **Навыки:** отдельное обозначение при распознаваемом чтении SKILL.md или явном
  подключении навыка. Название инструмента само по себе не считается навыком;
  определяются не все способы загрузки инструкций.
- **OpenCode:** проверка компонентов учитывает те же отдельные каталоги CLI и
  Node.js, что запуск, включая прежнее npm-расположение. Исправлено ложное
  сообщение о недостающем CLI для такой установки; реальное отсутствие или
  неподходящая версия по-прежнему требуют подготовки.

Разработчик подтвердил исправление ввода, карточки других агентов и повторную
проверку компонентов OpenCode на промежуточных сборках. Это не проверка всех
устройств, аккаунтов и сценариев. Штатное терминальное окно Codex ещё может
показывать старый текст проверки компонентов и служебные символы при прокрутке;
этот отдельный дефект отложен. Работа чата не требует захода в терминал при запуске.
Полный цикл Claude/Vertex с реальными аккаунтами не заявляется проверенным.

## Обновление и данные

Обновление доступно через **Настройки → Проверить обновление**; update.json
совместим с обновлятором v1.0.19. Можно установить APK вручную поверх прежней версии.

- С v1.6.0 и промежуточных1.6.x **сброс не нужен**: форматы команд, заметок,
  пресетов, серверов, истории и авторизации не меняются. Миграций и очистки нет.
- Прежние com.termux/сертификат, Android8+/ARM64. versionName1.6.5/code1198 выше
  публичной1.6.0/code1192 и частной1.6.5-test/code1197. Права агентов не меняются.
- Завершите важные задачи перед обновлением. Обновлённые помощники применяются
  при следующем запуске сессии; выберите ту же историю. Сохранение работающих
  процессов обновление не гарантирует.
- При обновлении с версий до1.5.3 сохраняется прежнее удаление приватных данных
  удалённой функции локальных ИИ; внешние модели/proot-дистрибутивы не удаляются.
  Сохраните нужные локальные данные заранее.

**English:** fixes large Codex history startup, composer focus loss in all four
agent chats and OpenCode component search paths. Adds shared expandable action
cards and supported skill labels. Same package/signer, Android8+/ARM64, code1198;
no reset from1.6.0/private1.6.x. Reopen the same history after finishing important
tasks. Upgrades from before1.5.3 retain the previously documented removal of old
local-AI private data; export needed local data first. Native Codex terminal mouse
escape echo/stale startup text remains a known separate limitation.
