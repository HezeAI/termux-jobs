### Согласованные непроверенные области и причина

Отдельного Android экземпляра без рабочих данных нет. По прямому поручению
разработчика сейчас **не выполняются** аварийное завершение приложения,
низкоуровневые Android handoff/recovery проверки и экспорт/восстановление
тестовых копий на устройстве. Это **Not checked**, не PASS и не отсутствие дефекта.
Рабочий com.termux нельзя использовать для force-stop: завершение затрагивает
все его сессии. Read-only проверка доступности ADB не нашла запущенного сервера;
сервер не запускался, приложения/сессии не останавливались, APK не устанавливался.
Стендовые broker/native export/restore результаты остаются отдельными.

Также не подтверждены на телефоне все старые профили/переключение чата при prompt,
общие No/Allow пути managed native TUI помимо принятого OpenCode directory gate,
старый профиль Codex непосредственно в Termux и ручной CLI. Их кодовые/стендовые
результаты сохранены без телефонного PASS. Настоящий Gemini API/Vertex вход
не проверен: рабочая авторизация не использовалась. Полные driver/network paths,
MCP и плагины не входят в текущий охват и остаются непроверенными.

## Условия завершения согласованного этапа

1. Доступные изолированные проверки и локальные исправления сохранены с доказательствами; нет известной критической регрессии, утечки или неподтверждённой безопасности остановки затронутых процессов.
2. Основные No/Allow и согласованные границы всех четырёх агентов приняты разработчиком на телефоне; источники не смешаны со стендом.
3. Непроверенные Android handoff/crash/backup и исключения явно сохранены; пропуск не считается успешной проверкой.
4. Следующий APK проверен как финальный файл и передан на приёмку новых изменений. Приёмка test8 получена; дальнейшая публикация разрешена по RELEASING.md.

Полные датированные проходы, исходные неудачи, команды и маркеры перенесены без потери доказательств в существующие документы выше.
Этот этап не закрывает накопление вложений, независимый аудит, полный трафик/драйверы, MCP или плагины.
