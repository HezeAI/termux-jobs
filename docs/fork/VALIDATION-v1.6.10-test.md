Регрессия1.6.9 подтверждена скриншотами разработчика: Alpine ошибочно определялся
как APT, apt-get update возвращал защитный отказ Termux. Read-only проверка
установленного Alpine обнаружила sbin/apk и отсутствие usr/bin/apt-get и
dpkg-query. В установленном коде proot login подтверждено добавление Termux bin
в конец PATH. Прежний probe считал такие хостовые команды гостевым менеджером.

Исправление ограничивает PATH стандартными каталогами Linux при определении
менеджера, чтении пакетов/описаний/версий и запуске подтверждённых операций
новых proot-окружений. Команда выполняется в subshell: PATH интерактивной оболочки
не изменяется. Маркер выбранного alias продолжает защищать от случайного запуска
после exit в хост. Обычные Termux/Ubuntu используют прежний APT-путь.

30 целевых JVM-тестов прошли без ошибок. Новый регрессионный тест создаёт
изолированные фиктивные гостевые менеджеры и хостовый APT: все пять nonAPT
менеджеров определяются правильно, операция вызывает гостевую команду, PATH
родительской оболочки сохраняется, отсутствующий менеджер даёт отказ без fallback.
Это тестовые скрипты, реальные менеджеры/окружения не запускались и не менялись.
Первый запуск тестов выявил несовместимый Files.writeString в тестовом коде;
заменено на Files.write, окончательный прогон успешен.

Сборка и DEX runtime прошли. ZIP, package/version, minSdk26, ARM64, отсутствие
debuggable, v2-подпись и прежний сертификат проверены. Assets и native побайтно
совпадают с1.6.9. Проверяемые приватные файлы и секретные маркеры отсутствуют;
это не исчерпывающий поиск всех возможных секретов. git diff --check проходит.

Ревью и инспекция: ограничение применяется к probe и всем новым пакетным путям,
проверены перенос команд в текущую/новую сессию, сохранение alias/isolation,
цитирование имён, отсутствие автоответа yes. Общий транспорт файлов и окружение
AI Agents не изменены; пользовательские процессы не останавливались.

Формат библиотеки8 не менялся, reset/удаление данных не предусмотрены. Package и
сертификат совпадают с1.6.9/code1205, код повышен. Повторный реальный тест Alpine
(вкладки, refresh, установка tree и tree --version) ещё требуется разработчику.
Закрыть и снова открыть панель пакетов для нового определения менеджера.
Debian update/install/tree --version уже подтверждены разработчиком на1.6.9.
Другие пакетные менеджеры и бэкапы не считаются проверенными на основании этого
исправления; восстановление Void без OCI остаётся отдельным открытым вопросом.
На GitHub не опубликовано.
