# v1.5.24-test

Приватное исправление полосы активности после проверки v1.5.23-test:
при прокрутке, смене вкладки/сессии и реальном изменении размеров краткая
перерисовка не запускает проблеск. Толщина линии уменьшена с3dp до1dp.
Окно фильтра1600мс не воспроизводит пропущенный вывод позднее; новые данные
после него снова учитываются. Доступный подтверждённый статус работы Codex
и локальная foreground-команда продолжают учитываться независимо.
Это эвристика: задержанный вывод перерисовки после окна всё ещё может
считаться активностью, а короткая работа внутри окна может не подсветиться.

Кружочки над вкладками удалены, исходные Toast заголовков других сессий возвращены.
Остальные функции1523 сохранены. com.termux, ARM64, Android8+, code1161,
прежний сертификат, schema8. Для перехода с1523 сброса/миграции данных нет.
При переходе с версии до1522 действует ранее описанное удаление приватных
локальных моделей/их историй, см. RELEASE-v1.5.22-test.md.
GitHub-публикация не выполняется. Проверки: VALIDATION-v1.5.24-test.md.

Карточки активной передачи сервера теперь включают полосу прогресса обеих направлений.
При неизвестном размере используется indeterminate; обновляются только собственные View.
