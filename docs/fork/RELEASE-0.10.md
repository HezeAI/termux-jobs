# Termux Fork 0.10

AMOLED-интерфейс Termux с библиотекой команд, несколькими терминалами и
сохранёнными сценариями запуска. Основан на Termux v0.118.3, лицензия GPLv3.

- Главная: журнал последних 25 отправленных команд и сохранённые сессии,
  с независимой прокруткой обоих списков.
- Библиотека: названия, категории, избранное, редактирование, копирование текста
  и вставка без автоматической отправки; выбор терминала назначения.
- Сессии: каталог, до трёх команд, выбор Termux/Ubuntu и готовность Bash;
  остановка цепочки при ошибке, отмена оставшихся шагов, закрытие с подтверждением.
- Многострочное поле ввода и переключаемый интерактивный режим клавиатуры.

Ubuntu и Codex не включены в APK. Для Ubuntu требуется существующая установка
proot-distro с контейнером `ubuntu`; остальные инструменты устанавливаются отдельно.
Сценарий не отправляет команды внутрь интерактивного Codex: следующие шаги ждут
его выхода. Старые профили сохраняют прежнее поведение до выбора новой среды.

ARM64, Android 7+, package com.termux, versionName 0.118.3-fork.10, versionCode 1005.
Совместим с обновлением прежних APK этого форка, подписанных тем же ключом.
Обычный Termux с другой подписью обновить этим APK нельзя. Перед заменой приложения
сохраните данные; APK не предназначен для параллельной установки с com.termux.
Хранилище v4 обратно несовместимо для записи с версиями форка 0.9 и ниже.

Проверка: 162 теста прошли; подпись v2 проверена; пользователь подтвердил работу
на своём телефоне. На других устройствах работа пока не проверена.
