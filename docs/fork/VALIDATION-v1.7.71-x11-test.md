# Частная v1.7.71-x11-test / code1286

## Итог изменений

- openSUSE Leap16.0 подключена к X11 в своём установленном rootfs: отдельный
  сервис OpenSuse / процесс :jobs_x11_opensuse / display103 / port8003 /
  каталог workspace-x11-opensuse. Общий механизм владельцев, запуска,
  переключения, отмены, закрытия последней сессии и диагностики сохранён.
- Базовый XFCE устанавливается Zypper --non-interactive install --no-recommends,
  сертификаты/клавиатура/звук/библиотеки Vulkan/EGL входят в его состав.
  Программы используют RPM для списка/точного удаления с проверкой зависимостей,
  Zypper XML search --no-refresh для каталога и явный refresh для обновления.
  Варианты Engrampa/MozillaFirefox ограничены openSUSE, Xarchiver других не меняется.
- GPU openSUSE использует приватную Debian Mesa26.3 и libsensors5 из Debian.
  Обе загрузки закреплены SHA256 и размерами. Системная Mesa не заменяется;
  дополнительные лицензии/источники указаны в Mesa-GPU-NOTICE. Для GPU включён
  прежний режим без композитора. Изменение рендера работающего стола запрещено.
- Firefox: lib64 и org.mozilla.firefox.desktop распознаются, старые journal
  остаются допустимы. Приняты только два точных набора ключей SHA, произвольные
  пути/ссылки не принимаются. Пользовательские ярлыки и правки сохраняются.
  Существующий MOZ_SHM_NO_SEALS не заменён отключением песочницы или GPU браузера.
- Fedora: базовый xfce4-about добавлен для меню над Logout. Временный XDG
  override Hidden=true для xfce-polkit.desktop создаётся только в runtime
  текущего Fedora X11. ~/.config и /etc/xdg не переписываются; пользовательские
  XDG overrides сохраняют приоритет. После завершения процессов экспорт не
  действует в других сеансах/агентах.

## Реальные проверки без установки пакетов в системы телефона

1. Из нативной фоновой команды Termux запрошен XML-каталог Zypper установленной
   openSUSE. Метаданные/cache, rpmdb, run и журнал направлены в копии внутри
   репозитория. Все имена базовых компонентов сверены с настоящим каталогом.
   Полная установка XFCE не выполнялась.
2. В отдельной проверке download-only RPM подписанные пакеты загружены в
   репозиторий. rpm --checksig с копией rpmdb подтвердил signatures/digests OK.
   Обычная копия кеша в диагностическом namespace дала Permission denied при
   hardlink/copy; потому этот прогон НЕ считается успешной полной установкой.
   Приложение использует штатный proot-distro login; его полную установку
   openSUSE/X11 предстоит проверить разработчику. Проверки подписей не обходились.
3. Нужные библиотеки из этих подписанных RPM распакованы только в отдельную
   папку зависимостей. Сборка Mesa+libsensors5 установлена нашим загрузчиком
   в собственный cache внутри репозитория с повторной SHA256-проверкой.
   SHA libsensors5 проверен по официальной странице Debian:
   https://packages.debian.org/trixie/arm64/libsensors5/download
4. В openSUSE через ограниченный proot запущен собственный C EGL-тест, без
   X-сервера и без запуска/остановки рабочего стола разработчика. Результат:
   EGL1.5; zink Vulkan1.4 (Adreno830v1 MESA_TURNIP); пиксель64,128,191,255;
   glError0. Прогон повторён с финальной структурой нашего GPU-cache,
   содержащего обе закреплённые загрузки, результат тот же.
5. Fedora filesystem/ярлыки прочитаны без изменения: бинарник lib64,
   launcher org.mozilla.firefox.desktop, xfce4-about отсутствовал. Пакет
   xfce4-about подтверждён официальным каталогом Fedora:
   https://packages.fedoraproject.org/pkgs/libxfce4ui/xfce4-about/
