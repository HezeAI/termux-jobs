# v1.1.8 — локальная сборка, не опубликована

В «Сервер + Agent» добавлены просмотр и редактирование текстовых файлов,
встроенный аудио/видеоплеер и отправка файлов на сервер. Журналы обновляют
существующий текст без пересоздания страницы.

- Меню файла → «Посмотреть» → «Редактировать». UTF-8/Markdown и другие текстовые
  форматы до 256 КБ. Проверка изменения исходного файла перед сохранением,
  атомарная замена; бинарные файлы, symlink/hardlink не редактируются.
- Media3 ExoPlayer создаётся только при открытии файла. Использует системные
  Android-декодеры, без программного codec bundle/фонового сервиса/кэша.
  Полноэкранное окно, пауза и перемотка, внешний плеер или скачивание.
  Закрытие/фон освобождают плеер и принадлежащий ему SSH-туннель. Внешний плеер
  получает временную loopback-ссылку; остановка/таймаут туннеля остаются доступными.
- Файлы → «Отправить файлы на сервер»: 1–20 документов через системный выбор,
  подтверждение сервера/каталога/размеров, прогресс по подтверждённым SFTP-записям,
  остановка, переименование/замена/пропуск совпавших имён.
- Передача идёт в случайный закрытый временный файл в целевом каталоге; обычная
  публикация не перезаписывает существующий путь. Замена только явно выбранного
  regular file, если SFTP поддерживает posix-rename. Проверяются размер/mtime/mode
  перед публикацией, но сторонние редакторы не блокируются: это не CAS.
  Владелец нового файла — SSH-пользователь; при замене копируются обычные mode bits,
  ACL/xattrs/владелец исходного файла не копируются. Ограничение — 2 ГБ на файл.
- При остановке/ошибке очистка известного временного файла повторяется отдельным
  SFTP-подключением. Если сервер недоступен, показывается путь для ручной очистки.
  Убийство Android-процесса может оставить временный файл. При обрыве в момент
  окончательной публикации результат нужно проверить в каталоге; повтора замены нет.

## Совместимость

com.termux, прежний сертификат, versionCode1065. Библиотекаv8, профили, Codex/AI,
SSH-сессии и данные окружений не мигрируют и не сбрасываются. Agent.py прежний,
переустановка агента/FFmpeg не требуется. Для отправки сервер должен разрешать SFTP.
Android min24 и target28 прежние; compile SDK35 нужен для Media3 1.5.1 и не
меняет target SDK. Media3 закреплён на этой версии для существующего сборщика.
Фактическая поддержка кодеков зависит от устройства. APK устанавливает пользователь.
GitHub и настоящий сервер в ходе разработки не меняются.

Результаты автоматических и ручных проверок разделены в
[VALIDATION-v1.1.8.md](VALIDATION-v1.1.8.md).
