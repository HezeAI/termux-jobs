## Ревью и границы

Процессный кеш не содержит Activity, worker или содержимого файлов; нет
фонового сервиса/таймера/постоянной БД. При завершении процесса он исчезает.
Чтение не продлевает срок; перегруппировка сохраняет исходный возраст.
Restore/import сбрасывает оценки. Сводка не является разрешением на чтение,
не подставляет данные в архив и не заменяет свежие проверки источников.

Пути initial scan / cache hit / manual fresh refresh / add-folder regroup /
error / BUSY / close / late callback прослежены. Пока нет готовой оценки,
создание заблокировано. Сканирование отключает редактирование формы и кнопку
создания; Cancel доступна. Обновление сохраняет выбор компонентов/папку назначения.
Закрытие вызывает cancel только своего Engine, callbacks закрытой шапки игнорируются.
Прогресс меняет только spinner и строку; после завершения перестраивается только
диалог бэкапа. Терминал, сессии, сервер и частота их опроса не затронуты.

Сжатие: gzip1, pigz2/4; уровень1/3/9 независим. Установка pigz требует прежнего
явного подтверждения пользователя приложения. Для legacy proot-distro полный
архив Ubuntu использует штатное сжатие; предупреждение сохранено.
Threads — необязательное поле metadata, форматы архивов и существующие readers
сохранены; прежние запросы получают прежние defaults.

Schema8, пакет/сертификат прежние, сброс с1526 не нужен. Для перехода с версии
до1522 действует прежняя очистка приватных данных удалённых локальных ИИ,
см. RELEASE-v1.5.22-test.md. Другие данные не сбрасываются.

Разработчику на устройстве проверить первый вход со сканированием, выход и
повторный вход, положение Refresh в обоих режимах и обоих языках, spinner/строку,
обновление с сохранением выбора/пути, отмену и отсутствие продолжения обхода
после закрытия. На маленьком DPI проверить перенос названия и видимость Refresh.
Сделать небольшой архив каждым доступным методом; реальная скорость pigz на
устройстве не измерена. Мок-тесты не доказывают реальные жесты/DPI/Android-жизненный
цикл или скорость файловой системы. GitHub-публикация не выполнялась.
