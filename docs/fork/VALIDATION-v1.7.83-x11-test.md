# Проверки v1.7.83-x11-test / code1298

Частная сборка Arch Linux X11. Публикация на GitHub не выполнялась.

## Изменения и совместимость

Arch Linux ARM использует свой rootfs `archlinux`, процесс `:jobs_x11_archlinux`,
экран105 и приватный каталог. Добавлены XFCE, ввод Fcitx5, PulseAudio, общие
исправления запуска/фона/меню/закладок и диагностика сессии X11. CPU по умолчанию;
Turnip + Zink и VirGL выбираются до запуска, GPU-композитинг Arch отключён.
Модель: один рабочий стол на окружение; разные окружения не перенаправляются
в Ubuntu. Архив драйвера хранится отдельно от APK, системная Mesa не заменяется.

Pacman устанавливает полный явно заданный набор обязательных компонентов.
Установка и подготовка каталога выполняют полное обновление пакетов выбранного
Arch (`-Syu --needed`); это отмечено в подтверждениях. Подготовленный повтор
использует `-Su`, родной кэш сохраняется. Ни подписи, ни зависимости не обходятся.
Удаление использует только `-R`, без recursive/cascade/nodeps, системные компоненты
защищены. Исправление прав ярлыков использует собственные файлы Pacman и
проверенные SHA256 из mtree; пользовательские правки не одобряются автоматически.

VirGL: отдельный сервер/сокет для Arch, native компоненты Termux и Mesa внутри
Arch. Выбранная Ubuntu не используется. Механизм остановки группы процессов
не переписывался. Управление процессами идёт через прежний pipe-owned guardian.

Пакет com.termux и сертификат сохранены; code1298 выше1297. Форматы данных
не меняются, автоматического сброса/переноса нет. Истории и пресеты не очищаются.
Установка X11/программ по согласию пользователя изменяет пакеты выбранного Arch;
это особенность rolling-системы, не миграция данных при обновлении APK.

Имена обязательных и рекомендуемых пакетов сверены с core/extra Arch Linux ARM,
включая LibreOffice Fresh и совместимый llvm22-libs. Взяты метаданные официального
зеркала de3.mirror.archlinuxarm.org по HTTPS с проверкой сертификата; обход
проверки TLS не использовался. Это проверка каталога, не тест установки пакетов.

## Автоматические проверки

102 Python-теста пройдены: Arch, Void, GPU, VirGL, native/scoped окружения,
рабочий стол, программы, клавиатура, закладки и возобновление программ.
Дополнительно3 теста матрицы всех окружений пройдены:

- Termux/Alpine/Fedora/openSUSE/Void/Arch: исполненные shell-фикстуры подтверждают
  запрос полного пакета компонентов даже при ответе mocked DB «установлено»;
  отсутствие xfdesktop, панели или xfconf-query блокирует готовность.
- Ubuntu/Debian и старый приватный alias: исполняемая проверка отклоняет
  отсутствие компонентов XFCE/D-Bus, аудио-пакета и файла CA.
- Все гостевые окружения: check/install/run и операции программ сохраняют
  выбранный rootfs, bind своего control-каталога и корректный login/run.

66 JVM-тестов пройдены:32 X11Integration,6 DesktopProgramResume,
9 WorkspaceDesktopGpu,18 WorkspaceDesktopPrograms,1 WorkspaceDesktops.
Проверены уникальность процессов/экранов/портов/каталогов, отказ чужому rootfs
во всех приватных службах, остановка/cancel/закрытие владельцев для всех targets,
отдельное сохранение GPU-настройки Arch и сохранение работы остальных каналов.
Всего171 автоматическая проверка. Исполненные моки не являются установкой
на Android и не доказывают GUI, жесты, ввод, разрешения или работу GPU.

Сборка Release успешна (1м1с), DEX13498 определений/31 явно рассмотренный
неразрешённый тип. ZIP/package/minSDK26/arm64/code/cert/v2/SHA проверены.
JNI34 дескриптора сверены. Базовые native-библиотеки идентичны v1.7.5,
относительно v1.7.82 изменены только9 ожидаемых X11 assets; добавленных
архивов драйверов в APK нет. Изменённые Java/assets сверены со staging.
Поиск известных маркеров ключей/авторизационных файлов пройден, он не даёт
исчерпывающей гарантии отсутствия любого секрета. bash/sh -n и diff --check пройдены.

Свидетельства: `.verification/arch-x11/{python.log,clean-matrix.log,jvm.log,
jvm-results.json,build.log,audit.log,apk-audit.json,mesa-latest.json,
mesa-release.json,core-packages.json,extra-packages.json}`.

## Проверка на телефоне

Разработчик подтвердил: рабочий стол и GPU Turnip + Zink Void работают на v1.7.82.
Arch X11 этой сборки пока не проверен на телефоне. Минимум: установка/старт CPU,
фон и файлы/клавиатура/звук, одна небольшая программа; затем остановка и
Turnip + Zink с glmark2, затем отдельный тест VirGL. Проверить закрытие сессии
и повторный запуск. Чистая установка Arch X11 на другом телефоне остаётся
самостоятельной проверкой. Системы и рабочие сессии при разработке не менялись.
