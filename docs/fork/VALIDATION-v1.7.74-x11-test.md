## Изменения

- Void X11: отдельный сервис/процесс, display104/порт8004/контрольная папка;
  XFCE, Fcitx5, PulseAudio, свой XBPS-каталог/проверка/установка/удаление.
- Приватный Turnip+Zink для Void glibc, pinned Mesa26.3/LLVM18; композитор off.
- VirGL первоначально для Termux/Ubuntu: отдельный выбор до установки стола,
  согласованная установка Termux virglrenderer-android/ANGLE/Mesa и гостевой
  Mesa. Нативный сервер использует официальные `--angle-gl`, `--no-fork`,
  `--multi-clients`, `--socket-path`; сокет индивидуален для запуска.
- Для программ всех подключённых X11 сохранение незавершённого запроса и кнопка
  «Продолжить» после Stop/ошибки/повторного входа. Нет автоматического рестарта.
  Повторный install пропускает успешно завершённый refresh, сохраняет подписи,
  зависимости, конфигурацию и штатные блокировки менеджера. Используется один
  штатный пакетный кэш, без отдельных копий архивов. Доступность побайтовой
  докачки зависит от менеджера/сервера. Восстановление конфигурации после
  прерывания распаковки не обходится принудительными флагами.
- openSUSE Evince включает evince-plugin-pdfdocument; Parole — приватную
  OpenH2642.6.0 из pinned Debian ARM64 DEB. Системный noopenh264 не заменяется,
  недоступный репозиторий исключается только во временном представлении Zypper.
  Приватный ярлык меню задаёт LD_LIBRARY_PATH только плееру; пользовательские
  правки/ссылки защищены. Старой установке нужно повторить группу «Видео и аудио»
  и перезапустить плеер. Старые собственные ярлыки могут обходить новый запуск.

## Ревью и логическая инспекция

Прослежены запуск/остановка/отмена/повторная установка, закрытие/повторное
открытие программ, восстановление журнала и запуск выбранного рендера.
Нативный VirGL входит в уже существующую pipe-owned группу рабочего стола.
Завершение не принимает чужие PID; EOF владельца заканчивает только свою группу.
Приватный socket-directory создаётся mktemp и имеет0700. Переменные гостевой
Mesa не передаются Android-серверу. Потеря сервера завершает свою desktop-задачу.

Журнал продолжения хранит только allowlisted идентификаторы и признак готовых
индексов; AtomicFile, ограничение размера/количества, отказ от symlink. Снимки
используют память, а не перечитывают диск на каждом опросе UI. Успех очищает
запрос; сбой/отмена сохраняет его. Сигнатуры/зависимости пакетов не отключаются.
Копии ярлыков кодека проверяются до изменения; системные RPM/ярлыки и настройки
агентов не переписываются. Изменения не добавляют root Android.

С финальным APK проверены ZIP/дубликаты, ID/code/minSDK/ABI, подпись v2,
SHA-256, JNI-дескрипторы28+1+5, DEX-классы Void/журнала/VirGL. В APK не найдено
проверяемых маркеров приватных ключей/токенов и приватных конфигурационных файлов;
это проверка конкретных маркеров, не математическая гарантия отсутствия секретов.

Относительно73: пять добавленных и девять изменённых ассетов перечислены в
`.verification/x11-next/delta.json`. Библиотеки JNI побайтно прежние; все новые
ассеты и изменённые исходники сверены с упакованными. Изменения Java из новой
сборки совпадают с staging, прошедшим проверки. Вне этих изменений сохраняется
проверенное сравнение со стабильной v1.7.5.

## Совместимость и проверка разработчиком

Нет изменения схемы пресетов/историй/проектов, автосброса или переноса данных.
Добавлены только приватные журналы/метаданные. Кэш рекомендаций openSUSE
пересканируется один раз для учёта настоящего кодека. Совместимость идентичности
обновления подтверждена; фактическое обновление и сценарии устройства ещё нужны.

Минимальная проверка разработчиком:
1. Void: установка/CPU XFCE, клавиатура, звук, Mousepad; затем Turnip+Zink.
2. Termux и Ubuntu отдельно: выбрать VirGL, установить компоненты, запустить
   стол/GL-тест, остановить. Проверить, что соседний стол остаётся работать.
3. Прервать загрузку программы, закрыть/открыть приложение, нажать «Продолжить»
   в той же карточке. Проверить успех и сохранение независимости окружений.
4. openSUSE: повторить «Видео и аудио», перезапустить Parole из Applications,
   открыть реальное MP4/H264 и PDF в Evince.

GL4ES, импорт своего Turnip и выбор60/120Гц отложены. Частота остаётся60Гц.
Обычный openSUSE glmark2/GLX с ошибкой FBConfig не объявляется исправленным:
подтверждён разработчиком только glmark2-es2 через EGL/Zink на Adreno830,
без финального Score. Реальные VirGL/Void UI, жесты/клавиатура и воспроизведение
записи не подтверждаются автоматическими или искусственными тестами.
