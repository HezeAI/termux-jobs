# Termux Job’s v1.0.19 — кандидат, не опубликован

## Главное

- Проверка обновлений GitHub в общей шестерёнке. Краткие изменения RU/EN,
  скачивание с прогрессом/отменой, проверки SHA-256, размера, пакета,
  versionCode/versionName и сертификата, затем системное подтверждение установки.
- В общих настройках убран дублирующий пункт аккаунтов/API OpenCode.
  Подключения доступны при создании/настройке сессий и пресетов запуска.
- Стандартное журналирование приложения выключено по умолчанию. Прежний NORMAL
  однократно меняется на OFF; DEBUG/VERBOSE и дальнейший выбор сохраняются.
  Собственный журнал сессий работает независимо.

## Совместимость

com.termux, Android 7+, ARM64, versionName1.0.19, versionCode1056, прежний
сертификат, библиотекаv8. Обновление поверх поддерживается при том же сертификате
и меньшем установленном versionCode; специальная резервная code1100 не подходит.
Первую версию с обновлением надо установить вручную. Перед установкой завершите
важные задачи: Android может остановить процессы приложения. Не удаляйте приложение
для обновления — удаление уничтожает приватные данные. Миграция данных не меняется.

Для будущих релизов нужен update.json рядом с APK; без него выдаётся пояснение.
Реальную установку через новую функцию надо проверить на следующем стабильном
релизе. AI Agents остаются экспериментальными; мерцание OpenCode не исправлялось.
