# Необязательный стиль Termux-job's для XFCE

В частной v1.7.99 Touch Workspace удалён; сохранён только Kali-inspired.
Ресурсы Kali, размеры окон и управление мышью не изменены. При обновлении
активный выбор Touch автоматически заменяется галочкой Kali. На следующем
запуске старые изменения автоскрытия панелей, времени двойного щелчка и числа
рабочих областей восстанавливаются из первой резервной записи, если они не
были затем изменены вручную. Настройки сессий и пользовательские файлы не
сбрасываются. История эксперимента: [Touch Workspace](TOUCH-WORKSPACE.md).

В частной v1.7.95-x11-test Retro XP заменён на **Kali-inspired** по выбранному
PNG из design/x11-linux-concepts-v1.7.94/. Это тема для нашего XFCE, не установка
дистрибутива Kali или его инструментов. Прежние реализации описаны исторически
в VALIDATION-v1.7.91,93,94-x11-test.md.

Тема остаётся только для базового Termux. В меню «Терминал / Рабочий стол»,
под переключением вида — прежняя галочка «Стиль Termux-job's». По умолчанию
выключена. Доступна после соединения со службой, когда стол и операции установки
остановлены. Применяется при следующем запуске; работающий стол не меняется.
Для других окружений строки нет, backend отклоняет запрос гостя.

## Оформление Kali-inspired

- Тёмный GTK3 на встроенной Adwaita Dark, угольные окна, синие выделения,
  тёмные панели, Menu со знаком Termux >_. Содержимое пользовательского меню
  не заменяется. Нет отдельных загружаемых пакетов темы.
- Тонкая синяя рамка XFWM, заголовок44px, кнопки34px. Сглаженные круглые PNG
  накладываются на прозрачные XPM. XFWM поддерживает такое
  [наложение изображений](https://github.com/xfce-mirror/xfwm4/blob/master/src/mypixmap.c).
  Кнопки не имеют квадратного непрозрачного холста. Значок приложения также
  отображается на прозрачном основании. Минимизировать/развернуть/закрыть,
  заголовок слева: button_layout=O|HMC. Ширина зон растягивания6px сохранена,
  тонкая линия не уменьшает область захвата.
- Боковые/нижние тайлы постоянны вдоль оси повторения: прежний пунктир не
  возвращается. Композитор для нарисованных ресурсов не требуется.
- GTK2 получает простой тёмный gtkrc без внешних движков. Приложения с Qt,
  собственными декорациями/цветами могут отличаться от PNG. Это не полная
  замена оформления каждого приложения и не пиксельная копия макета.
- Свои синие PNG-значки96×96: папки и разные Home/Documents/Downloads/Pictures,
  терминал, браузер, корзина, компьютер, накопитель и документы. Базовые
  Thunar/Firefox-имена также сопоставлены этим значкам. Остальные наследуют
  Adwaita/hicolor. Значки рабочего стола80px, нижней панели56px; пропорции
  изображений одинаковы, без растягивания отдельных значков.
- Нижняя панель88px, ширина100%, автоскрытие выключено, верхняя48/32px.
  Шрифт интерфейса DejaVu Sans13, заголовков Bold13, значков12; Thunar zoom150%.
  Это пиксели XFCE, не Android dp: результат зависит от масштаба X11.
- Фотофон971×1619: тёмные горы, озеро и синий дракон, курсивные Termux-job’s,
  &, X11. Извлечён из выбранного концепта встроенным image_gen и адаптирован
  под вытянутый экран без растягивания рисунка. Исходник/промпты находятся в
  design/x11-kali/. Используется пропорциональный zoom: в другой ориентации
  края могут обрезаться; GUI и смена ориентации требуют проверки на телефоне.
- Прежние статичные чёрные курсоры с белой обводкой32px. Приложение может
  рисовать свой курсор. Неизвестные имена используют Adwaita.

Существующий applicationsmenu перемещается к началу существующей нижней
панели, получает Menu и свою иконку. Все прочие плагины/ID сохраняются;
новые панели, Applications/Places/часы из макета не создаются принудительно.
Если нижняя панель или её массив ID отсутствуют, перенос не выдумывается.
Для чистой установки читается default.xml из собственного PREFIX.

## Ресурсы и обратимость

scripts/prepare-x11-style.py создаёт собственные Cairo-значки, PNG-кнопки,
XPM-рамки и Xcursor. Фон — сохранённый PNG. Итоговый x11-style.zip включён в APK;
сборка сверяет SHA256 исходного фона и архива. GTK CSS импортируется из
встроенного ресурса установленной GTK3, а не копируется в приложение.

x11-style.py работает только в своей новой D-Bus-сессии Termux, до XFCE/xfconfd.
Меняются отдельные свойства пяти пользовательских XFCE XML-каналов.
Бинарники/системные конфиги и rootfs не заменяются. Тема остаётся в
~/.themes/TermuxJobsStyle, значки в ~/.icons/TermuxJobsIcons, курсоры в
~/.icons/TermuxJobsCursor, фон в ~/.local/share/termux-jobs/style/wallpaper.png.

До записи сохраняются исходные свойства и хеши собственных файлов в
~/.local/state/termux-jobs/style/previous.json. Если XP уже применялся,
известные ресурсы обновляются при следующем запуске, первая резервная запись
остаётся. Выключение возвращает свойства до первого стиля, не промежуточную XP.
Отличающиеся ручные правки при выключении сохраняются. Новые свойства
button_layout/title_alignment тоже обратимы. Повторный старт не теряет
порядок плагинов/Menu и первую резервную запись.

Чужой изменённый файл на месте ресурсов, ссылка или плохой XML не
перезаписываются принудительно. Повтор после прерванной записи сохраняет
оригинал. Ограничения: файл/архив8MiB, распаковка16MiB,192 записи и pinned SHA256.
При выключенной галочке без прежнего применения нет записи конфигов.
Ubuntu/Ubuntu AI, Debian, Alpine, Fedora, openSUSE, Void и Arch эту тему не получают.
Рендеры, драйверы, клавиатура, остановка процессов и параметры агента прежние.

## Проверка на телефоне

Остановить Termux XFCE → оставить/включить галочку → запустить. Проверить
цвета окон/полей/меню, Home/Documents/Downloads, пропорции значков, рамку при
разных размерах окна, все состояния круглых кнопок и меню значка приложения.
Проверить курсор/растягивание и обе ориентации. Выключить и проверить возврат
своего оформления. Отдельно требуется чистая установка. Тесты пикселей/GTK CSS
без живого экрана не заменяют эту проверку.
