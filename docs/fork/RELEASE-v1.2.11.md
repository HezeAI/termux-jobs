# v1.2.11 — локальная проверка

Библиотека114 карточек (+36,4 расширены): опыт разработки, ошибки помощника,
права и клавиатура, AI Agents, бэкапы, SSH/SFTP, обновления и сборки.
Проектные источники и степень проверки выделены отдельно; OC001 не объявлен
решённым. Повторяющиеся симптомы объединены с альтернативными причинами.

С сервера можно скачать в выбранную папку Termux, установленного окружения
proot-distro или памяти устройства. Прежний быстрый Download остаётся.
Проверка доступа, подтверждение назначения, уникальное имя, .part, прогресс,
остановка и сообщение об ошибке очистки. Нет промежуточного полного файла.

Сохраняются изменения локальных1.2.3–1.2.9: библиотека, ключи/passphrase,
общий файловый менеджер и загрузка до50 файлов через существующую очередь SFTP.

## Совместимость

Пакет com.termux, прежний сертификат, versionCode1082. Форматы пользовательских
данных не меняются, очистка не требуется. Системные пакеты, агент и установленные
окружения этим APK не обновляются. Файлы назначения требуют прав записи;
скачивание ограничено2ГБ/10минутами. Реальная установка/передачи проверяются
разработчиком отдельно. Новая резервная сборка не создаётся.

Это локальный кандидат, GitHub остаётся v1.2.2. Публикация после проверки
и отдельной команды разработчика. Метаданные обновления подготовлены локально.
