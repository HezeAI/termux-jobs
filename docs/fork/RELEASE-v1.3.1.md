# v1.3.1 — локальная проверка: просмотр в звёздочке и справочник

В терминале нажатие карточки в звёздочке теперь открывает полный текст
с прокруткой. Действия: редактировать, вставить в текущую сессию, удалить.
Вставка заменяет поле ввода без отправки; удаление требует подтверждения.
Поиск, отдельные вкладки команд/заметок и сохранение ввода остаются.
Обычные просмотры во вкладке команд/заметок и журнал не переделаны.

Библиотека «Ошибки и решения»:126 карточек (+12),8 прежних дополнены.
Boot/runit, входящий SSH, исторический re-exec sshd, sh/source, rish/package ID,
защита dex Android14+, окружение rish, чёрный экран/цвета X11, кодировка ZIP,
режим Samba под supervisor. Есть источники и ограничения; это справочные
инструкции, а не автоматические исправления. Справа от названия добавлено
«Собрано с помощью AI!» / «Compiled with AI!». База пополняется с APK.

Сайт4PDA возвращал403, полный проход всех страниц/ссылок не выполнен.
Использованы доступные индексированные обсуждения и отдельно прочитанные
официальные документы/исходники. Никакие вложенные установщики не запускались.
Надпись AI не означает, что приложение сканирует среду или общается с моделью.
[Отбор и источники](FORUM-REVIEW-v1.3.1.md).

## Совместимость

com.termux, прежний сертификат, code1084 выше1.3.0/1083. Пользовательские
форматы не меняются, очистка не требуется. Команды/заметки/пресеты/истории
не мигрируются. Только поведение нажатия в звёздочке изменено: просмотр перед
вставкой. Серверный агент, native, Ubuntu и системные пакеты не обновляются.
Новая сборка для отката не создаётся. Публикация отдельно после проверки.
