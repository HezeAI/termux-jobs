# Termux Job’s v0.2.17

Новый выпуск после v0.2.6: сессии Codex с историей и управлением моделью, SSH-сценарии и исправления повседневной работы с терминальными вкладками.

## Codex

- Отдельный тип «Сессия Codex» с выбором среды Termux/Ubuntu и доступа: полный, в пределах проекта, только чтение.
- Новый чат, выбор конкретного чата из истории или ввод ID для продолжения диалога.
- Карточка модели, поведения, состояния и пятичасового/недельного лимитов аккаунта. Фоновое обновление и кнопка «Обновить»; отсутствующие данные не подменяются выдуманными значениями.
- Выбор модели → поведения → отдельное подтверждение. Каталог запрашивается у Codex; изменение применяется через штатное меню только к текущей сессии, после завершения ответа.
- Исправлены запуск сохранённых чатов, несовместимые флаги удалённого клиента и чтение статуса из Ubuntu. Помощник работает в исходной среде и передаёт приватные метаданные без текста диалога и авторизации.
- При закрытии интегрированной сессии её скрипт завершает принадлежащие ему помощники; другие запуски Codex не затрагиваются.

## SSH и интерфейс

- «SSH · сервер»: адрес, пользователь, порт, удалённый каталог и до трёх команд на сервере; при ошибке следующие шаги останавливаются.
- Авторизация автоматически, по файлу SSH-ключа или паролю. По желанию пароль запоминается в зашифрованном виде с Android Keystore; новый ключ сервера требует подтверждения.
- Исправлена внутренняя прокрутка списков при открытой клавиатуре и поиске.
- Поиск команд и заметок в звёздочке открывает клавиатуру при нажатии.
- У каждой терминальной вкладки отдельный черновик ввода с позицией курсора/выделением. При переключении текст возвращается, после отправки очищается. После закрытия вкладки или перезапуска приложения черновик не восстанавливается.

## Установка и совместимость

Android 7+, ARM64. Пакет `com.termux`, версия 0.2.17 / versionCode 1033, прежний сертификат Termux Job’s. APK устанавливается поверх совместимой подписанной версии форка без удаления данных. Обычный Termux с другой подписью поверх не обновляется. Перед обновлением сохраните резервную копию.

Формат библиотеки v8 читает v1–v8; откат на старый APK не гарантирует чтение новых профилей. Не очищайте данные Android-приложения ради отката: это удаляет Linux-среду. Сохранённый профиль Bash не восстанавливает живой процесс; история диалога Codex хранится самим Codex.

Codex, Node.js, Ubuntu, OpenSSH и средства сборки не входят в APK. Для карточки нужна новая сессия типа Codex после обновления. Проверено с CLI 0.162.1; другие версии и неизвестные терминальные меню могут потребовать ручного выбора. Ограниченный sandbox зависит от среды и не заменяется полным автоматически.
