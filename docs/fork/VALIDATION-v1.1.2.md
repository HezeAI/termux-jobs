## Факты и ограничения

Пользователь сообщил: полная копия проходит; «По выбору» в1.1.1 даёт
SOURCE_UNREADABLE. Скриншот не содержит проблемного пути. Код подтверждает:
старый onerror немедленно прекращал весь расчёт; отдельной ошибки одного каталога
достаточно для такого результата. Точный каталог/errno на телефоне не установлен.
Read-only обход каталогов из Ubuntu/proot не повторил ошибку; эти права и bind mounts
могут отличаться от прямого запуска Android-worker, поэтому это не опровержение
скриншота. Теперь ошибки показываются по компонентам, не скрываются как полная копия.
Служебное L2S отличается от обычных symlinks; установленный proot-distro native
backup исключает .l2s и сохраняет backing content. Выборочный код теперь делает
переносимые entries без изменения источников. Это отдельная проверенная проблема
портируемости; не утверждается, что именно .l2s вызвал показанный SOURCE_UNREADABLE.

lintVitalRelease завершается вместе со сборкой, но upstream lint/JNA выдаёт
Unsupported OS/arch: Linux/aarch64 — это не полностью чистый полный lint-анализ.
Native proot/APT в тестах подменены, установки/реального восстановления не было.
Новые формы, IME/DPI/жесты, загрузку реального будущего GitHub APK и Android installer
надо проверить на телефоне. Мок-тесты прогресса не скачивают APK из сети.

Минимально: обновиться поверх1.1.1, открыть «По выбору», посмотреть список и
возможные проблемные пути, выбрать доступный Codex; убедиться, что кнопки создания
в обоих режимах активны только при согласии и папка подписана явно. Восстановление
системы+Codex проверить отдельно на втором устройстве. Публикация после проверки.
