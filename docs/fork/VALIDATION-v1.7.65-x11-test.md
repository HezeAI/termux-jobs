# Частная v1.7.65-x11-test / code1280

Выбор CPU/Turnip + Zink теперь только сохраняет режим для выбранного
окружения: не проверяет/не устанавливает рабочий стол, не загружает драйвер
и не запускает X11. Выбирать можно и при отсутствующем рабочем столе;
при работающем столе смена по-прежнему блокируется.

«Переключиться на рабочий стол» берёт сохранённый режим, проверяет стол,
предлагает установить недостающее, затем подготавливает выбранный рендер
и запускает стол. Установка стола/драйвера остаётся в центральном экране
с прогрессом и отменой. Повторно выбирать рендер после установки не нужно.
Отказ/ошибка загрузки не переключают на другой режим и не запускают стол.
Предпочтение сохраняется для повторной попытки. Исправление видимых карточек
установки окружений из64 сохранено. Автоматического удаления/миграций нет.

## Изменение и логическая инспекция

WorkspaceDesktop.selectRenderer сохраняет только выбранный режим в per-target
настройку. Ветки установки/службы из этого обработчика удалены. Открытие меню
может читать состояние службы для блокировки смены на работающем столе.
menuAction для запуска захватывает этот режим и запрашивает check. После
успешной проверки/установки prepareSelectedRenderer подготавливает рендер,
и только затем отправляет launch с выбранным renderer и владельцем сессии.
Уже работающий стол показывается без повторной установки.

Сохранены подтверждения, контроль SHA-256, отдельный маркер отмены загрузки
драйвера, блокировка поздних callback и перенесённый в свою вкладку запрос
подтверждения. Системная Mesa/другие сессии и установленные окружения
при сборке не изменялись. Идентичность пакета/сертификата прежняя,
versionCode1279 →1280. Сброс/миграция пользовательских данных не требуются.

## Проверка на телефоне

Нужно выбрать GPU без установленного стола и убедиться, что начинается
только сохранение выбора. Затем «Переключиться»: подтверждение, установка
стола/драйвера в центре, запуск выбранного режима. Отдельно проверить
уже установленный стол, отказ/отмену и повторный запуск без загрузки.
Это не проверяется полностью JVM-моками; результаты устройства пока неизвестны.
APK не публикуется на GitHub.

## Автоматические проверки

53 JVM/Robolectric-теста прошли: подготовка стола19, GPU6, общий UI20,
карточки Ubuntu4, карточки окружений2 и прогресс2.
.verification/x11-renderer-deferred/jvm-final.log.
Новые случаи: сохранение GPU до установки без начала проверки/загрузки;
сохранение CPU при установленном столе без запуска; кнопка переключения
подхватывает ранее сохранённый GPU и предлагает подготовку отсутствующего
драйвера только после проверки стола, отказ не вызывает launch.

Инспектирован порядок shell: check/install завершаются до проверки GPU,
поэтому отсутствие драйвера не блокирует установку самого рабочего стола.
Тест маршрутизации команд временно подменяет SDK28 →30 только для проверки
команды; показ UI проверяется на SDK28. Это не тест Android30/клавиатуры/X11.
