# v1.5.23-test — файлы сервера, фоновые передачи и активность сессий

В этой приватной сборке также добавлены:

- «В фон» для скачивания и отправки: сохраняется та же передача и окно,
  строки прогресса появляются в карточке сервера только при активных операциях.
  Нажатие возвращает прогресс/отмену; рамка «Сервер + агент» анимируется по часовой.
- Тонкая линия активности во всех терминальных сессиях, с постоянной высотой
  области и без пересоздания терминала при анимации.
- Вместо Toast при изменении заголовка другой сессии — кружочки над вкладками,
  краткий плавный текст события и окно других сессий по нажатию.
- В списке открытых AI Agents — векторный робот; у обычных сессий остаётся терминал.

Фоновые передачи здесь означают продолжение при работе в других вкладках
живого приложения. Защита от уничтожения процесса Android и автопродолжение
не добавлены. Отключение профиля/закрытие владельца останавливает передачу.
Прогресс и анимация обновляют свои View/Drawable, не пересоздают терминал.
Индикатор сессии — активность PTY/доступной локальной команды, не процент
готовности; тихий SSH и неподдерживаемый агент могут не сообщать занятость.

Приватная ARM64-сборка, com.termux, code1160 >1159, Android8+,
прежняя подпись. Публикация на GitHub не выполняется.

После домика в файлах сервера добавлена векторная корзина. Первое нажатие
включает режим выбора файлов/папок и подсвечивает обводку кнопки. Повторное
нажатие при пустом выборе отменяет режим. Если объекты выбраны, открывается
прокручиваемый список путей с подтверждением «Да / Нет». «Нет» сохраняет выбор.
Прежний долгий тап тоже выделяет объекты для корзины. При выделенных записях
подсвечены обе карточки: корзина и скачивание/перемещение. Смена папки или
профиля сбрасывает режим и выбор.

Удаление выполняется с сервера безвозвратно, с правами SSH-пользователя.
Папки удаляются с содержимым; у символических ссылок удаляется ссылка,
а не её цель. Нужен Linux/Python3, обновление установленного агента не нужно.
Вся выборка проверяется перед изменениями. Переходы по ссылкам в пути,
переходы на другие файловые системы, специальные файлы и изменившиеся
проверенные объекты блокируются. До500 выбранных объектов,20000 вложенных
записей,64 уровней,25 секунд проверки и удаления.

Ошибка или обрыв могут оставить частично удалённую папку: уже удалённые
данные не восстанавливаются, автоматического повтора нет. При полученном
ответе показывается число полностью удалённых выбранных объектов; если
ответ потерян, результат остаётся неподтверждённым — нужно проверить список.
Диагностика получает тип операции FILE_DELETE и код ошибки, без путей/содержимого.

Общая библиотека остаётся schema8, сброс не нужен. Сохраняются остальные
текущие функции, данные и истории CLI-агентов. Локальные модели не возвращены;
если обновляться с версии до1.5.22, действует прежняя преднамеренная очистка
приватных моделей/историй локальных ИИ, описанная в [1.5.22](RELEASE-v1.5.22-test.md).

English: vector server trash after Home; empty selection toggles/cancels selection
mode, nonempty selection opens a scrollable Yes/No permanent-deletion prompt.
Long-press selection works for trash/download/move; both action cards highlight
when entries are selected. Recursive folder deletion never follows symlink targets.
Existing pinned SSH/Python transport, no installed-agent update. Partial deletion
is reported, never automatically retried or rolled back. Same package/certificate,
schema8 and current other features; no reset. Local models remain removed.
