# v1.1.7 — файлы и компоненты серверов (локальная проверочная сборка)

На GitHub НЕ опубликовано. Публичная Latest остаётся v1.1.4.

Векторные значки папок/файлов и стрелки вместо сплющенного символа. Свойства
показывают имя, путь, подходящий размер и дату с поясом вместо сырого JSON.
Для обычных файлов только stat; ffprobe вызывается только для известных медиа.

«Компоненты агента» в троеточии сервера: состояние FFmpeg/ffprobe, установка
через отдельную задачу после подтверждения сервера и команды. APT, root либо
настроенный sudo -n; sudo пароль в задаче не спрашивается. Для запроса пароля
есть обычный SSH-терминал. Пакеты/зависимости не удаляются вместе с агентом.

Плашка просмотра появляется только при активном туннеле, показывает имя и
останавливает только его. Папки/свойства больше не пересоздают весь экран,
неизменная история графика не вызывает redraw. ! убран с верхней плитки,
описание остаётся внутри раздела.

## Совместимость и проверки

com.termux, min24/target28, ARM64, code1064, прежняя подпись. Библиотекаv8,
серверные профили и обычный SSH без сброса/миграций. Агент1.0.0 побайтно прежний:
переустановка не нужна. Фоновые процессы при обновлении Android могут быть
перезапущены: завершите важные операции перед ручной установкой APK.
Реальная установка FFmpeg, плеер, жесты/DPI и визуал требуют проверки пользователем.
Во время разработки сервер/бот/пакеты/рабочие сессии не менялись, APK не установлен.
