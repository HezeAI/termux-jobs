# Termux Job’s v1.0

Изменения относительно предыдущего публичного выпуска v0.2.17.

Новый удобный интерфейс теперь поддерживает русский и английский. Векторный глобус рядом с шестерёнкой переключает язык без перезапуска терминалов; верхние плитки содержат только центрированные иконки с прежними размерами. Переведены меню, диалоги, настройки, SSH, файлы и карточка Codex с выбором модели и уровней рассуждения.

После v0.2.17 добавлены выбор/создание проектной папки, просмотр и экспорт файлов, базовая сессия Terminal и стопка открытых сессий. История Codex доступна независимо от проектной папки, с отдельным фильтром; другой каталог требует явного подтверждения. ID и история чата сохраняются, файлы не перемещаются и права не повышаются.

Исправлены векторные значки, отступы между кнопками сохранённых сессий и двойная подсветка фильтров команд/заметок. Черновики раздельны для терминалов. Журнал по-прежнему хранит последние 50 отправок с повторами. Пользовательские тексты и вывод программ не переводятся.

Установка: ARM64, Android 7+, пакет com.termux, versionName 1.0.0 / versionCode 1037, прежний сертификат. Обновление поверх нашей версии; оригинальный Termux с другой подписью поверх обновить нельзя. Не удаляйте приложение ради обычного обновления. SDK/Node.js/Codex/proot-distro/Ubuntu и авторизация не поставляются в APK; нужная среда должна быть подготовлена отдельно.

Формат библиотеки v8 сохранён. Старые версии до v0.2.18 не поддерживают его редактирование. Codex-история хранится в выбранной среде отдельно.

Проверки и оставшиеся сценарии телефона: [VALIDATION-v1.0.md](VALIDATION-v1.0.md). 228 тестов прошли, проверены переводы, локализованные shell-команды, версия, ARM64, ZIP и прежняя подпись. APK одобрен пользователем для публикации; подробные автоматические проверки на реальном Android не заявляются. Контрольная сумма опубликована в SHA256SUMS.

Форк основан на Termux v0.118.3. Исходный проект: https://github.com/termux/termux-app. Лицензия GPLv3 и исходные уведомления сохранены.
