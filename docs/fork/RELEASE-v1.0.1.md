# Termux Job’s v1.0.1 — локальная сборка

Добавлен менеджер пакетов по долгому тапу на название сессии → Пакеты.
Поддержаны Termux и Ubuntu, включая выбранное окружение Codex и базовую Terminal.
Установленные / Доступные / Обновления, поиск по именам и отображение версий.
Данные берутся из локальных баз dpkg/APT настроенных репозиториев.

Установить, обновить или удалить пакет и обновить каталог можно после подтверждения.
Выбор: в выбранной сессии (по умолчанию) либо новой сессии того же окружения.
Если выполняется команда или Codex, выбирайте новую. Для существующей сессии
пользователь сам проверяет свободный Bash, соответствующее окружение и отсутствие
незавершённого ввода. Нет автоматического определения принимающей ввод программы.
Пакеты остаются в выбранном окружении и доступны всем его сессиям после закрытия
сессии без сохранения. Все новые меню и предупреждения переведены RU/EN;
названия/версии и вывод пакетного менеджера не переводятся.

Пакет/сертификат сохранены для обновления поверх v1.0, versionCode 1038,
versionName 1.0.1. Формат библиотеки v8 не меняется, Android 7+ / ARM64.
SSH и текстовый редактор не включены. Не устанавливалось агентом и не опубликовано.

237 tests, localization, release/lintVital и проверки APK прошли;
[подробности и оставшаяся проверка устройства](VALIDATION-v1.0.1.md).
