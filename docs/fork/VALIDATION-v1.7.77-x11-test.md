# v1.7.77-x11-test / code 1292

## Изменения

- Общий запуск X11 добавляет в GTK3/Thunar только отсутствующие локальные закладки с английскими подписями: Phone storage (`/sdcard`), Downloads (`/sdcard/Download`), Home (HOME выбранного окружения). Произвольные папки загрузок отдельных приложений не сканируются. Существующие закладки и их подписи сохраняются; одинаковые URI не дублируются. Удалённые стандартные пункты восстанавливаются при следующем запуске.
- Выполняется один ограниченный проход файла закладок при запуске. Нет фонового опроса, сканирования памяти, загрузки интерфейса или получения root. Ссылки позволяют зайти напрямую в разрешённые папки при запрете просмотра `/`, но не обходят разрешения Android.
- Файл ограничен 1 MiB, записи заменяются атомарно, сохраняется режим доступа существующего файла. Ссылки/спецфайлы/повреждённый файл и внешний XDG_CONFIG_HOME не изменяются. Ошибка добавления закладок не блокирует рабочий стол и не выводит содержимое пользовательских записей в журнал.
- До нового запуска стола при отсутствии разрешения хранилища показываются «Разрешить» / «Пока нет». Разрешение использует существующий Android-механизм приложения. «Пока нет» продолжает запуск без доступа, без постоянного сохранения отказа. При новом запуске вопрос повторяется, пока разрешение отсутствует. Переключение на уже работающий стол повторный запрос не вызывает.
- Отмена запроса Android или перехода в настройки также позволяет продолжить запуск после подтверждения отказа. Callback проверяет, что контроллер жив, исходная сессия ещё выбрана и вкладка видима. Прежние файловые диалоги используют прежний callback только успешного grant, поэтому отказ не открывает пустой браузер.
- Все подключённые X11 используют один механизм: Termux, Ubuntu, Debian, Alpine, Fedora, openSUSE, Void. Общий session helper подготовлен и для будущего Arch X11; подключение самого стола Arch не входит в это изменение.
- Fcitx, клавиатура, пакеты и разрешения системных каталогов не изменены. Пользователь уточнил, что ручной ввод работает; обновление библиотек не выполняется автоматически.

## Логическая инспекция

Запрос относится только к новому запуску из меню X11; возврат в терминал/работающий стол не требует повторного grant. Нет сохранения глобального «не спрашивать». Отказ не подменяет право Android и не блокирует локальную HOME. Callback успешного grant вызывается только после фактической проверки разрешения. Для файловых диалогов отказ по-прежнему не продолжает выбор. Жизненный цикл и остановка X11/guardian, другие агенты и пользовательские данные не затрагиваются.
