# Проверки v1.6.0

Stable-релиз: com.termux, version1.6.0/code1192, Android8+/ARM64.
Разработчик — HezeAI; Codex помогает с проверками. Это отчёт о конкретном APK,
а не подтверждение каждого сценария на всех устройствах.

## Итоговый APK

- `Termux-Jobs-v1.6.0-arm64.apk`, 36663894 байт.
- SHA-256: `2df1b376677e98e2f7c4da4dcda00229f7c9ae33846648fbe2ae858e1ba87cf3`.
- Сертификат SHA-256: `dd37d983cd2496ebe49c7e88ddbc0088f311d38b8a8503e4392c81b48a11a644` — прежний сертификат форка.
- ZIP CRC, отсутствие повторных/небезопасных путей, package/version/minSdk/ABI,
  подпись v2 и отсутствие debuggable проверены.
- Required runtime definitions проверены: 13108 определений классов, 31 прежний
  явно рассмотренный optional/unavailable тип; runtime-аудит не обходился.

  меняются номер/код выпуска и связанные ресурсы. Локальные AI-движки не добавлены.

  фиктивные строки unit-тестов, не настоящие ключи и не содержимое APK.

## Автоматические проверки

- Полный запуск scripts/verify-java.sh: **630 JVM-тестов** (app476,
  terminal-emulator154), без ошибок/пропусков. Terminal-view/termux-shared
  test tasks выполнены; собственных test cases в этих двух модулях нет.
- Дополнительно WorkspaceStoreTest: **24 тестов**, без ошибок,
  включая новый сценарий чтения schema8 без новых optional-полей агентов.
  Проверены Codex/Gemini/Claude/SSH, прежние поля/права/ID, команды/заметки,
  шифротекст SSH и повторное сохранение/открытие. Это синтетическая библиотека,
  не запуск Android-установщика поверх реального устройства.
- **119 Python-тестов**: бэкапы/сжатие/выбор компонентов, серверные операции,
  безопасное удаление/поиск/расписания и подготовка окружения.
- **19 наборов Node-проверок**: Codex permissions/status/chat и реальный native
  app-server с loopback synthetic provider; Gemini history/permissions/modes/
  receipts/hooks/socket/frame/thinking/Vertex; Claude adapter/lifecycle/реальный
  CLI с локальным provider; OpenCode chat/settings. Все завершились успешно.
  Нативные тесты используют изолированные homes и фиктивный локальный provider,
  а не аккаунты/платные запросы. Это не доказательство реального Cloud-биллинга.
- Защиты stale request/nonce/thread, native approvals, duplicate sends, отдельные
  процессы и незатронутый посторонний fixture-процесс проверены.
- Копирование/перемещение проверяется на временных fixture-объектах: конфликты,
  самоперенос/вложенность, символические ссылки и частичный результат.
- Финальная release-сборка успешна. Существующие предупреждения Kotlin/UAST/JNA,
  Gradle filesystem-watch и CloseGuard известны; чистый полный Lint не заявлен.

## Проверки разработчика и границы

Разработчик тестировал промежуточные сборки и подтвердил новый Codex-чат,
открытие клавиатуры, сворачивание и возврат к переписке в1.5.33; эта сборка
сохраняет те же runtime assets/native libraries. Также получены подтверждения
улучшения отображения/прокрутки в проверенных Gemini/OpenCode-сценариях.
Это не подтверждает всех размеров шрифта, жестов, устройств, версий CLI и аккаунтов.
Claude/Vertex полностью с реальными аккаунтами не проверены из-за ограничений
доступа/биллинга. Чистая подготовка окружения, разрешения Android, сложные CLI
диалоги, поворот и обновление с живой сессией требуют конкретных device-проверок.

## Совместимость

com.termux и сертификат прежние, code1192 выше stable1.5.3/code1165 и
private1.5.33/code1191. Schema8 сохранена, новые поля optional с defaults;
ServerProfiles/server-agent и форматы архивов прежние. Сброс с1.5.3 не требуется.
Сессии/истории/авторизация не конвертируются в собственную историю чата. Новые
интерфейсы активируются при следующем запуске. Сохраняется прежняя очистка
приватных данных удалённой local-AI функции при переходе с версий до1.5.3;
предупреждение включено в обе локализации update.json и release notes.
Совпадение signer/package и тест библиотеки не гарантируют выживания активного
процесса Android во время установки. Автоматического сброса данных нет.

update.json schema1 формируется из финального APK; APK/size/hash/code и RU/EN
compatibility сверяются перед публикацией и после скачивания release assets.
Сервис анонимной обратной связи не включён. Working sessions/общий SDK/
установленные окружения и серверные службы при сборке не менялись.

Доказательства локальной проверки: .verification/release-v1.6.0/.
Проверка опубликованных файлов фиксируется после загрузки отдельно.
