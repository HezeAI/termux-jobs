# Ошибки и решения — v1.3.2

Общие настройки → Ошибки и решения. Офлайн-библиотека из 129 карточек на русском
и английском. Полный текст ошибки, русское описание и английские термины доступны
через один поиск (несколько слов должны встретиться в карточке).

Системы: Termux, Ubuntu, Debian, Arch Linux, Alpine Linux, Fedora, openSUSE,
Другие Linux; есть режим «Все системы». Это справочные группы, а не установка
дистрибутивов. Наличие раздела не означает полного покрытия всех ошибок системы.
Способ запуска выбирается отдельно: любой, proot, обычный Linux/VM, SSH.
Специфичные для proot советы скрываются при выборе обычного Linux/SSH; при режиме
«любой» остаются видны с условиями применения. ОС за SSH выбирает пользователь.
Приложение не определяет фактическую оболочку по названию вкладки.

Категории: пакеты, файлы, запуск, сеть/SSH, сборки, Git, окружение, Python, Node.js.
Каждая карточка содержит применимость, признаки, предварительную проверку,
возможное решение, ограничения, дату сверки источников и кликабельные ссылки.
Дата означает редакционную проверку материала, не испытание команды на каждой ОС.

Это справочник, не сканер: терминальный вывод, историю, учётные данные и окружения
он не читает. Сеть нужна только если пользователь сам открывает источник браузером.
Встроенная база загружается по требованию; фоновых опросов и сервисов не добавлено.
База будет пополняться с обновлениями APK; отдельной загрузки/автообновления базы пока нет.

Команды в отдельном блоке — для проверки. Копирование не запускает их. «Вставить
в сессию» требует подтверждения замены черновика и затем использует существующий
выбор терминала. Команда попадает в поле ввода без отправки и конечного Enter.
Выбор ОС не гарантирует, что в выбранной вкладке сейчас Bash, а не AI/редактор:
пользователь должен сверить среду перед отправкой. Инструкции исправления,
меняющие пакеты/права/конфигурацию, описаны текстом и не выполняются автоматически.

## Источники и редакционные ограничения

Основные источники — документация Termux/PRoot-Distro, Ubuntu Server, Debian
Reference, руководство pacman на man.archlinux.org, Alpine Handbook, DNF5,
openSUSE, OpenSSH, Git/GitHub, Gradle, Android Developers, Python/PyPA, npm,
curl и Linux man-pages. К восьми карточкам добавлены обсуждения Termux на Reddit
и GitHub как дополнительный контекст, не единственное доказательство.

Прямое чтение некоторых страниц ArchWiki/Fedora блокировалось защитой сайта;
для карточек использованы доступные руководства авторов pacman/DNF5. База не
содержит выдуманных выдержек из закрытых страниц. Старые страницы Termux о
репозиториях используются с историческими оговорками, без устаревших URL зеркал.
Карточки — собственные краткие изложения с условиями, не копии сайтов/чужого кода.
Источник утверждения, подтверждение пользователем и наши тесты приложения —
разные виды доказательств. Все решения на реальных дистрибутивах не выполнялись.

Начальное покрытие ограничено: это не универсальное обещание исправления любой
ошибки и не полная база всех дистрибутивов. Пустой поиск честно сообщает, что
совпадений нет. Встроенный JSON имеет schema/version, ограничение размера,
уникальные ID, обязательные RU/EN-поля и HTTPS-ссылки без credentials.

Дополнительная сверка Reddit и пробелов: [источники и ограничения](ERROR-LIBRARY-SOURCE-REVIEW.md).

## Опыт проекта и совместимость

Добавлены36 случаев разработки Termux Job’s, четыре совпадающие карточки
расширены альтернативными причинами и решениями. Источник «project» явно
отделён от официальной документации сторонних проектов. Для этих записей
показаны свидетельства и статус: подтверждено пользователем, проверено по коду,
рекомендация или проблема открыта. Открытые случаи показывают диагностику
и временные меры. Они не объявлены исправленными.
[Перечень и границы доказательств](PROJECT-TROUBLESHOOTING-CASES.md).

Текущий выпуск v1.3.2/code1085. Библиотека не создаёт новую БД
или пользовательский формат; команды, заметки, пресеты и истории не очищаются.
Новая сборка для отката по просьбе разработчика не создаётся. Ранее переданные
APK остаются без изменений; установка APK с меньшим versionCode обычным
обновлением поверх не поддерживается.
