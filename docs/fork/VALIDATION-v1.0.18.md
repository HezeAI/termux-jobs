## Итоговое поведение

- Общая шестерёнка на всех вкладках: язык + существующий SettingsActivity,
  отдельный глобус убран. Два терминальных векторных переключателя48dp:
  интерактивный ввод/дополнительные клавиши, заливка как у выбранных фильтров.
- Диагностика — долгий тап по сессии, включая базовую Terminal. Сбор независим
  от окна, callbacks Activity/service, обновление открытого окна каждые2с.
- Опциональный extendedDebug в создании/редактировании сессии/пресета; копируется,
  сохраняется в библиотекеv8, отсутствующее поле=false. Применяется при запуске.
  Изменение предпочтения не выдаётся за включение native debug живого процесса.
- Базовые запуск/выход/ошибка подготовки и наблюдаемые error-коды. Расширенный:
  шкала активности; Gemini также native --debug. Флаги других агентов не меняются.
- Пауза/продолжение коллектора, приватный отчёт0600 и копирование его пути,
  уникальный .txt в Download. Закрытие окна сбор не останавливает.
- До2МиБ на профиль,32МиБ суммарно,64 профиля; старые записи вытесняются.
  В памяти сохраняется до смерти app-процесса, явные выгрузки остаются на диске.
- Отмена следующих startup steps: центрированный вектор внутри текущей плашки,
  только supported custom Termux/Ubuntu, не AI/SSH/legacy. Не показывается в popup
  выбора сессий и скрывается на время выбора. Окно со всеми настроенными командами,
  Да/Нет. Только Да пишет прежний marker; текущая команда не останавливается.

## Границы доказательств и минимальная проверка устройства

Отчёт — структурированные события и allowlist кодов, не полный вывод и не HTTP
trace. Не собираются ввод, диалог, URL/токены, env, custom commands или auth files.
TERMINAL_SIGNAL может происходить из цитаты в терминале и не доказывает ошибку
текущего API-запроса. Внутренние сообщения не видны, если native CLI их не вывел.
Расширенные внутренние trace других агентов не подключены. Пауза коллектора
не выключает уже запущенный Gemini --debug и не останавливает процесс.

Robolectric не доказывает работу реальной IME/DPI/жестов/Download-разрешений.
После установки пользователь проверяет оба переключателя и подсветку; создаёт
сессию/пресет с extendedDebug, повторяет Gemini-запрос при закрытом окне,
открывает диагностику, паузу/продолжение, сохраняет .txt в Download и проверяет
путь. Для custom steps: Нет не отменяет, Да отменяет следующие, текущий процесс
продолжает работу; popup не содержит кнопки отмены. Real auth/inference/квота
аккаунта этим APK тестированием не подтверждены.

Агент APK не устанавливал. Пользователь разрешил GitHub-релиз; README/release
notes обновлены, AI Agents явно отмечены experimental. Подробного протокола
всех устройств/агентов/диагностики от пользователя не получено.
Доказательства: .verification/diagnostics-v1.0.18/artifact.json, build-complete.log,
signature.txt, badging.txt, verify-final.py, test-results/.
