# v1.4.27-test — local assistant operating guide

A short bundled Markdown guide is automatically included on each local llama/LiteRT agent turn, including existing chats. It tells the assistant to act on granted rights, check actual access before denying it, verify dependencies/results, preserve exact paths and verify oldest/newest deletion candidates. Filtered lists must not be mistaken for entire directories. Tool JSON must be standalone.

Current settings remain authoritative: chat has no tools, read prohibits changes/commands, full access permits requested changes and deletions where code allows them. Project boundaries and confirmation settings are unchanged. The fixed install-tool confirmation rule remains; allowed full-access commands can use the selected environment's package manager. No packages are installed by this APK change itself.

Compatible update: com.termux, versionCode1133, existing certificate. No data reset, chat/model/preset migration or native change. Instructions add input tokens and may affect timings. They improve guidance, not model capabilities or guaranteed compliance. External CLI agents are unchanged. GitHub publication not authorized.
