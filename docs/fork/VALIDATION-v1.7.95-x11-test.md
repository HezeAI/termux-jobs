# Проверка v1.7.95-x11-test / code1310

Retro XP заменён Kali-inspired по выбранному PNG. Прежняя галочка стиля
только базового Termux XFCE: тёмный GTK/панели, синие папки/выделения,
дракон на вытянутом фоне, тонкая рамка и круглые кнопки.
[Устройство/ресурсы/ограничения](X11-STYLE.md).

## Изменения и границы

- scripts/prepare-x11-style.py: тёмный CSS/GTK2, собственные синие Cairo-иконки,
  PNG-кнопки34×34 с прозрачными углами и сглаженными краями, сплошные XPM-тайлы.
  Прозрачный XPM-холст+PNG — штатная композиция XFWM, без квадратной подложки.
  Menu сохраняет знак >_ и содержимое. Дополнены имена Thunar/Firefox.
- design/x11-kali/wallpaper.png: встроенный image_gen, edit выбранного PNG,
  затем адаптация полотна к портрету без растягивания рисунка. Промпты/метаданные
  рядом; PIN фона и ZIP закреплены сборкой. Отдельной сетевой установки темы нет.
- x11-style.py: тёмный режим панели, шрифт13, заголовок слева, O|HMC вместо
  дополнительных кнопок. Новые свойства включены в прежнюю обратимую запись.
- WorkspaceDesktop.java: описание сменилось с XP на Kali-inspired.
  Название галочки, настройки подключения и прочие элементы UI прежние.
- Плагины/меню пользователя не сбрасываются. Новые панели Applications/Places
  из макета не создаются: это адаптация темы под установленный XFCE, не
  пиксельная копия всех элементов и приложений. Не устанавливает Kali Linux.
- Другие окружения не получают стиль. Native, драйверы, процессы/остановка,
  клавиатура, серверная анимация и агентский запускатель не менялись.

## Совместимость и следующая проверка

Схема данных прежняя, без очистки. code1309→1310, пакет и сертификат сохранены.
Если стиль уже включён, известные ресурсы XP обновятся при следующем старте;
неизвестные ручные изменения ресурсов не перезаписываются. Выключение возвращает
настройки до первого применения стиля, сохраняя отличающиеся ручные правки.

На телефоне: остановить Termux XFCE, оставить/включить галочку и запустить.
Проверить цвета/пропорции окон, рамку на разных размерах, hover/pressed/focus
кнопок, Menu, значки и растягивание. Проверить портрет/альбомную ориентацию:
фон масштабируется пропорционально с возможной обрезкой краёв. Программы со
своим оформлением могут отличаться. Проверить выключение/возврат и чистый bootstrap.
GUI/Android-обновление этой версии не считаются проверенными по тестам кода.
