# v1.6.0 — чаты AI Agents и удобная работа с файлами

Изменения относительно последнего публичного выпуска **v1.5.3**.
Разработчик форка — HezeAI; Codex помогает с разработкой и проверками.

## Чаты агентов внутри приложения

- Codex, Gemini CLI, Claude Code и OpenCode получили общий Android-интерфейс
  переписки: сообщения, раскрываемые рассуждения и действия, поддержанные вопросы
  и подтверждения. Терминальный интерфейс доступен отдельно по кнопке робота.
- Существующие нативные истории используются повторно: новый интерфейс не
  создаёт собственную замену истории CLI и не переносит диалоги между агентами.
- В терминальном окне сохранены крупные стрелки, дополнительные клавиши и Enter.
  «Свернуть» скрывает окно; «Вернуться в чат [агент]» возвращает управление
  способом, поддержанным конкретным агентом. В чате есть пояснение и кнопка возврата.
- Исправлено открытие клавиатуры в терминальном окне с mouse-tracking TUI.
- Устранены подтверждённые разработчиком мерцания/проблемы прокрутки в проверенных
  сценариях OpenCode/Gemini. Android-чат отделён от перерисовки полного TUI;
  не заявляется исправление каждого сценария и каждой версии внешнего CLI.
- Плашки моделей/режимов стандартизированы. Выбор модели, рассуждения и прав
  появляется там, где его поддерживает backend; набор возможностей различается.
  Для Codex выбор модели/рассуждения отмечается «следующий ответ» до принятия
  следующего запроса. Корректно показан недельный лимит при единственном окне Pro;
  расход токенов не выдаётся за оставшуюся квоту. Обновление статуса не запускает
  отдельный запрос к модели.
- Неподдержанный интерактивный запрос не получает автоматического разрешения.
  Подтверждения привязаны к актуальным запросу/чату; права остаются нативными.
  Работа только в рамках проекта не является отдельным контейнером ОС.
- Shell-поле при включённом интерактивном вводе выполняет пользовательскую команду
  напрямую, без модели. Это права пользователя окружения; ограничения агента не
  являются песочницей для такой команды. Проверьте её перед отправкой.

## Подготовка среды и Gemini Vertex AI

- Проверка среды запуска в редакторах сессий/пресетов показывает наличие нужных
  компонентов. Перед новым запуском проверка повторяется; недостающие компоненты
  предлагается установить с подтверждением. Установленные инструменты и
  существующая Ubuntu не заменяются целиком. Часть зависимостей общая для Ubuntu.
- Для новых Codex-профилей используется Ubuntu без лишнего выбора среды;
  совместимость прежних профилей Termux-Codex сохранена.
- Gemini: API key и Vertex AI; Google-вход для бесплатного режима пока недоступен
  в интерфейсе. Vertex предлагает компоненты/Google Cloud ADC, затем ввод ID
  облачного проекта и региона. Эти параметры переиспользуются в следующих
  подключениях; сохранение подключения не создаёт пресет автоматически.
- ID Cloud-проекта — не рабочий каталог. API, IAM, биллинг и доступ к модели
  настраиваются в Google Cloud; приложение не создаёт их автоматически.

## Файловый менеджер и серверы

- Долгий тап выделяет файл/папку; обычный тап продолжает открывать папки и меню
  файлов. Галочки позволяют менять выделение независимо от переходов.
- Выделение сохраняется при переходе между папками в том же окружении/профиле.
  «× N» снимает его. «Выбрать всё» учитывает текущий поиск и фильтр;
  до50 объектов в менеджере сессии, до500 — в серверном списке.
- В менеджере сессии векторная стрелка ведёт назад, кнопка назначения предлагает
  «Копировать сюда» / «Переместить сюда». Между разными окружениями этот режим
  не переносит объекты. Существующие файлы не заменяются автоматически;
  конфликты имён требуют выбора нового имени с подтверждением.
- Сервер использует общее выделение для скачивания, перемещения и удаления;
  переходы по папкам отделены от выбора. Подготовленное перемещение можно отменить.
  Удаление выбранных объектов из разных исходных папок сохраняет прежнюю проверку
  путей и подтверждение. Повторная опасная операция сама не запускается.
- Сохранены прежние элементы подключения: Подключиться/Отключиться обозначает
  соединения приложения, а «Автообновление
  данных сервера» — опрос. Отключение не останавливает сервер, удалённые задачи
  или независимые SSH-сессии. Обычный способ подключения SSH сохранён.
- Пакетная операция может завершиться частично: уже выполненные действия не
  откатываются автоматически. Переходы/выделение сами файлы не изменяют.

## Совместимость и обновление

- **Общий сброс данных не нужен.** С v1.5.3 сохраняются команды, заметки, пресеты,
  профили серверов, внешние истории/авторизация агентов и окружения. Библиотека
  schema8, серверное хранилище v1 и формат бэкапов не меняются; новые поля необязательны.
- **com.termux, прежний сертификат, Android8.0+/ARM64, versionCode1192** — выше
  публичной v1.5.3 и частной v1.5.33. Доступно обновление поверх и через
  «Шестерёнка → Проверить обновление»; в релизе есть update.json.
- Уже работающие сессии не переключаются принудительно. Чтобы получить новый чат,
  после завершения важных задач заново запустите ту же историю. Важные файлы
  перед обновлением рекомендуется сохранить: установка не гарантирует выживание
  работающего процесса Android. Данные приложения автоматически не очищаются.
- При переходе с версий **до v1.5.3** сохраняется прежнее предупреждение: удалённая
  локальная AI-функция очищает только свои приватные модели/чаты/инструкции/
  диагностику и пропускает старые локальные профили. Сохраните нужное заранее.
  Внешние оригиналы моделей и proot-дистрибутивы автоматически не удаляются.
- Локальные ИИ не возвращены. Анонимная отправка обращений на сервер не добавлена;
  сообщения и данные пользователей через такой сервис не собираются.

## Проверки и ограничения

Разработчик проверял промежуточные сборки и подтвердил работу нового Codex-чата,
клавиатуры, сворачивания и возврата в переписку. Автоматические проверки и
ограничения приведены в отчёте: это не доказательство всех сценариев на всех устройствах.
Claude и Vertex не прошли полный цикл с реальным аккаунтом из-за ограничений
доступа/биллинга; для Claude есть проверки настоящего CLI с локальным тестовым
провайдером. Установленные CLI, поддержка модели и права аккаунта могут отличаться.
Некоторые сложные/секретные интерактивные запросы требуют штатного терминала.
Полный чистый Lint не заявляется: прежние ограничения инструментов описаны в отчёте.
