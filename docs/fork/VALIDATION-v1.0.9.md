## Ревью и логическая инспекция

Проверены двойные model-запросы, закрытие во время busy/exit/relaunch, readback-ошибка,
ошибка spawn, 5-секундный таймаут выхода frontend и сохранение профиля только по
подтверждённому результату. SIGTERM направлен только объекту child mini текущего run,
сервер не перезапускается при нормальной смене модели; чужие процессы не ищутся.
При failed spawn безопасно закрываются только owned процессы. Насильственный SIGKILL
не добавлен. Эти отдельные ошибочные пути логически просмотрены; аппаратно не проверены.
Codex shell/RPC/status/model selection не менялись в этой правке. Формат v8 и Linux
пакеты не менялись; пресеты — переименование UI, не миграция или снимок Bash.
