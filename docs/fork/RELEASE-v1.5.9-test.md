# v1.5.9-test — smaller local-AI service prompts and compact chat pills

Private ARM64 test APK, com.termux, versionCode1146, Android8+. Existing certificate and package; no history/settings/library migration, automatic resets or model-file edits. Not published to GitHub.

Standard/brief built-in behavior now distinguishes writing/saving an installation guide from actually installing software, follows the latest user's language despite English tool errors, and avoids treating one failed command as proof that all file access is denied. The separate behavior file is no longer required to get these rules: select built-in Standard or Brief. Tools only still excludes additional behavior. User-imported behavior text is preserved and not silently rewritten.

Default behavior was shortened; permissions/environment text is shared and describes active settings. Qwen tool descriptions reuse concise descriptions already used by LiteRT; names, JSON schemas, argument types, required fields, bounds/enums, additionalProperties and permission-dependent availability remain unchanged. Native Qwen and SDK function-call formats/parsers are retained. LiteRT's protocol block no longer repeats media limitations already appended from the actual selected model. Legacy llama.cpp JSON mode also benefits from the shorter default behavior and concise schema descriptions in brief/tools-only mode. Arbitrary uploaded model capability/obedience is not guaranteed.

Current-turn task evidence, full original history, summaries, progress tracking, approval checks and video sub-analysis remain. No extra inference, model load/unload, installation, environment fallback or tool execution was added. Context and output limits remain unchanged. Size comparisons use synthetic identical settings and the existing estimate, not exact tokenization or a hardware speed benchmark; real diagnostic reports remain the follow-up check.

Tool action, completed-step and Context and history cards now use small rounded left-aligned pills. Short status remains visible; exact paths/results/errors are available by tapping. Approval Yes/No cards and file-choice controls remain prominent. Shared local-chat presentation applies to llama.cpp and LiteRT. Existing saved records are rendered through the same views without deleting their content.
