- Все Python fixtures:146 тестов;38 backup-тестов входят в это число.
  Покрыты PAX-пути, BusyBox, systemd-имена, метаданные Void, .l2s Arch,
  отдельное восстановление, происхождение удаляемой копии, смена inode,

  proot-distro отказывает удалению при shared session lock и удаляет после
  освобождения блокировки. Это fixture, не проверка Android-экрана удаления.
- Release-сборка успешна. Проверены runtime DEX-зависимости, ZIP/CRC,
  package/version/minSDK/ABI, отсутствие debug-флага, v2 подпись и SHA-256.
- Относительно1.6.18-test неизменны native libraries и все assets, кроме

## Проверки разработчика на устройстве

В ходе проверочных сборок перед выпуском разработчик подтвердил для Debian,
Alpine, Fedora, openSUSE, Void Linux и Arch Linux ARM: каталог пакетов,
установку и запуск tree, полный бэкап, отдельное восстановление, сохранение
тестового файла/пакета, файловый менеджер и повторный запуск. Исходные Debian
и Void также повторно запускались. После последней правки предупреждение
.l2s у восстановленного Arch не повторялось.

Эти проверки не подтверждают все возможные пакеты и архивы. Новый экран удаления
нужно проверить на ненужной восстановленной копии: закрыть её сессии, выбрать
в меню бэкапа, подтвердить удаление и проверить сохранность исходного окружения
и архива. Старые копии без подтверждения происхождения удаление не предлагают.
По отдельному разрешению разработчика штатной командой proot-distro удалена
старая незавершённая копия Debian jobs-6a650d598a1d без manifest.json. Проверено
исчезновение только её каталога; другие записи окружений сохранены. Это отдельная
ручная операция, а не проверка новой кнопки приложения.

Полный чистый Lint, любые чужие/выборочные архивы, перенос на любое устройство,
согласованность живых баз и все Android-жесты/разрешения не заявляются проверенными.

## Ревью и логическая инспекция

Прослежены выбор/установка/проверка/вход по конкретному alias, файловый менеджер,
пакетные операции после выхода из гостя, отдельное восстановление, подтверждение
удаления, отказ занятой копии и частичная ошибка. Удаление вызывает только
штатный remove конкретного jobs-имени, без force/kill/rmtree fallback. Исходные
окружения/архивы не являются целями. Для нового восстановления сохраняется
приватная запись попытки; для старого нужен отчёт успешного восстановления.
Имена сами по себе не подтверждают происхождение. Shared UID не является
изоляцией от произвольной программы, уже имеющей права Termux.
