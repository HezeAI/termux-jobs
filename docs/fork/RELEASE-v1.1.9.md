# v1.1.9 — локальная сборка, не опубликована

Экран «Сервер + Agent» стал компактнее: три карточки CPU / RAM / Диск
с полосами заполнения вместо текстового блока и графика. Разделы проектов,
задач, файлов и служб подняты под карточки.

- Карточки и их цифры/полосы обновляются на месте. При отсутствии измерения
  показывается «—», а не нулевая загрузка. Векторные иконки и адаптивный текст.
- Переключение разделов меняет только блок под вкладками, сохраняя мониторинг,
  навигацию и ScrollView. Открытие папки заменяет только строки списка.
- На время обновления содержимого сохраняется положение страницы и подавляется
  автоматический переход к элементу с фокусом. Обычные свайпы/клавиатурная
  навигация доступны; новый жест отменяет отложенное восстановление. Если новый
  список короче, позиция ограничивается его реальной высотой. Пока асинхронно
  загружается новый раздел, прежняя высота временно удерживается.
- Рядом с «Подключить / обновить» — квадратная 48dp кнопка с центрированным
  вектором терминала, тем же, что в основной навигации. SSH-действие прежнее.
- Описание «!» начинается с «Устанавливается…»; убраны вступление
  «наша программа, не ИИ» и описание графиков/истории метрик. Права, установка,
  ограничения задач и удаление остаются объяснены на RU/EN.

- Внизу списка серверов объяснено: профиль — настройки подключения на телефоне,
  а агент/задачи/файлы живут на сервере и не удаляются вместе с профилем.

## Совместимость

com.termux, прежний сертификат, versionCode1066 >1065; Android7+/ARM64,
min24/target28 прежние. Библиотекаv8, серверные профили, пресеты, AI-чаты,
данные и программы окружений не мигрируют/не сбрасываются.
Server agent/native/SSH/SFTP/player/editor unchanged; переустановка агента не нужна.
Опрос сервера прежний: примерно10с в разделе,30с на других вкладках,
пауза в фоне приложения; сам агент собирает снимки каждые30с. Удалён только
график в Android UI, данные/работа агента не меняются.

APK устанавливает пользователь, GitHub пока не обновляется. Проверки и
непроверенные сценарии: [VALIDATION-v1.1.9.md](VALIDATION-v1.1.9.md).
