# v1.5.0 — сессии, истории и работа с серверными файлами

## Сессии и истории

При закрытии несохранённой сессии появились галочка **«Сохранить историю»**
и действия **«Закрыть» / «Добавить в пресеты и закрыть»**. История и пресет
запуска — разные вещи. Сохранённый текст не восстанавливает выполнявшийся
процесс Bash, SSH или программу после его остановки. Собственные чаты
CLI-агентов не удаляются снятием этой галочки.

В общих настройках — **«Истории чатов»**: список, просмотр в прокручиваемом
окне и удаление с подтверждением для поддерживаемых чатов Codex. Используется
штатный API Codex в выбранном Termux/Ubuntu, без подмены удаления архивированием.
Если установленная версия CLI не поддерживает API, приложение сообщает об этом.
Перед удалением нужно закрыть использующие чат сессии, включая внешние окна.
Проекты, авторизация и инструменты не удаляются; привязка пресетов к удалённому
чату очищается только после успешного удаления.

## Права AI Agents

Обновлены настройки и пояснения прав, подтверждений и ограничения внешних
путей в зависимости от возможностей агента. Это штатные режимы конкретного
CLI и правила инструментов, а не новый универсальный системный sandbox.
Рабочая папка сама по себе не ограничивает доступ. Для неподдерживаемых
вариантов ограничение помечено недоступным. Изменения настроек применяются
при следующем запуске агента; активные процессы не перенастраиваются скрыто.
Существующие настройки сохраняются.

## Сервер: выделение, скачивание и перемещение

Долгое нажатие на файл или папку включает выделение. Вместо широкой кнопки
отправки — две равные панели с отступом: **↑** загружает файлы на сервер,
**↓** открывает действия с серверными файлами: **«Скачать» / «Переместить» /
«Выбрать всё» / «Снять выделение»**. До 500 выбранных записей текущей папки. Без предварительного
выделения правая панель предлагает «Скачать с сервера» / «Переместить по серверу»
и окно выбора объектов текущего каталога. Стрелка перехода к родительской
папке направлена влево; действие не изменилось.

- Скачивание нескольких файлов и папок, включая вложенность и пустые папки.
- Выбор места через встроенный менеджер: память устройства, Termux или доступное
  proot-окружение. При необходимости запрашивается доступ к общей памяти.
- Быстрое скачивание в Download остаётся доступно в меню отдельного файла.
- До **10 ГиБ на файл**, 20 000 просканированных записей, глубина 64,
  суммарно до 256 ГиБ; соединение ограничено шестью часами.
- Каждый набор сохраняется в отдельную папку `download-…`. Исходные имена
  сохраняются; существующие пользовательские файлы не заменяются. Выбор
  «заменить всё» не требуется: слияние с существующим деревом не выполняется.
- Ссылки и специальные файлы пропускаются. Путь и тип проверяются перед чтением;
  это не защита от всех возможных гонок на недоверенном изменяющемся сервере.
- Передача использует ограниченное окно запросов SFTP по отдельному SSH-соединению,
  без запуска shell-команд для имён серверных файлов. Показываются текущий файл,
  общий объём, скорость и оценка оставшегося времени.
- Остановка закрывает только принадлежащее передаче соединение. Завершённые
  файлы остаются; текущий неполный временный файл очищается, если доступ позволяет.
  При сбое во время финализации проверьте папку результата. Возобновления
  прерванного набора после завершения приложения пока нет.

Для перемещения выберите **«Переместить»**, откройте другую папку того же
сервера и нажмите изменившуюся кнопку **«Переместить сюда»**. Будет подтверждение
с количеством и путём назначения; можно отменить подготовленное перемещение.
Совпадения имён, перемещение внутрь самого себя и неподдерживаемые типы
отклоняются. Между разными файловыми системами операция может быть недоступна;
автоматическая схема «скопировать и удалить» не выполняется. Набор не атомарен:
если поздний шаг завершился ошибкой, уже перемещённые объекты останутся в новом
месте. Службы, терминалы и агент при этом не останавливаются.

## Локальные модели

**Локальные модели временно недоступны — идёт тестирование.** Пункт виден,
но неактивен в создании сессий и пресетов. Запуск локальных пресетов из прежних
тестовых сборок тоже заблокирован с пояснением. Модели, история, окружения и
пресеты не удаляются. Закрыто только экспериментальное направление локального
ИИ; Codex, Claude Code, Gemini CLI и OpenCode остаются доступны.

## Обновление и совместимость

- Android 8.0+/API26, ARM64; пакет `com.termux`, прежний сертификат подписи.
- Публичный `versionCode 1137` выше v1.3.3/code1086 и тестовой code1136.
- **Очистка данных не требуется.** Библиотека остаётся формата v8; новые поля
  необязательны. Нет автоматического удаления чатов, проектов или окружений.
- В релиз включён `update.json`: обновление доступно через приложение.
- Личная тестовая v1.5.1-test/code1138 новее этой публичной. Обновлятор не
  предлагает понизить её до code1137; для будущего обновления потребуется
  выпуск с большим кодом. Данные не нужно очищать для обхода этого правила.
- Перед обновлением завершите важные задачи: Android может перезапустить
  процессы приложения при установке. История не является снимком процесса.

## English

v1.5.0 separates history retention from launch presets when closing an unsaved
session; adds supported Codex conversation viewing and confirmed deletion;
clarifies native AI-agent permissions and path restrictions where supported.
Server files support long-press multi-selection, recursive SFTP download into
a chosen Termux/proot/device-storage folder (10 GiB per file), progress and
cancellation. A separate destination folder avoids overwriting existing files.
Same-server Move / Move here is confirmed and nonoverwriting; cross-filesystem
moves can fail, and a partially completed batch is not rolled back automatically.

Local models are temporarily disabled while testing continues, including
existing-preset startup. Experimental data is retained; external CLI agents
remain available. Android8+/ARM64, same package/signature, stable code1137;
in-app update metadata included. **No data reset required.** Private test code1138
is newer and will not be downgraded by the updater. Finish important tasks before
updating; saved transcripts do not restore stopped processes. Codex history APIs
and device-dependent transfer/storage/UI behavior require compatible installations.
