# 2.1.5-test16 /1511 — карта изменений

1. Причина подскролла найдена в composerViewport: handlesComposer становится
false при открытом терминале, и нижний отступ видимого фонового чата обнулялся.
Теперь используется keepsChatPresentation, как при построении composer.
Не добавлена компенсирующая прокрутка после перехода. При переносе общего
виджета дополнительных клавиш сохраняется высота его места в чате.
Прежний механизм pre-draw привязки к концу/якорю истории сохранён.

2. Промежуток плюс/заметки4→8dp. Надписи11→12.65sp(+15%).
Терминальные команды/алиасы/заметки получают равные доли доступной строки.
После них сохранён промежуток44.5+8dp перед отправкой: граница текста заметок
совпадает с концом модельного блока. Отправка и ComposerLimits не передвинуты.

3. Общие настройки: заголовки17.6sp/bold, основной текст16.4sp,
пояснения12.8sp — текущие физические sp бокового меню с масштабом0.8.
Оба верхних названия — «Общие настройки». Обработчики сохранены.

4. Компактный chooser до300dp с центральным заголовком и строками агентов.
Кнопка возврата сохраняет исходный объект формы и введённые значения.
Обратное перелистывание скрывает форму после движения вправо.
Обе кнопки имеют овальную обводку, светлый круг и тёмную векторную стрелку.
Стрелки центрированы относительно текста. Папка находится вне EditText,
в соседней44dp области с промежутком8dp, без постоянной рамки/заливки.

5. По дополнению пользователя Enter добавлен отдельной верхней строкой
в общей панели, в колонке PgUp. Исходные строки сохраняются.
Пустые места верхней строки невидимы/неактивны. Используется штатный KEYCODE_ENTER.
При уже имеющемся Enter дубль не добавляется; раскладки без PgUp не изменяются.
Новая строка учитывается в количестве строк и высоте панели.
