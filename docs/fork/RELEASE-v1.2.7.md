# v1.2.7 — локальная проверка выбора SSH-ключа

В профиле Сервер + Agent рядом с путём приватного ключа — кнопка папки.
Выбор через файловый менеджер: Termux, Ubuntu или память устройства.
Ключ из внешнего окружения/общей памяти копируется только после согласия,
в приватный уникальный файл600. Оригинал и существующие ключи не меняются.
Есть скрытое поле «Passphrase (если требуется)» с Android Keystore и явным
удалением сохранённого значения. RU/EN. Пароль сервера и passphrase разделены.

Code1078, пакет/сертификат сохранены, формат профилейJSON прежний, сброса нет.
Обновлён резерв без библиотеки и нового SSH: v1.2.8/code1079 на базе v1.2.2.
Первая установка — основная1078; резерв1079 только при необходимости возврата.
Старый резерв1077 поверх1078 не установится. Следующий APK после1079 должен
иметь code>1079. Пользовательские данные автоматически не очищаются.
Секреты Keystore могут потребовать повторного ввода после переноса установки.
Интерактивный SSH-терминал запрашивает passphrase самостоятельно.
