Установлен xfce4-session4.20.4-1. Исходники соответствующего тега:

клиентов либо таймаута. Причина срабатывания регистрации пока не подтверждена.

Дополнительно проверены наличие iceauth/authority (без чтения ключей), порядок
Failsafe, наличие SESSION_MANAGER у клиентов, типы двух процессов D-Bus.
Само наличие native и proot демонов не доказывает смешения систем/шин.
Прямой EXTERNAL handshake по адресу из окружения, отображённому из другой Ubuntu,
отклонил гостевой0 и принял kernelUID10620. Это не доказательство причины:
изолированная новая шина в среде разработки с EXTERNAL успешно отвечает и с UID0.
Проба uid-подстановки применялась только к одноразовому dbus-send из репозитория,
не дала успешного GetState/ListClients и не вошла в приложение. UID работающих
процессов, авторизация сервера, системные библиотеки и пользовательские файлы
не изменялись. Пробы остаются в ignored .verification/xfce-startup.

- Только локальный Unix D-Bus текущего запуска: два AUTH EXTERNAL запроса,
  результат ok/rejected/unavailable; UID числовой, ответы/cookie/GUID не записываются.
  TCP не используется; политика авторизации не меняется.
- Счётчики/сумма/max/ошибки существующих X11/D-Bus проверок, без аргументов/ответов.
- Категории ошибок регистрации сессии, ICE, D-Bus; прежние GPU/WM/фон/панель сохранены.

Выход query-метрик не чаще5с и при завершении. Сбор использует цикл запуска и
заканчивается готовностью либо180-секундным таймаутом. Нового вечного процесса нет.
Java сохраняет первый/последний снимок каждого ключа (максимум40), отдельно от48
этапов/ошибок: данные процессов не вытесняют итоговую готовность.
Недоступные /proc/шина не обходятся; успешный старт не требует успеха диагностики.
Сэмплинг может немного влиять на время; это не измерение без накладных расходов.

## Кнопки меню сессий

В верхней плашке выбранной сессии и каждой строке раскрытого списка размещён
векторный значок настройки20dp, кнопка40dp. Внешняя ширина списка340dp (с прежним
ограничением экрана), высота верхней плашки48dp и прежний контракт строк
WRAP_CONTENT/минимум48dp/14sp/max3lines сохранены. Подпись резервирует место справа
и может раньше обрезаться; для очень длинных названий нужна визуальная проверка.
Кнопка отмены команд запуска остаётся отдельной и сдвинута внутри той же плашки,
чтобы не пересекаться с шестерёнкой. При отсутствии привязанного профиля меню
недоступно до появления профиля. Создать новую сессию остаётся отдельной строкой.
Долгие тапы на селекторе/строках больше не открывают меню. Действия и их
подтверждения не менялись. Меню другой строки открывается без смены активной сессии.
Раскладку, касания и обрезание длинных подписей нужно проверить на телефоне.
