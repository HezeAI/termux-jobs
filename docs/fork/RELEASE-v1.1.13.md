# Локальная v1.1.13 — файлы и задачи сервера (тестирование)

Звёздочка в навигации файлов открывает избранные папки и файлы выбранного
сервера. Папку сначала откройте, затем выберите «Добавить текущую папку».
Для файла пункт «В избранное» находится в его меню. Текущая избранная папка
подсвечивает звёздочку. Долгий тап по записи в избранном позволяет убрать её;
файлы на сервере не удаляются. До100 папок и100 файлов на профиль. Пути хранятся
локально, не отслеживают переименование/удаление; устаревший путь даст ошибку
при открытии. У файла из избранного до передачи размер может быть неизвестен.
На узком экране панель навигации с шестью значками прокручивается горизонтально.

Лупа ищет буквальное вхождение имени без учёта регистра в текущем каталоге
и подпапках. Поиск не читает содержимое файлов и намеренно не следует по ссылкам
или другим файловым системам. Пределы:8сек/20000записей/500результатов/64уровня.
Пропуски/неполный результат показаны; сузьте каталог/запрос. Порядок обхода зависит
от файловой системы. Закрытие окна отменяет собственный SSH-канал; Python-поиск
ограничен по времени. Нужен Python3 на сервере, установка/обновление агента не нужны.

В «Задачах» добавлены закреплённые команды: название, каталог, команда Bash,
до50 на профиль. Создание/изменение/удаление через отдельное окно, запуск всегда
после просмотра сервера/команды и подтверждения. Из журнала задачи можно закрепить
её команду. Каждое выполнение создаёт отдельную запись; закрепление ничего не
запускает. Тексты команд хранятся локально открытым текстом: не включайте секреты.
Изменение адреса существующего профиля сохраняет избранное/команды; проверьте
пути и команду для нового адреса перед подтверждением запуска.

Завершённые/ошибочные/остановленные задачи можно убрать из списка вместе с
журналом с подтверждением. Созданные командой файлы сохраняются. Активные задачи
удалять нельзя; неподконтрольную запись можно забыть с отдельным предупреждением,
процесс это не останавливает. Действия обновляются при смене статуса в открытом
журнале. Показаны длительность и exitCode, когда агент их предоставил.

К существующему прогрессу отправки добавлены средняя скорость текущего файла
и примерное оставшееся время (при известном размере). Скачивание получило отдельное
окно прогресса/отмены с той же оценкой. Отмена закрывает только принадлежащее передаче
SSH-соединение; мониторинг/терминалы не закрываются. До2ГБ/файл, скачивание до10мин,
без возобновления. При неизвестном размере нет процента/оценки времени; меняющийся
файл может сделать оценку неточной. Фоновой Android-службы передачи не добавлено:
не закрывайте приложение. Неполный собственный файл удаляется; ошибка удаления
показывает путь, удаление чужих файлов не выполняется.

В меню сервера добавлена диагностика: доступность TCP-порта, наличие доверенного
ключа, проверка SSH/Python и присутствия файла агента. Проверка не запускает агент
или задачи. Успешный TCP не означает успешную авторизацию. Ошибки SSH/ключа/авторизации/
Python могут быть неразличимы — интерфейс это указывает, raw stderr/секреты не выводятся.

Защита редактора уже была реализована и сохранена: предупреждение при отмене
несохранённого текста, отказ от перезаписи изменившегося файла, сохранение текста
в открытом окне при ошибке. Проверки скриптов/редактора пройдены локально;
живой SSH/Android требуют ручного тестирования. Черновики на диск не сохраняются,
аварийное завершение процесса не покрывается; это не гарантия восстановления черновика.

Пакет/сертификат прежние, code1070 >1069, библиотекаv8 без сброса/миграции.
В профилиv1 добавлены необязательные поля; прежние профили читаются с пустыми
избранным/командами. Старые версии приложения не знают эти поля и при перезаписи
профилей могут их потерять. Экспорт библиотеки по-прежнему не включает профили
серверов. Агент/native/media/AI/расписания не изменены, переустановка агента не нужна.
GitHub не опубликован; пользователь устанавливает APK вручную.
