## Ревью и логическая инспекция

Обзор размеров не является планом удаления. После выбора строится свежий план;
корень выводится из фиксированных путей приложения, а имена/identity проверяются.
При выполнении сверяется весь снимок до первого удаления группы. Файлы и ссылки
удаляются через directory fd без следования ссылкам, пустые выбранные папки —
снизу вверх; корень HOME/workspace-sessions сохраняется. Только сама ссылка,
не её /sdcard-цель. Новые файлы за пределами снимка не удаляются. Применимы
прежние блокировки контейнеров/APT; /home и /root берут lock одного alias.
UI дважды проверяет занятость среды/каждого ID истории; пользовательские процессы
не останавливаются. При отмене частично выполненное удаление не откатывается.

Коллекция WorkspaceStore сравнивается с первоначальным снимком перед удалением
выбранных id. Базовый Terminal и несохранённые сессии не удаляются как пресеты,
работающий выбранный пресет блокируется. Целиком workspace-v1.json не удаляется;
schema8 остаётся прежней. AtomicFile/очередь сохранения прежние; сообщение об
успехе появляется только после finishWrite. Ошибку записи сообщает существующий
обработчик библиотеки; автоочистки и скрытой отправки данных нет.

Полные PREFIX и системные деревья доступны **только для просмотра**. Запрос
prepare-home с системным scope отвергается: удалять runtime во время исполнения
нельзя. Полный сброс исходного окружения/PREFIX не реализован. Ограничения,
60000 записей/8MiB плана, приблизительность размеров/перекрытие разделов и
отсутствие sandbox против процесса с тем же UID описаны в STORAGE-CLEANUP.md.

Реальные пользовательские данные не очищались при разработке. Размеры/жесты,
клавиатура, прокрутка и Android-разрешения не подтверждены UI-моками.
Минимум: открыть очистку и состав каждого раздела, проверить RU/EN/прокрутку,
один раз удалить ненужную тестовую папку HOME, одну тестовую команду/заметку,
проверить сохранность соседних записей и блокировку работающего пресета.
Проверить обязательную новую галочку, Отмену/outside taps, а также единственный
пункт удаления восстановленных окружений. Системный PREFIX не должен иметь
выбора удаления. Собственные разговоры других CLI не выдаются за каталог Codex.
