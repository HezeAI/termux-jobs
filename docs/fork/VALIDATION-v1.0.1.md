## Логика и границы

Каталог читается отдельным ограниченным процессом, вне UI-потока.
Команды из фиксированных операций и проверенных имён выполняются только после
подтверждения. Выбранная сессия проверяется на running, прежний handle и среду;
свободный Bash пользователь определяет сам, предупреждение показано.
Приложение не распознаёт автоматически текущую программу и не очищает её ввод.
При выборе новой вкладки не переносится команда Codex или состояние исходного
профиля; лимит восемь вкладок учитывает существующий путь запуска.
Нет -y, purge, autoremove, отключения APT locks или принудительной остановки
посторонних процессов. Чтение закрывается только для собственных процессов.
