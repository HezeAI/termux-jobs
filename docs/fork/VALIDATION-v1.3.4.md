# Локальная проверка v1.3.4

## Изменения и инспекция

Поиск вызывает renderLibraryResults, меняющий только дочерние карточки двух
существующих панелей. Query/категории/избранное используют прежние условия.
Полный renderContent сохраняется для изменения фильтров и навигации.

close() браузеров идемпотентен, закрытие диалога ведёт туда же. Закрывается
только существующий принадлежащий браузеру файловый helper и worker; пользовательские
терминалы и общий SSH-мониторинг не затрагиваются. Очищаются каталоги/выбор файлов,
callback удаляет браузер из реестра контроллера или серверной вкладки. Владелец
обходит копию реестра при закрытии нескольких окон, чтобы избежать изменения
коллекции во время обхода. Асинхронные ответы проверяют прежние closed/generation.
