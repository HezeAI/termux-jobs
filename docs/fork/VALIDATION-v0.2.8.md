Проверка после установки пользователем:

1. Обновить поверх основной версии. В настройках SSH выбрать «По паролю».
2. Ввести пароль, оставить «Запомнить пароль» выключенным, подключиться. У первого нового сервера сверить отпечаток в отдельном окне; «Доверять» только после сверки.
3. Убедиться, что команды исполняются после успешного входа и поле ввода пароля не выводится в терминале.
4. Включить запоминание, повторно ввести пароль и сохранить. Закрыть/перезапустить приложение, подключиться к профилю снова. Это проверит настоящий Android Keystore и повторный вход.
5. Неверный пароль должен завершить подключение; команды не должны исполниться.
6. В режиме ключа выбрать ~/.ssh/id_ed25519 либо другой доступный файл; ключ не копируется. Парольная фраза ключа при необходимости вводится в терминале.

Ограничения: реальный сервер, UI подтверждения host key и реальное Android Keystore сохранение/повторное чтение в установленном приложении ещё не проверены. Password authentication — без keyboard-interactive/OTP; для таких серверов используйте «Автоматически». После удаления приложения или переноса Keystore-ключ не восстанавливается обычным файловым бэкапом — пароль нужно ввести заново.
