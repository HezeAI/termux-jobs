## Ревью данных и границ

Первый запуск намеренно удаляет только приватные `files/local-ai`,
`cache/local-ai` и local diagnostics preferences. No-follow обход проверен
временными fixtures с внешними и корневыми symlink, повторная очистка безопасна.
Старые localAi-профили пропускаются без превращения в Bash. HOME/PREFIX,
другие библиотеки, внешняя авторизация/истории и дистрибутивы автоматически
не удаляются. Нужные приватные модели/чаты нужно экспортировать заранее.
Предупреждение есть в RU/EN release notes и update highlights/compatibility.
Общая очистка команд/пресетов для обновления не требуется.

Server delete: preflight всей выбранной группы, no-follow/descriptor-relative
операции, проверки изменившихся объектов, запрет перехода на другой filesystem
и специальных файлов. Остановка/ошибка может оставить частичный результат,
автоповтора/отката нет. Профиль/каталог проверяются перед подтверждённым запуском.
SSH pinning и существующие границы SFTP/медиаплеера не изменены.

Фоновые upload/download сохраняют те же owned-операции при переключении внутри
приложения; окна возвращаются из карточек. Закрытие Activity/процесса не является
поддержанным сценарием продолжения. Индикаторы не пересоздают весь терминал;
один pending frame, скрытые views не продолжают анимацию.

Backup cache ограничен по объёму/возрасту, без Activity/таймера/сервиса/БД и без
содержимого файлов; restore/import сбрасывает оценки. Cache hit не продлевает
срок. Refresh свежий; создание всегда читает/проверяет источники заново.
Закрытие останавливает только свой scan-worker. Новые формы/кеш/прогресс/
поздние callbacks и gzip/pigz2/4 покрыты адресными тестами предыдущей итерации,
включёнными в текущий полный прогон. Реальная установка pigz не выполнялась.

Логически прослежены initial scan/cache hit/refresh/close/error/late callback,
подтверждение/частичная ошибка удаления, фон/возврат/отмена передачи,
активность/resize/scroll/hide, миграция/пропуск старых локальных профилей.
Это не обещание отсутствия всех возможных регрессий.

## Проверка на устройстве

Разработчик проверял промежуточные сборки и сообщал об улучшениях отображения
и нагрузки; это не доказывает каждый итоговый сценарий v1.5.3.
Осталось отдельно проверить на устройстве:

1. Обновление поверх, предупреждение об удалении локальных данных и сохранение
 обычных проектов/внешних чатов; поведение Android-установщика.
2. Первый/повторный вход в оба бэкапа, Refresh на RU/EN/разных DPI, отмену
 и небольшой архив доступными gzip/pigz методами. Скорость pigz не измерена.
3. Временные серверные файлы/папки: выбор/отмена/подтверждение удаления,
 upload/download → В фон → другая вкладка → возврат/отмена.
4. Линию активности при клавиатуре/скролле и нагрузку на разных устройствах.
