# v1.2.9 — локальная проверка выбора файлов

Запрос/проверка разрешения для общей памяти, продолжение после выдачи доступа.
Один файловый менеджер для SSH-ключа и загрузки: Termux, найденные установленные
окружения proot-distro, память устройства. Для ключа одиночный выбор, для загрузки
до50 файлов между папками. Системный выбор Android из загрузки убран.
Передача напрямую через прежнюю очередь SFTP/прогресс/конфликты/остановку.

Code1080, прежние пакет/сертификат, форматы данных без миграций и очистки.
Повышен именно прежний резерв1.2.6: теперь1.2.10/code1081, содержимое прежней
базы с изменением только версии. Сначала основная1080; резерв1081 только для
отката, после него следующий APK должен иметь code>1081. Старые APK сохранены.
