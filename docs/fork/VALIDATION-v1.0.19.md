## Ревью и границы

Сеть только по ручному действию; один worker, лимиты ответов/APK, таймауты,
HTTPS redirects только GitHub hosts. Нет доступа к shell credentials, HOME,
PREFIX, агентам или процессам. Проверка установленного пакета/подписи и повышение
versionCode обязательны; установщик Android проверяет подпись окончательно.
Обновление не удаляет приложение. APK отдаётся FileProvider с read-only grant.
Отмена/ошибка удаляет частичный файл, не запускает установщик; после завершения
Activity установка не открывается. Ранее включённый DEBUG/VERBOSE сохраняется;
NORMAL однократно переходит в OFF. Журнал сессий не изменён.
