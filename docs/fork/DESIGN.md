# Интерфейс и поведение v0.2.1

Этот документ описывает текущий основной форк. [Исходный референс](reference.png)
и ранние макеты отражают процесс разработки, а не точный интерфейс релиза.

## Навигация и оформление

Сверху расположены компактные плитки «Главная / Команды / Терминал»
и шестерёнка. Нижней панели навигации нет. Чёрный фон, бирюзовые акценты,
скруглённые тёмные панели. Заголовки разделов выровнены; поиск и добавление
команды расположены рядом с заголовком «Команды».

Терминал использует исходный шрифт и интервалы. Отдельной настройки
интервалов нет. Смена заголовка терминальной сессии обновляет заголовки
и вкладки без пересоздания всех страниц.

## Главная

Журнал и сохранённые сессии имеют отдельные прокручиваемые тёмные панели.
Журнал содержит до 25 отправленных из поля ввода команд: новые сверху,
повторные отправки также записываются. Есть время, поиск и очистка с подтверждением.
Меню записи: вставить, сохранить в команды, скопировать. Диалог закрывается
кнопкой Back или касанием снаружи; отдельного пункта «Отмена» нет.

Вставка текста и прямой ввод в TerminalView не создают запись журнала.
«+» у сохранённых сессий создаёт профиль без автоматического запуска.
Обычные терминалы появляются в сохранённых только после явного сохранения.

## Команды

Поля: название, текст, категория и избранное. Есть поиск и фильтры.
Нажатие на карточку вставляет текст; при нескольких активных терминалах
предлагается выбрать получателя. Отдельной кнопки вставки на карточке нет.
Троеточие: добавить/убрать из избранного, редактировать, удалить.
Копирования и дублирования в этом меню нет.

Звёздочка у поля ввода открывает выбор для текущего терминала.
Вставка не отправляет команду, не создаёт процесс и не меняет каталог оболочки.

## Сессии и меню

Профиль: имя, каталог, до трёх команд и выбор среды. Карточка запускает профиль
или открывает его активную вкладку. Настройки имени применяются сразу,
каталога и стартовых команд — при следующем запуске.

| Место | Действия |
| --- | --- |
| Троеточие сохранённой карточки | Закрыть сессию, настройки, удалить сессию |
| Долгий тап по вкладке | Перезапустить, настройки, закрыть сессию |
| Несохранённая вкладка | Дополнительно «Сохранить сессию» |
| Шестерёнка терминала | Клавиатура, дополнительные клавиши, интерактивный ввод, отменить команды запуска |

Закрытие останавливает процесс и убирает вкладку после завершения, но сохраняет
профиль. Перезапуск сначала завершает прежний процесс. Оба требуют подтверждения.
Удаление профиля — отдельное действие; активную сессию сначала нужно закрыть.
Снимки вывода, история снимков и автоматические снимки удалены.

## Ввод и запуск

Поле ввода многострочное, Enter переносит строку. Отправка — отдельной кнопкой.
Поле растёт до шести строк, затем прокручивается внутри. Исходный paste
с поддержкой bracketed paste сохранён.

По умолчанию касание вывода не открывает клавиатуру. «Интерактивный ввод»
включает прямой ввод в TerminalView; нижнее поле остаётся доступным.

В режимах Termux/Ubuntu шаги выполняются после готовности Bash. При ошибке
следующие шаги пропускаются. Интерактивная программа задерживает продолжение
до выхода. Отмена касается оставшихся шагов, а не текущего процесса.
Подробности и примеры — в [руководстве](USAGE.md).
