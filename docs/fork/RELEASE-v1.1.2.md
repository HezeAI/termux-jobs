# v1.1.2 — «По выбору», согласие и индикатор обновления

**Локальная сборка для проверки, не опубликована.** Публичный выпуск пока v1.1.0.
Содержит весь выборочный бэкап из локальной v1.1.1 и следующие исправления.

- Режим «Выбранные данные» переименован в **«По выбору»**.
- При расчёте состава недоступность одного каталога больше не прерывает весь
  список. Показываются относительные проблемные пути и неполный размер;
  затронутые компоненты отключены, остальные доступны. При ошибке уже выбранного
  источника копирование по-прежнему останавливается, неполная копия не готова.
- Служебное хранилище proot .l2s не обходится как обычные файлы. Поддерживаемые
  внутренние ссылки сохраняются содержимым, без привязки к пути исходного телефона;
  выход из допустимого хранилища блокируется. Обычные внешние ссылки не обходятся.
  Права источников не изменяются; полный native-backup режим не переделан.
- **Создать** отключена и приглушена до отметки согласия; снятие отметки снова
  отключает кнопку. Работает в полной форме и финальном подтверждении «По выбору».
- В обеих формах явно подписана **«Папка создания резервной копии»**, ниже — путь
  и «Выбрать каталог».
- Встроенное обновление: индикатор проверки GitHub, полоса скачивания с процентом
  и объёмом, отдельное состояние проверки APK/подписи. Отмена сохраняется.

## Совместимость

com.termux, прежний сертификат, versionCode1059 выше публичной1.1.0/code1057 и
локальной1.1.1/code1058. Очистка команд, заметок, пресетов, истории и окружений
не требуется; библиотекаv8 и формат updater schema1 сохранены. Полные архивы
manifest v1 читаются; «По выбору» использует manifest v2 (принимающее приложение
v1.1.1+ либо доверенный restore.sh из бэкапа). Для проверки рекомендуется1.1.2
на обоих телефонах. Без системы данные только извлекаются, активация ручная.
Авторизация может потребовать повторного входа. Процессы и Android Keystore не
переносятся. Установка APK может остановить процессы; завершите важные задачи.

Скриншот v1.1.1 подтвердил SOURCE_UNREADABLE; точный путь старое сообщение не
содержало. Исправление общего обрыва воспроизведено на тестовых ошибках обхода;
новый сценарий на установленном телефоне должен проверить пользователь.
