# Проверки частной v1.7.53-x11-test

## Изменение и совместимость

Добавлен отдельный выбор CPU/Turnip+Zink для остановленных столов Termux и Ubuntu
26.04. CPU по умолчанию, существующие пресеты и данные сохраняются; миграции или
сброса данных нет. Пакет и сертификат сохранены, versionCode 1268 выше предыдущего
1267. Установка поверх должна сохранять Android-данные по идентичности пакета и
подписи; обновление и весь графический путь этой сборки требуют проверки на телефоне.
Публикация GitHub не выполнялась.

## Автоматические проверки

- 79 Python-тестов: GPU-установщик, X11-интеграция/запуск/native и миграция.
- 8 GPU-тестов также прошли в native Termux Python; финальные 8 Python-тестов
  повторены после последней правки отмены.
- 36 JVM-тестов выбранных классов: GPU/UI, выбор окружений и состояние клавиатуры.
- Проверены отказы повреждённого хеша, внешних ссылок/специальных файлов,
  подменённой блокировки, отмена и сохранение посторонних файлов.
- UI/служба проверены на серый режим при неизвестном/активном состоянии и отказ
  горячего переключения. Тесты UI не подтверждают жесты и отрисовку Android.
- Сборка release успешна; архив без ошибок/повторов, arm64-v8a, minSdk26,
  non-debuggable, APK v2-подпись проверена. Проверены JNI-контракты и определения
  runtime; 31 оставшийся тип имеет ранее оформленное рассмотрение.
- Проверены включённые assets против исходников, ожидаемые native-библиотеки,
  отсутствие известных приватных маркеров. Это не доказательство отсутствия
  любых возможных персональных строк во всех данных.
- git diff --check и bash -n пройдены. В сборке остаются унаследованные
  предупреждения vendor/Kotlin; чистый Lint для этой сборки не заявляется.

## Реальные изолированные GPU-пробы

На телефоне sysfs сообщает Adreno830v2; доступ к KGSL проверен.
Внутри репозитория распакованы закреплённые пакеты, затем проверен полный путь
нового установщика и x11-gpu-env.sh. Системные Mesa и окружения не заменялись.
Оба EGL pbuffer-теста 4×4 дали пиксель [64,128,191,255], glError=0:

- Ubuntu: zink Vulkan 1.4 (Adreno 830v1 / MESA_TURNIP), Mesa26.3.0-devel.
- Termux: zink Vulkan 1.4 (Adreno 830 / MESA_TURNIP), Mesa26.2.5.

Названия устройства переданы драйверами, значение sysfs не подменялось.
Обе пробы выполнены также параллельно. Они не создают окон и не доказывают
работу двух полноценных рабочих столов, GLX или плавность движения окон.

## Ревью и логическая инспекция

Прослежены установка → проверка хешей → выбор → запуск графического дочернего
процесса, CPU fallback по выбору пользователя, отказ для неподдержанных сред,
отмена до/во время/после распаковки и запрет смены работающего рендера.
Поздняя отмена не активирует GPU, даже если полный кэш уже успел опубликоваться.
Служба повторно проверяет состояние независимо от UI. Новых сигналов завершения
процессов нет; существующая логика остановки и независимые X11-серверы сохранены.
Настройки агентов и их Ubuntu AI этой правкой не переключаются.
