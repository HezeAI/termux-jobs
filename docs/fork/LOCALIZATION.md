# Локализация интерфейса

Поддерживаются русский и английский. Векторный глобус рядом с шестерёнкой на всех вкладках открывает выбор System / Русский / English. Системный язык, отличный от русского, использует английский. Выбор хранится в приватных предпочтениях приложения, без изменения пользовательских каталогов и переменных окружения.

WorkspaceText.tr применяется только к строковым литералам приложения. Android-ресурсы workspace_strings.xml содержат стабильные ключи workspace_text_NNN; не перенумеровывайте существующие ключи. Добавьте ключ в default English, values-ru и карту WorkspaceText. Не переводите пользовательские команды, категории, заметки, названия файлов/сессий, пути или маркеры протокола Codex.

Стандартные настройки переведены в app/src/main/res/values-ru/strings.xml и termux-shared/src/main/res/values-ru/strings.xml. Аргументы %1$s/%d должны совпадать с исходными ресурсами. Перевод команды shell должен менять только пользовательское сообщение, сохраняя quoting и управляющие конструкции.

Проверка: python3 scripts/check-localization.py, WorkspaceLanguageTest и обычные обязательные тесты/сборка. На устройстве проверьте длинные надписи, малый экран/DPI, меню Codex, сохранность ввода и живых процессов при смене языка. Мок-тесты не доказывают отрисовку/клавиатуру на телефоне.

Текущая v1.0.4 содержит 472 workspace strings. Новые надписи менеджера пакетов,
выбора версии, категорий и редактора файлов поддерживают RU/EN. Имена/версии пакетов,
Description репозиториев, содержимое файлов и пользовательские категории не переводятся.
