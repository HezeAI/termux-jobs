## Ограничения и устройство

Агент не устанавливал APK, не менял пользовательские проекты и сессии. Shell
запись тестировалась только на собственных fixtures. Реальный transport Android
Termux/proot/SSH для сохранения требует телефона; mock UI не проверяет IME/жесты/DPI.
Минимально: + и Редактировать команды/заметки → ▾ категория → выбор/новая/отмена;
создать тестовый .md в нужной среде, открыть/перенести строку/сохранить/сверить через
терминал, отменить изменённый буфер; внешнее изменение файла до Save должно дать
конфликт с сохранением буфера. SSH требует Bash/GNU coreutils и прав родителя.
Редактируются только распознанные текстовые файлы UTF-8 до 256 КБ, без links.
Save проверяет revision оптимистически: остаётся race между последним check и rename
для внешних writers, нет гарантии эксклюзивной блокировки. Если сеть/Android прервёт
операцию после rename, файл мог сохраниться, даже если клиент не получил SAVED.
Неизвестные filesystem metadata/Android shared storage ограничения не обещаны.
Пользователь одобрил переданную сборку и явно запросил GitHub-релиз. Подробный
протокол перечисленных сценариев устройства не предоставлен; они не объявляются
полностью проверенными агентом. Публичные исходники связаны с тегом v1.0.4.

В проверенной сборке versionName 1.0.4 задавался явной TERMUX_APP_VERSION_NAME.
Перед публикацией значение по умолчанию app/build.gradle и ARM64 build script
приведены к той же 1.0.4; Java/ресурсы проверенного APK не изменялись.
