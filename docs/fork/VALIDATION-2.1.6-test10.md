# 2.1.6-test10 /1531 — RTK из Components, выбранная строка бокового меню

## Изменения

RTK OSS upstream1.1.0 / revision jobs.1 опубликован в существующем
[Termux Job’s Components](https://github.com/HezeAI/termux-jobs-components/releases/tag/rtk-1.1.0-jobs.1).
Commit компонента `c882d44`. Релиз содержит бинарный архив, точные исходники,
патч, инструкцию сборки, Apache-2.0 LICENSE, dependency notices внутри архивов,
протокол измерений, результаты проверок, benchmark и SHA256SUMS.
Старые 8 релизов и132 assets сохранены; их IDs/имена/размеры/digests сверены.
Остальные записи каталога компонентов не менялись.

Загрузчик приложения использует опубликованный HTTPS URL с закреплёнными
версией, отдельной ревизией, размером и SHA-256. Он проверяет архитектуру,
лицензию, notices, хеш бинарника и реальный запуск. Встроенный тестовый архив
и частная ветка его передачи/распаковки удалены из APK.

Выбранная строка чата или терминальной сессии использует новый общий ресурс
`workspace_chat_background` (#000000) вместе с областью чата AgentChatView.
Изменена только заливка выбранной строки. Скругления, обводка, значки, подписи
и обработчики выбора сохранены. Фон карточек разделов меню не менялся.

Lite использует тот же проверенный бинарник jobs.1, но сохраняет свой прежний
измеритель: один captured stdout исходной команды → фильтр RTK → сопоставление
фактически возвращённого результата. Чистое дочернее окружение не передаёт
JOBS_RTK_BYTES_FILE/PID фильтру, поэтому native измеритель jobs.1 не включается.
Проверены отсутствие sidecar и отсутствие записей штатного режима. Повторный
PostToolUse не удваивает счётчики. Wrapper исходного grep подтвердил один запуск.
head учитывает только5 строк и даёт0% сокращения. Сохранение originals не считается
recall; явное чтение добавляет фактически возвращённые байты отдельно.
Ошибка grep сохраняет stderr и exit2. Настройки и счётчики второго чата не менялись.

Начальный Lite fixture с grep без имени файла не сокращался штатным grep-фильтром.
Для проверки сокращения использован настоящий grep -nH с filename/line полями.
Обработка команд не менялась ради теста. Отсутствие сокращения само по себе допустимо.

## Проверки настоящих агентов: переиспользовано и границы

Новых обращений к облачным моделям не выполняли. Production hook, фильтрация,
права, статистика, dispatcher и recall побайтно/по Python AST сверены с test9.
Единственная изменённая Python функция — installation. Агентские JS adapters,
RTK binarySHA и все pins, кроме удалённого private channel, совпали.
Доказательство: `.verification/rtk-remote/integration-reuse-proof.json`.

Переиспользуются результаты test9: настоящие CLI Codex0.166.0 и Claude2.1.296
с изолированным фиктивным провайдером и сетевым guard,12 парных сценариев
ls/recall/head/Git/поиск/чтение, Codex untrusted с отказом.
Точные режимы: Codex danger-full-access/never и untrusted; Claude SDK manual/default.
Эти результаты не подтверждают настоящую модель или другие настройки прав.
Фильтры RTK и их охват не расширялись. Неизмеренные/неоднозначные/обрезанные
CLI результаты сохраняют неизвестную базу. Штатное предупреждение о правах сохранено.

Нативные тесты и benchmark test9 переиспользованы для неизменённого бинарника
SHA3b8c5b69…; новый Rust build не выполнялся. Подробные границы и измеренные
задержки — [предыдущий отчёт](VALIDATION-2.1.6-test9.md).
Три JNI payloads APK переиспользуются после новой сверки95 native inputs и хешей.
GPU/X11 не запускались. Это не проверка графики на устройстве.
