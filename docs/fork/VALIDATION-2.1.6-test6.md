# Termux Job’s 2.1.6-test6 /1527 — проверка

2026-11-08. Частная тестовая сборка, не стабильный релиз. Без установки и публикации.
Включает исправления меню и появления из test5.

## Статистика RTK

- `statistics-v2` начинает новый период. Прежние measurements и history.db сохранены;
  их итог зафиксирован отдельно как прежняя оценка. Переключение режимов не сбрасывает
  новые показатели. Каждый чат имеет собственные данные.
- Lite использует фактический stdout исходной команды после head/tail/фильтров.
  Команда не запускается повторно. PostToolUse сопоставляет реально возвращённый
  результат по хешу. При подтверждённом удалении конечного пробела/перевода строки
  CLI одинаково нормализуются исходный и сокращённый тексты; считаются UTF-8 байты.
- Для штатного RTK1.1.0 подтверждённый head/tail без фильтрации считается тождественным
  преобразованием. Остальные базы пока неизвестны: native tracking может использовать
  полный размер файла и содержит оценочные токены. Эти значения не заменяют базу.
- Показатели разделены: до/после, дополнительно через recall, число команд,
  без сокращения, неизвестная база и неподтверждённое получение результата.
  Сохранение originals/recall.db само по себе не считается получением текста.
- Считается текст результата инструмента. Внешние поля JSON, служебная обвязка
  выполнения Codex и повторная отправка истории не входят. Это не экономия лимита
  подписки и не измерение всего контекста. Другие post hooks, которые позже заменяют
  результат, находятся за границей проверенного пути.
- Учитываются штатный `rtk recall` и поддерживаемые чтения Lite originals этого чата.
  Неизвестная форма ответа отмечается отдельно. Произвольные программы, читающие
  сохранённые файлы, автоматически не распознаются как recall.
- Новый PostToolUse hook требует следующего обычного запуска чата. Текущие сессии
  автоматически не перезапускаются. До подтверждения результата процент не выводится.
  Сохранённые правила и режимы разрешений не изменены.

## Обводка «Стоп»

Существующий кадровый таймер меняет только серый цвет обводки по плавной косинусной
кривой, полный цикл 2,5 секунды. Красный квадрат, фон, геометрия и обработчик остановки
не изменены. Повторные обновления WORKING не сбрасывают фазу. Завершение/скрытие
останавливает движение; отключённые системные анимации оставляют статичный цвет.

  RuntimeEnvironment.application. Отказ сохранён в `java.log`; это ошибка теста.
