# Проверки v1.7.81-x11-test / code1296

Частная сборка. GitHub-публикации нет.

## Причина и принятое решение

На настроенном телефоне установлен proot-distro5.9.0. Из официального APT-репозитория Termux скачан пакет5.10.2 в .verification/proot-clean-api, без установки. SHA-256 проверен по Packages.gz; извлечённый код показывает изменение аргумента download_blob с token на auth. При этом auth уже содержит полное значение Authorization, старый token был только значением Bearer-токена. Старый обязательный token в нашем probe отвергает этот официальный пакет. Это объясняет несовместимость на чистой установке с текущим пакетом; версию непосредственно на Samsung отдельно не получили.

ENVIRONMENT_DOWNLOAD_RESUME_UNSUPPORTED не означает сетевой обрыв: наш prefetch вызывался и при первой установке, до загрузки слоёв. Обновление компонента вv1.7.80 не решало проблему, поскольку новый интерфейс отвергался тем же адаптером. Проверки на настроенном телефоне с5.9.0 этого не выявили. Метаданные скачанного официального пакета: .verification/proot-clean-api/package.json; извлечённый код находится только в ignored-каталоге проверки.

По решению разработчика предварительный загрузчик удалён полностью. environment-download.py удалён из исходников и APK, из AgentPreparation и из копирования EnvironmentSetup. Из общего environment-runtime.sh удалены prefetch/probe и обращения к внутренним OCI-callback. Все современные OCI-окружения устанавливает публичный proot-distro install IMAGE --name ALIAS. Старый CLI сохраняет свой предыдущий путь с плагинами. Агентская подготовка использует тот же runtime. X11 уже вызывал штатный CLI для отсутствующей Ubuntu; графический запуск/рендер не менялись.

Arch Linux ARM сохраняет отдельный официальный архив Termux: фиксированные HTTPS URL и SHA-256, затем установка архивного файла штатным CLI. Старый архивный вызов удалённого downloader также убран. Проверки хеша/HTTPS не отключались.

## Повтор, остановка, данные

Побайтовое продолжение незавершённого файла больше не обещается. Целые проверенные OCI-слои повторно использует штатный кэш proot-distro; оборванный слой может скачиваться заново. Прогресс, кнопка Стоп, фон и собственный supervisor установки сохранены. Механизм сигналов/групп процессов в environment-install.py не менялся.

Чтобы кнопка «Продолжить» оставалась после остановки/ошибки и повторного открытия, добавлена отдельная отметка попытки в SharedPreferences по alias. Это повтор штатной установки, а не обещание побайтовой докачки. На успехе отметка очищается; старая state.json этой установки удаляется только при совпадении канонического пути и отсутствии подмены пути симлинком. Старые .part и общий кэш не удаляются автоматически. completed-отметка не позволяет оставшейся старой metadata ошибочно блокировать статус Installed.

Повтор при оставшемся rootfs не перезаписывает его: сохраняется консервативная ошибка INCOMPLETE_ROOTFS_REQUIRES_REMOVAL. Ранее существовавшие окружения не удаляются и не заменяются. Убитое Android приложение может оставить требующую проверки попытку; наличие /bin/sh само по себе не доказывает успешную распаковку всей системы.

Согласованная корзина для отказа от незавершённой установки остаётся будущей задачей. После перехода на штатный кэш нужно учитывать совместно используемые слои; нельзя очищать общий кэш как будто он принадлежит одной карточке. Установка программ через apt/apk/dnf/zypper/xbps не менялась; их прогресс и сохранение состояния остаются.

## Ограничения и следующий тест

Чистая Ubuntu на Samsung этой сборкой ещё не установлена. Реальное скачивание/распаковка штатным CLI на Samsung и работа прочих дистрибутивов требуют проверки на устройстве; фикстуры не заменяют её. Минимум: обновить APK и повторить установку Ubuntu из списка окружений. Ошибка удалённого адаптера этим путём больше не генерируется, но сеть/репозитории/native installer могут сообщать собственные ошибки. Сетевой сбой пакетов Void не объявляется исправленным.

Пакет/сертификат сохранены, versionCode1296 выше1295. Форматы истории/пресетов/агентов не меняются, сброса данных нет. Новая metadata попыток приватна приложению. Существующие скачанные части остаются до отдельной очистки. Применение изменения не требует удалять установленные окружения.
