# v1.7.75-x11-test / code 1290

Исправления после снимков экрана разработчика: RPM отказался удалять Evince, поскольку установленный evince-plugin-pdfdocument зависит от него. Ошибка операции также сбрасывала статусы всех рекомендуемых программ.

## Изменения

- В openSUSE удаление Evince включает установленный evince-plugin-pdfdocument в одну RPM-транзакцию. Подтверждение предупреждает об этом. Не используется --nodeps, принудительное удаление, autoremove или удаление произвольных зависимых пакетов. В других окружениях состав удаления не расширяется.
- При операции установки/удаления сохраняется копия известных статусов остальных рекомендуемых программ. Статус затронутой группы становится неизвестным до успешной проверки; частичный вывод не считается успешным результатом. Ошибка/отмена не сбрасывает остальные карточки.
- Полный дисковый кэш после изменения пакетов по-прежнему инвалидируется, чтобы после перезапуска не выдавать устаревший снимок за актуальную проверку. Миграции, сброса данных и изменения работающих окружений нет.

## Проверки исходников

- Python: test_x11_opensuse, test_x11_void, test_x11_fedora — 21 сценарий прошёл, включая PDF-модуль установлен/отсутствует, сохранение прежнего поведения Fedora и отказ RPM без обхода зависимостей.
- JVM/Robolectric: DesktopProgramResumeTest, WorkspaceDesktopProgramsTest, X11ProgramCacheTest — прошли. Проверены сохранение остальных карточек после неудачного удаления, неизвестный статус затронутой группы, UI-снимок ошибки, прежние сценарии повторного запуска и кэша.
- Логическая инспекция: проверка разрешённого пакета остаётся до изменения снимка; снимок копируется, а не изменяется на месте; частичный результат не принимается за полный; отмена/ошибка сохраняет снимок, управление дочерним процессом и ожидание guardian не изменялись. Исполнение shell из имён пакетов не добавлялось.
