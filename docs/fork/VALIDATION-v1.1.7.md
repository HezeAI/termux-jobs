## Логическая инспекция и границы

Установка FFmpeg доступна только после явного подтверждения сервера/команды,
выполняется через прежнюю очередь задач. Нет auto-install от opроса/свойств;
команда фиксирована, file/server text не вставляется в shell. Только APT: root
или настроенный sudo -n; для sudo пароля — терминал. Cancel подтверждения ничего
не запускает. Пакеты не удаляются вместе с агентом. Не прерывайте APT без нужды.

Non-media использует read-only stat, без ffprobe. Media RPC прежний, компоненты
проверяются отдельно по SSH. Распознавание по расширению; .ts как код, не видео.
Файловые actions используют runInline с busy/generation, обновляют список/диалог,
не root hierarchy. При ошибке список/путь остаются согласованы.
График имеет fingerprint данных, метрики прежние; отдельный pollBusy сохранён.
Плашка просмотра проверяет живой SSH-процесс, не состояние внешнего плеера;
выход из плеера сам по себе может оставить туннель до явной остановки/таймаута.
Остановка касается только принадлежащего клиента tunnel process.

Верхний ! убран, внутреннее объяснение осталось. Библиотекаv8/серверные профили/
обычный SSH без сбросов; сервер, бот, процессы и системные пакеты не менялись.
