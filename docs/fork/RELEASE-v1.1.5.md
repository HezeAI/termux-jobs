# v1.1.5 — Сервер + Agent (локальная проверочная сборка)

**На GitHub не опубликовано.** Публичная Latest остаётся v1.1.4.

Отдельная широкая кнопка «Сервер + Agent» в верхней строке. Название центрировано,
в углу векторный `!` с объяснением установки, прав и удаления агента. Полноценный
экран подключений, проекты, CPU/RAM/диск и графики, серверные задачи с живым журналом,
файлы и службы. Старый SSH-вход в создании сессий сохранён.

Опциональный агент устанавливается после подтверждения через SSH в собственную
папку выбранной учётной записи, без sudo и публичного порта. Удаление отдельно,
активные/неподконтрольные задачи блокируют его. Агент имеет права SSH-пользователя,
root означает полный доступ. Пакеты ОС, бот и прочие службы при установке не меняются.

Файлы: каталог, свойства (ffprobe если установлен), скачивание, переименование без
перезаписи и удаление файла с подтверждением. Видео/аудио через временную ссылку
и loopback SSH-туннель, нужен совместимый внешний плеер; срок до30минут.

## Совместимость

com.termux, Android7+/ARM64, versionCode1062; сертификат прежний (проверяется
по финальному APK в VALIDATION-v1.1.5). Библиотекаv8 и формат прежних сессий не меняются,
данные не сбрасываются. Обновление Android может перезапустить процессы приложения:
закончите важные операции перед ручной установкой.

Linux/Bash/Python3.8+ на сервере, openssh в Termux. Агент не стартует автоматически
после перезагрузки сервера: следующее подключение возобновляет его. Задачи не переживают
перезагрузку, интерактивный ввод в них не поддерживается. После аварии агента прежние
задачи требуют ручной проверки и не запускаются повторно автоматически.

Данные профилей хранятся отдельно; экспорт библиотеки не переносит их автоматически.
Пароли защищены Android Keystore и могут потребовать повторного ввода после переноса.
Мониторинг приостанавливается в фоне приложения; просмотр видео имеет отдельный срок.
Первое реальное подключение/установка агента, DPI, жесты и плееры требуют ручной проверки.

Описание: docs/fork/SERVERS.md. Проверки: docs/fork/VALIDATION-v1.1.5.md.
Для возможной будущей публикации готовятся локальные update.json и SHA256SUMS;
их наличие не означает опубликованную версию или авторизацию публикации.
