# Termux Job’s v1.0.3 — локальная сборка

Описание пакета теперь показывается в карточке: до трёх строк и Подробнее с
полным текстом во внутреннем прокручиваемом окне. Источник — metadata выбранного
окружения APT/dpkg; описание читается только при открытии, без загрузки всего
каталога и автоматического перевода/генерации примеров запуска.

Команды и заметки открывают единое окно текста и действий: избранное, редактирование,
удаление с подтверждением; троеточия списка убраны. Вставка команды сохранена.
Поля категории предлагают существующие категории своей библиотеки; новую можно
вписать свободно. Новые сообщения интерфейса RU/EN.

247 тестов и сборка release/lintVital прошли; [проверки и ограничения](VALIDATION-v1.0.3.md).
Android 7+ / ARM64; пакет/сертификат сохранены, versionCode 1040, схема v8 прежняя.
