## Ревью и логика

Версии запрашиваются для имени из проверенного каталога в отдельном процессе
окружения профиля. pipefail сохраняет ошибку APT; лимиты 1 МиБ/1000 версий и
тайм-аут транспорта ограничивают чтение. Только installed dpkg status участвует
в сравнении dpkg --compare-versions. Quoted name=version не становится shell code;
нет -y/allow-downgrades/auto-hold/добавления сторонних источников.
Выбранная версия проходит стандартное подтверждение цели; отмена не устанавливает.
Закрытый менеджер/отменённое окно загрузки не открывает выбор при позднем ответе.
Стандартный маршрут выбранной/новой сессии и проверки handle/среды сохранены.
