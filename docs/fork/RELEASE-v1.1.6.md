# v1.1.6 — стабильное отображение серверов (локальная проверочная сборка)

На GitHub не опубликовано. Публичная Latest остаётся v1.1.4.

Убрано впечатление постоянного переподключения: автоопрос раньше показывал
«Подключение / выполнение…» и полностью перестраивал страницу каждые10секунд.
Теперь обновляются существующие элементы метрик/графика и только изменившиеся
строки задач. Путь, файловые кнопки, выделенный раздел и прокрутка сохраняются.
Отдельный флаг pollBusy не блокирует действия пользователя; транспорт по-прежнему
открывает отдельные SSH-запросы. Постоянный SSH-канал в этой версии не добавлен.

Разделы Проекты/Задачи/Файлы/Службы имеют промежутки и скруглённую подсветку.
Навигация файлов — четыре одинаковые центрированные векторные кнопки: вверх,
домой на сервере, ввод пути, обновление. Возврат к списку серверов — векторная
стрелка. Убраны верхний плюс и плюс из единственной кнопки «Добавить сервер».

## Совместимость

com.termux, Android7+/ARM64, versionCode1063 >1062, прежняя подпись. Серверные
профили и библиотекаv8 без сброса/миграции. SSH · сервер в создании сессий сохранён.
Агент побайтно прежний: переустанавливать на сервере не нужно.
На сервере разработчиком ничего не менялось, службы/задачи не останавливались.
Реальные DPI/жесты/сеть и обновление APK требуют ручной проверки. При установке
Android может завершить приложение, поэтому заранее закончите важные процессы.

Руководство: SERVERS.md. Проверки: VALIDATION-v1.1.6.md.
Локальный update.json готовится из финального APK, не публикуется.
