## Проверка на устройстве ещё требуется

1. Выберите Ubuntu и рабочий каталог проекта; Все чаты должен включать историю из /root, Чаты этой папки фильтрует отдельно. При продолжении корневого чата в проекте подтвердите две папки и проверьте реальный cwd/историю после запуска.
2. Отмена не меняет выбранный чат. Изменение каталога сохранённого профиля повторно требует подтверждения; уже запущенный процесс не перемещается.
3. Звезда/+ /папка в терминале и кнопка папки в форме центрированы. В общем браузере и выборе папки вверх/дом не искажены, фильтр файлов заметно выделен.
4. Карточка Codex ниже строки сессий, стопка имеет промежутки. Проверить малый экран/DPI/клавиатуру и сохранность черновиков.

Нужен новый запуск bridge-v0.2.19 для нового preflight. Старые работающие процессы не заменяются. Полная проверка реального списка истории, жизненного цикла UI и отрисовки на всех телефонах не выполнена; синтетическая история RPC-стенда не заменяет проверку списка пользователя. Не запускайте изменение каталога текущего рабочего чата агентом.
