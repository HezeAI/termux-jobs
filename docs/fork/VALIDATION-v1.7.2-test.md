## Ревью и ограничения

Очистка не выбирает данные сама. План фиксирует файлы, повторно проверяет их
и использует no-follow directory fd; удаляются только найденные регулярные файлы.
Проверяются связанные сессии и native блокировки. Процессы не останавливаются.
Отмена прерывает оставшееся удаление без обещания восстановления уже удалённого.
Проверки не являются sandbox против произвольного процесса с тем же UID.
Политика/категории подробно описаны в STORAGE-CLEANUP.md.

История хранится приватно по физическому окружению, общий список пакетов не
получает дополнительных native запросов. Разовых путей receipt нет в сохранённых
пресетах. Нет перехвата вывода терминала или постоянного фонового polling.
Код 1 честно обозначается как ошибка или отмена; ошибки произвольных команд,
введённых вне нашего пакетного интерфейса, не перехватываются.
Пока есть незавершённые receipts, промежуточный installed-list не превращается
в ошибочную запись об успешной установке. Закрытие сессии собирает её receipts.

Реальное удаление пользовательских данных и очистка установленных окружений
в рамках этих проверок не выполнялись. UI-тесты не подтверждают жесты/DPI и
Android-разрешения на телефоне. Минимальная проверка разработчиком: открыть
новый пункт под настройками приложения, проверить пустой выбор/обязательную
галочку/Отмену и outside taps на ненужных тестовых данных; открыть Установленные
→ История слева от Закрыть, проверить неизменный размер исходного окна и историю
тестового пакета. Выбор версий: ограничения и native-проверки см. исторический
VALIDATION-v1.7.1-test.md; новых native запусков DNF/Zypper здесь не заявлено.
