# Проверочная v1.6.8-test — вход в Void

- Пакет com.termux, code1204, Android8+/ARM64, прежняя подпись.
- APK: `Termux-Jobs-v1.6.8-test-arm64.apk` · 36681201 байт.
- SHA-256: `7b67f41395a062f1c0ed68b4291ef0c5a4836327e951f7c175851761360dafa6`.
- GitHub не опубликован. Копия в Download проверена по SHA-256.

Причина подтверждена read-only по установленным файлам: в Void /bin/sh → dash,
/bin/bash отсутствует, root passwd указывает /bin/bash, OCI Entrypoint=null,
Cmd=[/bin/sh]. Официальный установленный proot-distro проверяет passwd shell
до явной команды login. Native run сохраняет ту же настройку proot, но передаёт
явную команду через _run_inner, минуя эту проверку. Это проверено на выделенном
AST функции реального установленного resolver с mock command_login: ни proot,
ни пользовательский процесс не запускались; файлы системы не изменялись.

Изменены выбор login/run для новых proot-сессий, файловые операции и подсказка
входа. Выбор run ограничен нужной конфигурацией и пустым Entrypoint; неверные
типы/отсутствующий манифест/неподходящие пути сохраняют прежний login. Ubuntu и
AI Agents проходят прежний путь. Для sh-fallback задаётся правильный SHELL.

37 целевых JVM-тестов прошли, включая новый случай отсутствующего root Bash,
отказ при непустом Entrypoint, обычный sh, наличие Bash и отсутствие манифеста;
проверки окружений/файлов/агентских генераторов также прошли. Сборка и DEX runtime
прошли. ZIP/package/version/ABI/minSdk/v2-подпись/сертификат проверены. Все assets
и native побайтно совпадают с1.6.7/code1203. Проверяемых приватных файлов/ключей
и секретных маркеров в APK не обнаружено. git diff --check проходит.

Архив Arch Linux ARM скачан в проект, SHA-256 совпал с закреплённым значением;
163892644 байт,33705 записей, корень archlinux-aarch64/, root shell /usr/bin/bash,
файл присутствует и имеет ELF AArch64; /bin/sh разрешается в Bash. Архив не
извлекался в установленную систему, запуск Arch ещё требует проверки на устройстве.
Фактический запуск Void после исправления, действия файлового менеджера и
восстановление Void без OCI-манифеста ещё требуют проверки разработчиком.
Формат библиотеки не менялся; очистка данных для обновления не требуется.
Новых APK отката в этой выдаче нет; прежние1200/1202 не устанавливаются поверх1204.
