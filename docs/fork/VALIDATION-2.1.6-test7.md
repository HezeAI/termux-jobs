# 2.1.6-test7 /1528 — компактные кнопки RTK

## Изменения

Все этапы диалога RTK используют общие кнопки действия и отмены: ширина по тексту,
центрирование, отступы16dp по горизонтали и8dp по вертикали, высота минимум48dp.
Минимальная ширина снята; число строк не ограничено, ellipsis отключён.
Полоса прогресса осталась широкой. Обработчики установки, подключения, сохранения
выбора, ошибок и отмены не изменены. Включены изменения test6.

## Проверено заново

- 4 RtkMode JVM tests: установка, отмена и отсутствие позднего включения,
  статистика, компактная геометрия и рост высоты при явном многострочном тексте.
- Release APK собран. Финальные ZIP, подпись v2, package com.termux, версия,
  ARM64-only, non-debuggable, runtime/DEX,132assets и638production sources проверены.
- Контрольная сумма копии в Download совпадает с проверенным APK.

## Переиспользовано

- Полный Modern Lint7.4.2 выполнен для этой правки до повышения versionCode:
  0ошибок,290предупреждений. Совпадение всех342Java/XML входов проверено.
  После анализа изменён только versionCode1527→1528 в конфигурации сборки.
- Неизменённые JNI payloads: заново сверены95входов и хеши готовых библиотек.
  X11/GPU не запускались. Полный набор проверок backend RTK не повторялся:
  этот патч меняет только Java-оформление кнопок.

## Ограничения проверки

Robolectric4.4 не подтвердил реальный перенос по метрикам шрифта и границы строк.
Первоначальные неудачные assertions сохранены в initial-test.xml,
oversized-test.xml и multiline-test.xml. Финальный тест использует явный перенос;
его результат не подтверждает автоматический перенос на телефоне.
На устройстве ещё нужно проверить длинные RU/EN подписи, большой шрифт,
узкий экран и все этапы диалога. APK автоматически не устанавливался.
