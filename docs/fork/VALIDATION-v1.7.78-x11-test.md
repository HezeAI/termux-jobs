# Проверки v1.7.78-x11-test / code1293

Частная сборка для проверки X11. GitHub-публикации нет.

## Изменения и причины

Проверка закреплённого bootstrap показала libc++27c без символа std::__ndk1::__hash_memory, который требуется установленному fcitx5. На настроенном телефоне libc++30 этот символ содержит. Установщик Termux X11 и явные установки нативных программ теперь запрашивают актуальный пакет libc++; подготовка VirGL также проверяет исполнимость сервера. Это исправление рецепта установки, а не замена библиотек самим APK.

Гостевые проверки, установка, запуск и программные операции используют PATH и XDG выбранного Linux-окружения. Унаследованные LD_LIBRARY_PATH, LD_PRELOAD и адрес системной D-Bus очищаются перед настройкой собственного окружения. Void сохраняет вход через run --work-dir /root. Android X11/Pulse и нативный сервер VirGL остаются предусмотренной частью архитектуры.

Необязательные зависимости привязаны к программам: Termux ristretto/tumbler получает poppler для PDF-миниатюр; явная установка gnupg получает libgcrypt/libgpg-error; fcitx5 получает libc++. Базовая установка Termux выполняется без необязательных Recommends, включая необязательный gnupg у xfce4-session. Уже установленные программы не удаляются. Нужные самому XFCE совместимости Alpine/Fedora остаются в собственном окружении X11. Проверка fcitx5 сообщает о неисправном компоненте, но не блокирует ручной ввод и стол. Firefox DNS нельзя включить без браузера выбранной системы. Обслуживание программы не требует полной повторной проверки всех компонентов стола.

Кэш рекомендуемых программ обновляет схему в прежнем файле, чтобы старый статус не скрывал новые зависимости. Пользовательские данные не сбрасываются.

Диагностика распознаёт Android cannot locate symbol, cannot link executable, недостающие библиотеки и несовместимость версий. Экспортируются ограниченные категории и разрешённые имена компонентов, без сырых личных путей или содержимого файлов. Код дочернего стола сохраняется отдельно от кода guardian: 137 служебного процесса сам по себе не доказывает OOM. Механизм остановки процессов не менялся.

## Автоматические проверки

112 профильных JVM-тестов прошли: диагностика, сохранение кода дочернего процесса при переполнении событий, UI подготовки/программ, кэш и интеграция. Профильные Python-проверки прошли, включая проверки bootstrap, границ окружений, зависимостей программ, отсутствующего Firefox, неисправного fcitx5 и отдельных путей Void/openSUSE/VirGL. Часть наборов запускалась повторно после последних изменений; повторы не считаются отдельными сценариями.

Сборка release arm64 успешна. ZIP, package/version/minSDK/ABI, подпись v2, DEX и JNI-контракты проверены. Относительно v1.7.77 изменились только шесть ожидаемых X11-ассетов; нативные библиотеки идентичны. Проверено совпадение исходников со staging. Известных маркеров приватных ключей и токенов в APK не обнаружено; это не утверждение об исчерпывающем сканировании всех возможных секретов.

## Ограничения и проверка на устройстве

Чистая установка на Samsung S26 Ultra и графические сценарии этой сборки ещё не проверены. Анализ bootstrap и автоматические тесты не подтверждают все сценарии чистого приложения. Точная причина завершения стола на Samsung кодом137 не установлена. GPU и различия Android/OEM требуют отдельной проверки.

Установка APK не обновляет системные пакеты сама. Для уже имеющихся несовместимых пакетов нужна соответствующая установка/обновление компонентов. Общая среда, пользовательские процессы и установленное приложение в ходе разработки не изменялись. Минимальная следующая проверка: Termux CPU и Ubuntu CPU на проблемном телефоне; при сбое сохранить Диагностика сессии → X11. Проверки клавиатуры, файлов и программ выполняются на устройстве отдельно.
