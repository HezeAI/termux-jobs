## Ограничения и следующая проверка на телефоне

Мок-тесты не подтверждают работу жестов, клавиатуры, системного меню передачи, SSH/Keystore или полного жизненного цикла Terminal на устройстве. Проверьте: выбор/создание папки и возврат в форму; новый чат → получение ID → сохранить → закрыть → продолжить; файлы в Ubuntu и передача APK/Download; переключение с сохранением черновика; exit в базовой Terminal и её восстановление.

Синтетическая история изолированного RPC-файкстура не появляется в thread/list (0 строк); проверка протокола resume/метаданных не заявляется полной проверкой списка настоящей истории на телефоне. Фильтрация cwd проверена логически и тестами; реальный список нужно проверить в выбранном проекте.

Нужен новый запуск Codex с помощником bridge-v0.2.18 для метаданных cwd/ID; старые работающие процессы не заменяются. Восстановление Terminal прекращается после нескольких быстрых отказов; оно не переживает принудительное завершение Android/выход из всего приложения. Terminal занимает одно из восьми мест, при заполнении создаётся после освобождения места.

Лимиты: текст 256 КБ, изображение 16 МБ с уменьшением разрешения, экспорт 256 МБ. Для SSH сначала доверенный ключ сервера, пароль/ключ профиля; непереносимый Keystore не копируется на другие устройства. Альтернативные пути через symlink могут потребовать выбора фактического каталога. История хранится Codex отдельно от профиля.
