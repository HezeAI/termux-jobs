# Touch Workspace · частная v1.7.98-x11-test

Вторая необязательная тема **только базового Termux XFCE**. В меню «Терминал /
Рабочий стол» галочка Touch Workspace расположена ниже «Стиль Termux-job's».
Выбор одной выключает другую. Обе выключены — обычное оформление; прежняя
галочка Kali при обновлении сохраняется. Изменение доступно после остановки
стола и операций установки. Применяется при следующем запуске.

## Экран и управление

Это GTK3-интерфейс внутри того же X11: крупная карточка быстрых папок, сетка
«Файлы / Терминал / Браузер / Программы», последнее действие и папка, нижняя
панель Home / Menu / рабочие места / Keyboard. Размеры масштабируются по
разрешению X11; содержимое прокручивается на маленьком экране. Ориентир —
`design/x11-mobile-concepts-v1.7.95/Termux-Jobs-X11-creative-touch-cards.png`.
Программы Linux открываются обычными окнами; их интерфейс не переписан в карточки.
Состав быстрых папок фактический: Download/Pictures при наличии, Projects при
наличии, иначе Home. Несуществующие папки и вымышленные счётчики не создаются.
Программы — локальный список установленных desktop-приложений, не установка
пакетов. Установка остаётся в Android-плашке «Программы».

С v1.7.98 оформление Touch остаётся, управление совпадает с обычным XFCE:
палец двигает курсор, короткий тап нажимает в месте курсора, удержать и вести —
левый захват/перетаскивание. Два пальца прокручивают, тап двумя пальцами — правая
кнопка. Прямой режим v1.7.96–97 удалён из рабочего адаптера по выбору разработчика.
Мышь/перо сохраняют прежнее прямое позиционирование. Отмена и смена вида отпускают
удержанные кнопки. К папке сначала подвести курсор, затем дважды тапнуть.

Для переноса окна подвести курсор к заголовку, удержать и вести. Для изменения
размера подвести к краю/углу, удержать и вести. В Touch зоны рамок20px X11 с
тонким контуром сохранены. Развёрнутое окно сначала восстановить обычной кнопкой.
Допустимый интервал GTK500мс сохраняется как часть темы и восстанавливается при
её выключении, если пользователь не менял это значение вручную.


Home возвращает экран карточек, Menu открывает программы. Панель остаётся
доступна над обычными окнами, три рабочих места переключаются через EWMH.
Keyboard вызывает тот же ручной Android-ввод, что верхняя кнопка приложения,
и не переводит X11-фокус из поля программы в нижнюю панель. Автоматический
ввод через fcitx остаётся отдельной настройкой.

## Границы и восстановление

Нативный небольшой executable собирается из `x11-touch-workspace.c` под
Android/Bionic ARM64, динамически использует установленные GTK3/GLib/X11.
Явный набор базовой установки Termux включает gtk3, exo и libx11;
проверка не принимает их отсутствие как готовый стол. Гостевые rootfs не меняются.
Сборка использует существующие заголовки Termux и NDK только для чтения;
новые инструменты и результаты остаются в репозитории.

Процесс запускается непосредственно из собственного `x11-session.sh` в группе
уже существующего guardian. Он не создаёт daemon/setsid, не записывает постоянный
автозапуск и не ищет чужие PID. Закрытие стола завершает принадлежащую ему группу.
Обычный терминал, AI-агенты, настройки туннеля и ядро libXlorie не меняются.

Когда композитор выключен, собственное окно Touch держит один server-side
background pixmap со снимком своих GTK-виджетов. X11 может восстановить
открывшийся участок сразу при движении чужого окна, не дожидаясь очередного
GTK-кадра. Снимок создаётся из виджетов, а не чтением экрана: чужие окна/данные
не попадают в него. Native-дети наследуют этот фон. Кэш обновляется только после
собственных изменений текста/прокрутки/геометрии, без постоянного таймера.
Старый pixmap освобождается при замене, новый размер ограничен4096×4096 с
учётом масштаба. С включённым композитором эта ветка не нужна и освобождает кэш.
Композитор, драйверы и чужие окружения не перенастраиваются.

Тема — отдельный ZIP с SHA-256-проверкой. XML-настройки и собственные ресурсы
применяет существующий осторожный helper. Первый исходный набор сохраняется
при Kali → Touch → Kali. Параметры только Touch (скрытие панелей, число рабочих
мест) возвращаются при выходе из него. Ручные изменения пользователя имеют
приоритет при восстановлении. Отключение обеих тем и новый запуск возвращают
исходные настройки. Пользовательские файлы, ключи и история не удаляются.

## Проверка на телефоне

После установки APK остановить базовый Termux-стол, выбрать Touch Workspace и
запустить его. Проверить размеры, движение курсора и щелчки, прокрутку двумя
пальцами, удержание/перетаскивание/размер окна и отсутствие следа при движении,
Home и Keyboard с полем браузера/редактора.
Затем остановить стол, выбрать Kali и проверить возврат; выключить обе темы
и проверить исходный вид. Мок-тесты и отдельный GTK-рендер этого не заменяют.
