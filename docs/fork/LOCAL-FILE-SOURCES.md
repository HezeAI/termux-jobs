# Локальные источники файлов — v1.3.0

Выбор приватного SSH-ключа, загрузка на сервер и папка скачивания используют общий файловый
менеджер приложения. В нём доступны Termux, найденные установленные окружения
proot-distro и «Память устройства». Для окружений учитываются старый installed-rootfs
и новый containers/<alias>/rootfs. Каталоги-ссылки, неверные aliases и отсутствующие
rootfs не предлагаются. Установка дистрибутивов/пакетов не запускается. Произвольные
chroot/Docker/rootfs вне этих мест автоматически не обнаруживаются.

«Память устройства» сначала проверяет разрешение, затем открывает /sdcard.
При отсутствии разрешения запрашивается существующее WRITE_EXTERNAL_STORAGE;
после выдачи операция продолжается. При отказе показывается пояснение и кнопка
настроек; на Android11+ возможно системное разрешение «Доступ ко всем файлам».
Environment.isExternalStorageManager проверяется отдельно. После возвращения
из настроек разрешение проверяется заново; выдача не предполагается по RESULT_OK.
При уничтожении Activity отложенное действие отбрасывается. Новые разрешения в
manifest не добавлены. Закрытые каталоги Android/data других приложений разрешение
может не открыть. Установки, symlink-команды и termux-setup-storage не запускаются.
[Документация Android](https://developer.android.com/training/data-storage/manage-all-files).

Для SSH-ключа выбор по-прежнему одиночный, с подтверждением импорта, скрытым
passphrase и Android Keystore. Ключ из другого окружения/общей памяти копируется
в приватный уникальный файл; оригинал не изменяется. Ручной ввод пути остаётся.

«Загрузить на сервер»: стандартный Android document picker убран по решению
разработчика. Менеджер даёт выбрать до50 файлов за одну отправку. Нажатие на
файл отмечает/снимает отметку; папка открывается. Отметки сохраняются между
папками одного выбранного источника, включая смену фильтра/поиска. Кнопка
«Загрузить выбранные (N)» активна при непустом выборе и отсутствии чтения каталога.
Затем отдельное подтверждение назначения; передача последовательная, прежняя
очередь SFTP/проверки конфликтов/переименование/замена/пропуск/прогресс/остановка.
Лимит2ГБ на файл сохранён. Одним выбором не смешиваются разные окружения.

Данные идут через независимое локальное чтение и существующий SFTP, без архива,
кэширования полного файла на устройстве или дополнительного подключения на каждый
источник. Для proot используется проверенный alias, /bin/sh и переносимый листинг
с stat вместо обязательного GNU find -printf. Путь передаётся с shell quoting.
При ошибке чтения/ненулевом exit отправка считается ошибочной, временный удалённый
файл очищается существующим механизмом. Изменение файла во время чтения не
блокируется: это передача, не согласованный снимок файловой системы. Очередь
не останавливает пользовательские терминалы. Пользовательские данные/схемы не
мигрируются и не очищаются; новые внешние зависимости не добавлены.

## Скачивание с сервера

В меню файла сохранено «Скачать в Download»: папка
/sdcard/Download/Termux-Jobs-Server, с проверкой разрешения.
Рядом «Скачать в другую папку…»: выбор Termux, установленного окружения
proot-distro или памяти устройства, затем папки. Перед передачей показано
назначение и запрашивается подтверждение. Установка окружений не выполняется.

Уникальное имя download-UUID-имя, временный файл .part с запретом обычной
перезаписи, публикация после успешного SSH-чтения и закрытия записи. При ошибке
удаляется только собственный временный файл; ошибка очистки отображается.
При прерывании во время завершения нужно проверить выбранную папку.
Это не транзакция файловой системы: одновременная внешняя модификация папки
и аварийное завершение приложения могут оставить файл/остаток .part.

Поток идёт прямо в выбранное окружение без промежуточного полного файла.
Существующие ограничения2ГБ/10минут, прогресс и независимое SSH-соединение
сохранены. Остановка не закрывает мониторинг и пользовательские терминалы.
Скачивание использует прежний SSH-путь, не объявляется ускоренным SFTP-upload.
Нужна проверка реальной передачи в proot, прав Android, нехватки места и
отмены на устройстве; тесты оболочки/мок-UI её не заменяют.

Версия1.3.0/code1083. Пользовательские форматы не меняются,
очистка не требуется. Нового резервного APK нет, старые файлы сохранены.
