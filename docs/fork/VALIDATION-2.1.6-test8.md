# 2.1.6-test8 /1529 — краткий блок RTK

Состояние подключения, одна сводка выбранного режима и короткое описание находятся
под переключателями. Детали по умолчанию свёрнуты: дата, оба режима, байты, recall,
число команд, прежние оценки и объяснение различий режимов. Предупреждение перед
включением штатного RTK сохранено. Обновление статуса не меняет раскрытие деталей.

Сводка использует текущие v2-счётчики. Для известной полной базы показывает до/после
и процент, рассчитанный по исходным байтам. При неизвестной или частичной базе
показывает полученный объём и неизвестное сокращение. Неизвестный объём не заменяет
нулём. Оценка токенов — округлённые UTF-8 байты/4; исходные счётчики не меняются.
Прежние оценки не используются в сводке. Recall остаётся отдельным показателем
в подробностях. Обработку команд и хранение статистики не меняли.
