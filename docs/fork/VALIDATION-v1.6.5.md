# Проверки v1.6.5 fix

Разработчик форка — HezeAI; Codex помогает с разработкой и проверками.
Сравнение с предыдущей публичной v1.6.0 и проверенной частной1.6.5-test.

## Проверки кода

- **644 JVM-теста**:490 app +154 terminal-emulator,0 failures/errors/skips.
  Модули terminal-view/termux-shared не содержат отдельных тестовых наборов.
- **119 Python-тестов**, плюс исполняемые shell fixtures проверки компонентов.
- **20 наборов Node/native CLI fixtures**: адаптеры/права/история, native Gemini
  hooks/socket, Claude2.1.296 и Codex0.163.0 с локальным синтетическим провайдером,
  OpenCode projection/settings, большие ответы истории. Облачные аккаунты и
  реальные API моделей эти fixtures не используют.
- Регрессионный тест до исправления воспроизвёл потерю фокуса ввода. После
  замены fullScroll на scrollTo сохраняются focus, draft, selection и IME
  composing span при новых сообщениях/карточках.
- Проверены стабильные идентификаторы/раскрытие карточек, RU/EN, исходные details,
  порядок сообщений/рассуждений/подтверждений, неизвестные статусы, ошибочное
  чтение SKILL.md и отсутствие выдуманных навыков для неизвестных событий.
- Проверена большая история:3MiB проходит только в chat-соединении; обычный
  клиент сохраняет2MiB,33MiB заголовок отвергается до выделения тела. Ошибка
  соединения фиксируется однократно, готовность после неё не изображается.
- Изолированный тест OpenCode воспроизвёл ложный MISSING при прежнем npm-пути;
  после изменения готовы direct/npm/private Node варианты, неправильная версия
  и реально отсутствующий CLI по-прежнему MISSING. Проверка не запускает установку,
  не меняет внешний PATH; сохранены consent/APT/hash/auth/rootfs guards.

## Ревью и логическая инспекция

Проверены границы группировки, обновление/раскрытие/детали, переключение сессий,
поздние ответы и пути отказа/восстановления. Общая карточка — проекция событий,
а не новый протокол выполнения или смена прав. Контекст навыка описывает
хронологическую связь; не доказывает успешное применение каждого навыка.
Права, команды, подтверждения, модельный контекст и механизмы остановки процессов
в этом выпуске не менялись. Обновление UI не заставляет клавиатуру получать
фокус по таймеру и не пересоздаёт весь терминал.

WorkspaceStore/schema8, серверное хранилище, backup/server helpers и форматы
истории не менялись относительно1.6.0; миграция/очистка для1.6.x не требуется.
Сохраняется ранее опубликованное предупреждение об удалении прежних приватных
local-AI данных при переходе с версий до1.5.3: см. release notes/update.json.
Не заявляется гарантия сохранения работающего процесса при Android-обновлении.

## Проверки разработчика и остающиеся ограничения

Разработчик подтвердил исправление фокуса ввода, оформление карточек у других
агентов и отсутствие прежнего предупреждения OpenCode в промежуточных сборках.
Финальный release имеет те же assets/native code с новым стабильным version/code.
Это не доказывает все жесты, DPI, клавиатуры, устройства, аккаунты или установщик.
Полный real-account цикл Claude/Vertex остаётся не подтверждённым.

Штатное терминальное окно Codex может сохранять старую строку проверки компонентов
и отображать mouse escape-коды при прокрутке после handoff. Исправление этого
отдельного дефекта отложено; он не выдаётся за исправленный чатный сценарий.
Для новых помощников завершите важные задачи и запустите ту же сохранённую
историю. Все варианты skill loading не распознаются, у Gemini нет выдуманного
skill-path из названия инструмента. Нативные transcript детали доступны по тапу.
