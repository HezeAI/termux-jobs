# Локальная проверка v0.2.9

Сборка для проверки на телефоне; на GitHub не опубликована.

Изменение: четыре внутренних списка (журнал, сохранённые сессии, команды, заметки)
используют WorkspacePanelScrollView. Запрет родительского перехвата устанавливается
при DOWN в dispatchTouchEvent до передачи касания дочерним карточкам; при
UP/CANCEL снимается. Nested scrolling отключён для этих панелей. Расчёт размеров
AdaptiveWorkspaceLayout, масштабирование и логика поиска не менялись.

Проверки:
- 186 существующих автоматических тестов прошли, failures=0, errors=0.
- assembleRelease, lintVitalRelease, bash -n scripts/build-local-arm64.sh и git diff --check прошли.
- ZIP APK целый. Подпись v2 проверена; сертификат совпадает с v0.2.8.
- Package com.termux, versionCode 1025, versionName 0.2.9, ARM64, minSdk 24, targetSdk 28.
- SHA-256 APK: eac92dd578a8086df0f12d68d76a16c96315f63efbfb7e7b1107e392f75e56a3
- Размер: 33854111 байт.
- Копия /sdcard/Download/Termux-Jobs-v0.2.9-arm64.apk перечитана и совпадает.

Ограничение проверки: несколько попыток нового теста физических свайпов в
Robolectric 4.4 не дали достоверного результата (упрощённые shadows обработки
касания/прокрутки). Этот неподтверждённый тест не включён в итоговые проверки;
существующие тесты не изменены. Полное воспроизведение поведения на устройстве
не выполнялось, поэтому отсутствие проблемы на телефоне пока не подтверждено.

После обновления поверх v0.2.8: открыть поиск на главной, оставить клавиатуру
видимой и провести пальцем по карточкам журнала и сохранённых сессий. Затем
повторить в «Команды/Заметки» для обоих списков, с пустым и заполненным поиском.
Внутри панели должен двигаться её список. В тесном окне общая прокрутка вне
панелей остаётся доступной. Скрыть клавиатуру и проверить размеры/выравнивание.
