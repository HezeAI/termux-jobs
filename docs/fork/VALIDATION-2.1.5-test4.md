# Приватный v35: основной1498 / резерв1499

2026-11-06. Основной:2.1.5-test4/code1498. Резерв:2.1.5-backup3/code1499,
из принятого старого интерфейса. Это тестовая выдача, без установки и публикации.
Статус основного: финальный APK и применимые проверки выполнены; телефонная приёмка нового интерфейса ожидается.

## Состав относительно stablev2.1.4

Сохранён полный согласованный состав1493–1496: хронология четырёх агентов,
порядок/доставка уточнений Claude с прежними ограничениями, контекст/лимиты,
таймеры, инструкции RU/EN, заметки, файлы/вложения/изменения с локальным поиском,
порциями истории, карточками и сохранением JPG/GIF через MediaStore.
Переработка v35 сохраняет настоящие PTY/адаптеры, авторизацию и историю.
Диктовка использует Android intent и вставляет текст только в черновик.

Добавления1498 по пунктам1–15 пользователя:

1. Общие настройки: убрать Advanced; уникальная автопроверка обновлений сохранена
   в Данных. About с лицензиями/ссылками — последний пункт Приложения.
2. AI agents: только инструкции/навыки. Удалены указанные глобальные входы,
   пользовательские инструкции, окружения и настройки моделей сохранены.
3. Restart после Open: подтверждение, захват выбранного запуска, привязка
   подтверждённого native chat ID. Неизвестный ID не подменяется новым чатом.
   Базовая запись сохраняется; X11 передаёт владельца новому handle без остановки.
4. Точки работы: отдельный видимый кадровый цикл, последовательная яркость,
   сохранение таймера; остановка скрытой декорации и при отключённых анимациях.
5. Меню ⋯:150мс alpha/scale с привязкой к кнопке, плавное закрытие,
   повторные нажатия защищены, закрывающаяся панель отпускает касания.
6. Новый агент: отдельный выбор, заголовок по агенту, Ubuntu AI, подготовка
   штатным механизмом после Create. Открытие/отмена не запускают установку.
7. Дополнительные клавиши: общая палитра обоих терминалов, прежние действия.
8. Sidebar: скрытый scrollbar; раскрытие высоты260мс с обратным ходом,
   без открытия чата и пересоздания списка.
9. Формы: терминальный выбор окружения/readiness сохранён; лишний launch-kind
   и диагностические/debug UI-входы убраны. Внутренние ошибки/журналы сохранены.
10. Терминальная форма: одна левая Cancel, без Presets; пресеты в sidebar.
11. Общая ограниченная волна касания; исключены терминал/X11, обычный текст,
    редактируемые поля и ползунки. Нажатие отменяется штатным touch-механизмом.
12. Composer: свободное пространство между левой и правой группами;
    model/microphone/send вместе. Лимиты двумя равными группами, неизвестные честно.
13. Выбор модели/рассуждения отдельно от лимитов/контекста; масштаб только глобальный.
    Живые права Claude/Gemini/OpenCode доступны отдельным пунктом sidebar;
    штатные guard/ack/persistence обработчики сохранены.
14. Arch Wiki между Notes и General settings, без терминального подменю.
    Stop только при busy + native cancellation token выбранного чата;
    INVISIBLE сохраняет геометрию. Подключение само по себе Stop не показывает.

15. Открытие sidebar только кнопкой шапки. Удалены edge detector и его system
    gesture exclusions; старый DrawerLayout также не перехватывает край после
    выделения текста. Закрытие свайпом влево/снаружи/Back сохранено. Текущая запись
    раскрывается до показа и прокручивается к названию, без вызова Open/Restart.
    Агентский терминал использует запись своего чата, X11 — выбранного терминала.

Дополнение к правам: отдельное окно «Права и подтверждения» для каждого агента.
Живые native switches Claude/Gemini/OpenCode сохраняют guards/ack; текущий режим
не подменяется сохранённой настройкой при отсутствии данных. Codex и остановленные
чаты показывают отдельно действующие данные (если известны) и настройки после
перезапуска. Уникальные Codex approvals и OpenCode external-path scope сохранены.
Старая полная форма сессии больше не содержит этих контролов; сохранение её полей
сохраняет параллельно изменённые права. Ни модель, ни лимиты в окно прав не входят.

Полная карта прежних34 областей: [REDESIGN-v35](REDESIGN-v35.md).
Оформление оценивается отдельно от функциональных тестов.

## Ограничения и проверка телефона

Проверено локально означает JVM/Robolectric, статический анализ или искусственные
события адаптеров. Это не телефонный тест. Прежняя пользовательская приёмка1493
не перенесена на1498. HTML v35 был отдельно отрисован в Firefox при440CSSpx;
макет не изменился. Достоверного Android-рендера/эмулятора для нового APK нет.

На телефоне остаются:

1. Сверка sidebar/компоновки/палитры с HTML, узкий экран и крупный шрифт.
   Раскрытие, быстрая смена направления, ⋯, ripple, системные анимации0×.
2. Чаты всех4 агентов: Stop до/во время/после запроса, подтверждение и повторы,
   точки/таймер, смена чата, черновик, возврат. Скрытие Stop без сдвига элементов.
3. Отдельные model/limits/permissions окна и свежие данные после смены модели,
   сокращения, переподключения. Без искусственного обнуления.
4. Новые формы, отмена без запуска, отсутствующие компоненты с подтверждениями;
   обе терминальные поверхности, ввод и дополнительные клавиши.
5. IME: Back с обоих краёв скрывает клавиатуру, сохраняет черновик и экран;
   без клавиатуры край не открывает меню. Кнопка раскрывает текущую запись;
   закрытие свайпом/снаружи/Back, в том числе из терминала агента и X11;
   X11/поворот/возврат и размеры. Restart проверять только на отдельной
   искусственной сессии с разрешением владельца; рабочие здесь не перезапускались.
6. Переиспользованные история/предыдущие сообщения, вложения/поиск/карточки,
   галерея и инструкции: проверить отсутствие визуальных регрессий.

Не закрыты: обрывы больших запросов/накопление изображений, исходный эпизод
уточнения Claude без его событий, непроверенные Android backup/crash/внешние
маршруты. Не добавлены CLI fork, экспериментальный контекст, auto-compaction,
MCP/plugins. Версии CLI, лимиты отправки, native графика и Components не менялись.
Пакет/подписант/схема8 сохранены; обновление данных и будущий откат на устройстве
не проверены. Резерв1499 не устанавливать заранее перед1498 и не считать копией данных.
[Отдельный отчёт1499](VALIDATION-backup-1499.md).

Уточнение жестов15 заменяет прежнее требование edge-opening: оба края с IME остаются системными. Реальную жестовую навигацию Android ещё должен проверить пользователь.

Итог: полный regression-2 и успешный целевой повтор рассматриваются вместе.
Не заявляется, что первоначальный полный прогон был безошибочным. Между ними
и упаковкой production inputs не изменились: исправлены только тестовые входы,
добавлены проверки. XML, точные входы и причины отказов сохранены отдельно.
