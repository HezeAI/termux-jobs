# Проверка v1.3.2

Разработчик HezeAI, Codex помогает с разработкой. Релиз v1.3.2.

## Область

Просмотр команды/заметки из звёздочки: «Назад», выбранная вкладка и поиск;
системная отмена; сохранение черновика. База129 карточек с первоисточниками,
три новых совета без исполняемой команды. Синхронизация не реализовывалась.

## Проверки

437 JVM-тестов прошли, ошибок/пропусков0. Сборка успешна.
APK: Termux-Jobs-v1.3.2-arm64.apk, 36576346 байт.
SHA-256: `76bb3399711ca5cd4845246784280e2ca73414b8cd0c395436bb9d1845f4da6d`.
com.termux, v1.3.2/code1085, ARM64, min24/target28, release без debug.
Прежний сертификат `dd37d983cd2496ebe49c7e88ddbc0088f311d38b8a8503e4392c81b48a11a644`, APKv2 проверена.
ZIP CRC, пути, ABI, выравнивание и совпадение исходников/staging проверены.
Native и server-agent совпадают с базовой1.2.2. Ограниченный скан известных
форматов секретов не выявил совпадений. update.json сформирован из финального APK.
Новая rollback-сборка не создавалась; публикация разрешена разработчиком после передачи сборки на проверку.

Первый прогон выявил два несоответствия тестовых ожиданий: прежнее число
карточек с community-источниками и переключение языка без штатного apply.
Ожидание обновлено. Второй прогон подтвердил возврат на обоих языках, но
выявил влияние языка теста на остальные проверки; новый тест изолирует ресурсы
перевода и восстанавливает прежнее значение. Production-код не менялся. Логи сохранены.

## Инспекция

Возврат повторно показывает прежний picker и восстанавливает позицию списка.
Поиск/вкладка остаются в замыкании picker, а просмотр не отправляет ввод и не
создаёт терминал. Редактирование и удаление не менялись по сравнению с1.3.1.
Форматы данных не меняются, окружения/службы/Bridge не затрагивались.

Требуется проверка разработчиком на устройстве: RU/EN, прокрутка списка и
возврат в оба типа карточек, клавиатура/жесты. Мок-тесты не доказывают Android IME.
Советы проверены по источникам, не исполнены на каждой прошивке. XDA частично
недоступен напрямую (403); полного чтения форума не заявлено.
