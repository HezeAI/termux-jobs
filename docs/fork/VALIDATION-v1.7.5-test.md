# Проверки 1.7.5-test / code1220

Сборка для проверки разработчиком; GitHub не публикуется.

## Изменения

- Исправлена подгрузка предыдущих сообщений Codex: отдельные native страницы,
  локальные окна большого turn, очередь нажатия при занятом polling, конец
  истории, повтор после ошибки и сохранение строк после свежего snapshot.
- Прежние размеры/ключи AgentChatCache и немедленное восстановление чата с
  черновиком сохранены. Обрезанный кэш сбрасывает только frontier пагинации.
- Новый чат не связывается с ID, пока статус явно сообщает materialized=false.
  Ошибка недоступной истории даёт понятное восстановление без скрытой подмены ID.
- Явный выбор чата в редакторе защищён от старого процесса, включая поздний
  callback и повторные опросы; защита переживает reload библиотеки. Новый запуск
  получает отдельный socket, копия профиля не наследует блокировку.

## Доказательства и пределы

Фактический native Codex app-server в отдельном fixture воспроизвёл -32600
thread not loaded при чтении ещё не сохранённого нового чата из второго процесса.
После двух synthetic turns тот же thread читается. Проверены streaming,
model/effort, native earlier cursor; внешние model/account API не использовались.
Останавливались только созданные fixture-процессы, пользовательские не менялись.

Node-проверки: 250 текущих и1200 прежних элементов;1200 элементов первого turn
после live trimming; окна не сдвигаются polling; истёкший cursor, пределы окна;
wire split3MiB/отказ33MiB; безопасные сообщения ошибок. Статус проверен на
несохранённой/пустой/существующей истории. Существующие проверки Gemini,
Claude и OpenCode проходят, их bridge assets не изменены.

Python-код по сравнению с проверенной1.7.4 не менялся: используются результаты
171 Python-теста той сборки; повторный запуск в1.7.5 не заявляется.

## Совместимость

Пакет com.termux, Android8+, ARM64, versionCode1220 выше1219. Сертификат прежний.
Схема8 сохраняется, новое поле защиты необязательное, пользовательские данные,
авторизация и native история автоматически не удаляются. Совпадение пакета и
подписи не подтверждает все сценарии миграции на устройстве.

После установки правки JS получит новый процесс соответствующей Codex-сессии.
Для проблемного ID без истории нужно явно выбрать новый/другой существующий
чат перед запуском. Выбор New защищён от статуса старого запуска, но не
перезапускает его автоматически. Проверить разработчику: проблемный пресет
demo-chat с каталогом DEMO-PROJECT; подгрузку нескольких страниц, возврат
во вкладку, сохранность черновика и фокуса. UI mocks не подтверждают жесты/IME.
