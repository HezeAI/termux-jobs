## Изменено

Общий AgentChatView/AgentMarkdown связывает локальный URLSpan и карточку с копией
профиля исходного чата при отображении. Идентификатор, среда и канал исходного
профиля сохраняются. Поздний тап, смена чата и завершение чтения не подменяют
источник текущим выбранным окружением. Развёрнутый Markdown использует тот же путь.

ChatAttachmentUi читает файл через существующий независимый ProjectFiles-транспорт.
При повторном открытии локальной ссылки одиночный stat формирует ключ кеша, чтобы
переиспользовать неизменённый файл. Команда не вводится в рабочий терминал агента.
Новые опросы CLI, запросы модели, движок чатов и библиотеки не добавлены.

HTML/HTM и GIF независимо от общего типа карточки идут в общий ChatFileViewer.
У HTML включён JavaScript для встроенных скриптов/кнопок; GIF передаётся WebView
как image/gif, вместо Bitmap первого кадра. Загрузка начинается после получения
размеров окна; callback первого кадра запрашивает перерисовку. Закрытие уничтожает
только этот WebView; смена чата не закрывает просмотр исходного файла.

Изоляция: случайный отдельный HTTPS-origin, перехват только одного файла,
запрет остальных запросов, CSP, отключённые file/content/universal access,
сетевые загрузки, DOM storage, новые окна, выбор файлов и разрешения устройства.
JavaScript-интерфейса к приложению нет. Внешние скрипты и соседние файлы не
подгружаются: используйте автономный HTML со встроенными ресурсами.

Кнопка сохранения оригинала оставлена. Пустой, недоступный, повреждённый файл,
неподдерживаемый предпросмотр, HTTP-ошибка виртуального документа и сбой WebView
получают видимый отказ. Лимиты предпросмотра: HTML4 МиБ; GIF16 МиБ и16 миллионов
пикселей холста. Превышение лимита предпросмотра не запрещает сохранение уже
прочитанного оригинала. Прежние пределы передачи: изображения100 МиБ, остальное5 ГиБ.
