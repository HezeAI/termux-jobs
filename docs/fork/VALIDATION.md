## Выполненные проверки

- Изолированный Gradle-прогон завершился BUILD SUCCESSFUL: 176 тестов, 0 ошибок, 0 пропусков; lintVitalRelease прошёл.
- Проверены ZIP CRC, версия, пакет, ABI и подпись APK v2.
- Проверены JSON-формат v5, миграция старых форматов, заметки, журнал 50 и сохранение повторов.
- UI-тесты покрывают просмотр текста, поиск, фильтры, CRUD заметок, выбор/сохранение сессий и стабильность страниц при обновлении title.
- Для звёздочки проверены две вкладки, поиск по трём полям, независимые запросы, избранные первыми, пустые результаты и библиотека, многострочная вставка без отправки/записи в журнал.
- Для адаптации проверены ширина 320dp, системный fontScale 1.6, минимальная высота панелей, внешняя прокрутка в тесном окне, возврат к независимой прокрутке при увеличении высоты.
- Код/ресурсы проверены в изолированной копии `.verification/arm64`. Инструменты: Gradle 7.2, JDK 11, SDK 30, Build Tools 30.0.3, локальный ARM64 aapt2. Неизменённые JNI-библиотеки переиспользованы из ранее проверенной локальной сборки.
- Синтаксис сценария сборки и git diff --check проверены.

## Практические пределы проверки

Пользователь подтвердил работу масштабирования v0.2.5 на Samsung. Это не является полным прогоном v0.2.6 на всех устройствах. UI-тесты не запускают настоящие shell/PTY, bootstrap или сервисы. Агент APK не устанавливал и работающую среду не менял.

На устройстве дополнительно проверять чистую установку/bootstrap, совместимое обновление с сохранением данных, Ubuntu и последовательности шагов, ввод/клавиатуру, два терминала под нагрузкой, заметки и их вставку, поворот/разделённый экран и ограничения Android на фоновые процессы. Профили не восстанавливают живые процессы. Откат на APK, не поддерживающий JSON v5, может оставить библиотеку только для чтения.
