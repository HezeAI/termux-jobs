# v1.4.29-test — experimental Qwen native tool format

Opt-in in local session/preset Settings → Engine settings → Model communication format → Native Qwen format (testing). Current JSON remains default for every existing/new profile. Initially supported only for catalog Qwen3.5 2B with llama.cpp; imported models, other catalog models and LiteRT retain JSON. Switching reloads the model with the same chat; compare with a new chat to avoid earlier false access denials. Keep CPU/threads/location unchanged; tool schemas consume context (8192 recommended, not selected automatically).

The adapter implements the verified embedded Qwen3.5 text/function-call subset: function schemas, tool_call/function/parameter blocks, assistant action history and grouped tool_response messages. It does not execute arbitrary Jinja, replace model weights, enable vision, or guarantee model compliance. Prompt token counting and generation use the same adapted messages in Android/Termux/Ubuntu runtimes. Complete standalone calls only; mixed prose/examples, multiple calls, duplicate/unknown parameters and malformed types fail closed. Literal thinking tags inside file contents are preserved. Historical JSON examples are never promoted to calls without recorded action metadata.

Parsed requests enter the existing authorization, project-path, confirmation and tool execution pipeline. Permissions are not broadened. Chat has no tools; read has no write/command; scoped full access has no arbitrary command. Installation confirmation requirements remain. Native buffers, CPU libraries, other agents and ordinary terminal rendering are unchanged. Actual success of natural-language tasks is a device test, not established by parser fixtures.

Compatibility: com.termux, versionCode1135, versionName1.4.29-test, existing signing certificate. Optional localProtocol field defaults json. No automatic data/model/environment reset. Switching protocol makes a custom rights prompt require review/reset. Older builds may discard the optional setting when rewriting the library. Finish important tasks before updating because Android can terminate app processes. No GitHub publication in this test delivery.
