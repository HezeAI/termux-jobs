# Проверка v1.7.96-x11-test / code1311

Второй необязательный вариант Touch Workspace под прежней галочкой Kali,
только базовый Termux XFCE. [Устройство и использование](TOUCH-WORKSPACE.md).

## Результаты

- 58 Python-проверок: прежнее оформление, повтор/обновление/выключение,
  исходные XML и ручные изменения, битые ZIP/XML, symlink; новый переход
  Kali → Touch → Kali возвращает параметры только Touch. Проверены оба ZIP,
  файловый менеджер/ярлыки GPU и проверки базовых компонентов окружений.
- 78 JVM-проверок: прямой тап с абсолютным позиционированием до нажатия,
  свайп без случайного клика, правая кнопка, двойной тап/drag, отпускание при
  отмене/втором пальце и отсутствие отложенного удержания. Сохранено покрытие
  прежней сенсорной панели. Обе галочки взаимоисключающие, сохраняются,
  блокируются в busy; backend отклоняет guest/mixed/live-запросы до смены
  состояния. Проверено фреймирование ручного запроса клавиатуры с nonce;
  снимки гостевых окружений не сбрасывают счётчик Termux для повторного вызова.
- C собирается с Wall/Wextra/Werror под Android ARM64. Настоящий Bionic ELF
  загружает GTK и выполняет self-test без LD_LIBRARY_PATH благодаря своему
  RUNPATH. Код GTK-карточек также собран с offscreen-окном и отрисован через
  отдельный локальный Broadway: размеры, CSS, фон, кнопки и нижняя панель
  просмотрены в preview.png/dock-preview.png. Это не проверка живого XFWM или
  Android SurfaceView/жестов на телефоне.
- Session-тест подтверждает, что вспомогательный процесс Touch стартует
  напрямую в той же группе, что сеанс; постоянный autostart не создаётся.
  В C нет setsid/daemon/сканирования PID. Существующая остановка guardian
  не изменена. Новое окно/панель живут только во время своего стола.
- Релевантное ревью: общие пакеты пополнены только в ветке Termux (exo,
  gtk3, libx11); приложения запускаются literal argv или штатным GAppInfo,
  пути не вставляются в shell. Тема проверяется по SHA-256, собственные XML
  и assets восстанавливаются через прежний осторожный helper. Проверены
  запуск, повтор, смена тем, отмена жеста, отключение, ошибка ресурсов и
  границы других окружений/агентов. PNG декодируется один раз, постоянных
  таймеров перерисовки нет.
- Release APK, CRC, com.termux/version/minSDK/ABI, v2-подпись и SHA прошли.
  libXlorie и остальные прежние native-библиотеки побайтно совпали с v1.7.95.
  JNI-контракты28/1/5 совпали. DEX:13561 definitions; обязательные runtime
  типы найдены, прежние31 unresolved имеют существующие review notes.
  В assets добавлены только ZIP Touch и свой executable40720 байт; изменены
  style.py, session.sh и native-desktop.sh. Личные ключи/конфиги/адрес
  Selectel не включены. Полный результат в apk-audit.json.

## Совместимость и оставшаяся проверка

com.termux и прежний сертификат сохранены, code1310 → 1311. Очистки данных и
миграции историй нет. Старый выбор Kali сохраняется, Touch по умолчанию выключен.
Свой экран не заменяет интерфейсы приложений Linux. Разрешение X11 влияет на
физический размер элементов; предусмотрены масштабирование и прокрутка.

На телефоне проверить запуск Touch, прямые тапы/свайп/hold/drag, программы,
возврат Home из окна приложения, рабочие места, Keyboard в поле приложения,
сворачивание и остановку своего стола. Затем Kali и выключение обеих тем.
Реальное размещение dock/strut в XFWM, Android IME, ориентация и установка на
чистом устройстве пока не подтверждены. GTK-preview и Robolectric этого
не доказывают; минимальная следующая проверка — перечисленные действия
разработчика после обновления APK.
