# Частная v1.7.56-x11-test / code1271

## Изменение

Карточка Firefox показывает PRoot и DNS HTTPS для всех подключённых сред:
Termux, Ubuntu, Debian, Alpine. supportsFirefox отделён от прежнего перечня
общего обслуживания/исправления ярлыков. Обычная Ubuntu поддерживает Firefox,
агентская ubuntu-ai исключена. Удалена устаревшая рекомендация Ubuntu X11 Test.

APT-среды используют тот же профильный x11-firefox-dns.py, что native-варианты.
Фиксированные операции выполняются через выбранный proot root, status только
читает профиль. Неизвестное новое состояние сбрасывает доверие к старой галочке.
PRoot использует существующий wrapper/журнал; его границы не расширены на другие
приложения. Действуют прежние проверки ссылок, внешних путей, локальных правок,
размеров и восстановление только записанных предпочтений.

## Проверки и границы

Shell fixtures проверяют выбранные Ubuntu/Debian, применение/отключение DNS,
проверку статуса без APT/установок и отсутствие обращений к ubuntu-ai.
Python fixtures проверяют обратимость DNS/PRoot, локальные изменения и внешние пути.
UI-тест создаёт Firefox-карточки четырёх сред и проверяет обе галочки/действие,
сохранение отражаемого состояния до подтверждённого ответа.
ProgramOutput проверяется на известный → неизвестный → выключенный DNS.

Никакие установленные профили Firefox/окружения/агентские сессии проверками
не изменялись. Пользовательская проверка обеих галочек в обычной Ubuntu и
Debian требуется; существующие результаты Termux/Alpine не доказывают её.
Размеры окна не менялись. GPU/CPU/композитор и запуск стола сохранены.
Пакет/сертификат прежние, versionCode1270 →1271; сброс/миграция данных не нужны.
GitHub-публикация не выполняется. Итоги сборки/тестов/аудита дополняются ниже.

## Дополнительные этапы запуска

В существующий ограниченный цикл x11-ready.py добавлены однократные markers
wm-observed, panel-visible, desktop-visible, session-idle. Времена в журнале
означают первое наблюдение проверкой, а не точное время создания окна.
Новых запросов/периодических задач нет; условия готовности, таймауты и ручной
вход сохранены. Видимость окон по metadata не доказывает отрисовку пикселей.
Ветка session-idle может завершиться без отдельных markers панели/фона;
отсутствие marker само по себе не означает отсутствие окна.
Синтетический тест проверяет однократность markers и неизменное число probes.
Разработчик описал появление элементов на глазах после ручного открытия:
задержка не считается одним только ожиданием UI. Причину ещё предстоит уточнить.
