# v1.1.3 — резервное копирование (тестирование)

Локальный APK для проверки; на GitHub ещё не опубликован. Последний публичный
релиз — v1.1.0. Включены выборочный бэкап и исправления локальных v1.1.1/1.1.2:
раздельные группы Termux/Ubuntu, проекты/Codex/SSH, online SQLite snapshots,
проверка зависимостей, недоступные компоненты и обязательное согласие.

Новые изменения: время, полоса текущего этапа, сменяющийся текущий путь; все
окна бэкапа защищены от закрытия тапом снаружи. Выбор gzip/pigz, уровни1/3/9,
по умолчанию gzip3. Для pigz предложена установка только после согласия,
в фоне приложения, с проверкой успеха. pigz ограничен4 потоками. Современный
proot-distro backup stdout сжимается выбранным методом; legacy сохраняет штатный.
Итог создания — «Бэкап создан и проверен» и путь, названия «(тестирование)».
Включены индикаторы проверки/скачивания обновления из v1.1.2.

## Совместимость

com.termux, versionCode1060, прежний сертификат; обновление поверх совместимо
по идентичности APK. Очистка команд, заметок, пресетов и истории не требуется.
Библиотекаv8 и manifestv1/v2 сохранены. Выборочным бэкапам нужен принимающий
клиент v1.1.1+ либо доверенный restore.sh. gzip/pigz создают обычный .tar.gz;
для восстановления pigz не нужен. Установка pigz может добавить зависимости
в общую среду Termux и выполняется исключительно после согласия пользователя.
Android может остановить процессы при установке APK; завершите важные задачи.

## Ограничения

Не универсальное восстановление1:1. HOME/PREFIX/data-only извлекаются отдельно;
нужна ручная активация, зависимости/авторизацию проверяют после восстановления.
Живые процессы/Android Keystore не переносятся. Неизвестные объёмы показаны
анимацией, не ложным процентом. Нет foreground service: оставьте приложение
открытым до окончания бэкапа/установки pigz. Физическая проверка поведения окон,
установки pigz и реального переноса остаётся за пользователем.
