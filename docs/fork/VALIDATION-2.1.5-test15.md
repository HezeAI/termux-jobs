# 2.1.5-test15 /1510 — карта изменений

1. Чат сохраняется под выезжающим AgentTerminalScreen. Его composer не
перестраивается в терминальный при переключении. Экран терминала включает
своё поле ввода. Существующие ограничения повторного открытия/закрытия сохранены.
Причина прежнего исчезновения подтверждена кодом: явный GONE и условие cover,
зависящее от отсутствия terminal, плюс перестройка общего composer.
Данные лимитов терминала получает тот же populateComposerLimits, что чат;
для неизвестных значений остаётся «Нет данных». Движки и PTY не менялись.

2. Плюс21dp с линией2 вместо19dp/1.6; отдельный vector только для composer.
Вместо значка — «Заметки», дополнительный промежуток4dp. Правые модель,
рассуждение, сохранённый промежуток и отправка используют прежнюю раскладку.
Меню«+» имеет локальную плотность0.8: текст/иконки/строки/отступы уменьшаются вместе.

3. Троеточие использует локальную плотность1.3 относительно текущего sidebar.
Обработчики/условия прежние; popup ограничен доступной областью, внутри ScrollView.

4. Выбор агента по центру, заголовок «Выберите агента», без отмены/крестика.
Форма появляется поверх ещё видимого выбора с переходом справа налево.
Кнопка в заголовке «Создать чат» с векторной стрелкой вызывает существующий
обработчик валидации/сохранения/запуска. Нижние кнопки скрыты. Системная отмена
закрывает форму; исходные проверки пути/названия/активного разговора сохранены.
