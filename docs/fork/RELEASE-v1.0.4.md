# Termux Job’s v1.0.4 — пакеты и редактор файлов

Этот выпуск расширяет возможности основного форка после **v1.0**. Все изменения
локальных сборок v1.0.1–v1.0.3 входят в релиз.

## Менеджер пакетов Termux и Ubuntu

Удерживайте название сессии → **Пакеты**. Доступны три списка: **Установленные**,
**Доступные**, **Обновления**, поиск и версия каждого пакета. Каталог берётся из
настроенных репозиториев выбранного окружения; его можно перечитать или обновить.

В карточке пакета есть описание, **Подробнее** с полным текстом и **Выбрать версию**.
Предлагаются версии, доступные в подключённых репозиториях; для понижения показывается
предупреждение. Описание автора сохраняет язык репозитория.

Установка, обновление, удаление и обновление каталога требуют подтверждения. Выберите
**текущую сессию со свободным Bash** либо **новую сессию того же окружения**. Если
работает Codex, редактор или другая команда, выбирайте новую. Приложение не определяет
автоматически, какая программа принимает ввод. APT показывает зависимости и свои
запросы подтверждения; автоматического -y/hold/pin или добавления репозиториев нет.

**Пакеты сохраняются в выбранном окружении и доступны всем его сессиям**, даже после
закрытия вкладки без сохранения. Termux и Ubuntu имеют отдельные базы пакетов.
Менеджер предназначен для APT/dpkg; он не ведёт список установок pip/npm/Cargo.
SSH-пакеты пока не поддерживаются.

## Улучшенный файловый менеджер

В меню текстового файла после **Просмотреть** появилась кнопка **Редактировать**.
Можно редактировать **Markdown (.md)** и другие распознанные текстовые файлы:
моноширинное многострочное поле, **Сохранить**, **Отмена**, подтверждение потери правок.
Enter переносит строку.

Редактор поддерживает UTF-8 до **256 КБ**. Неудачное чтение не открывает пустой документ;
ошибка сохранения оставляет введённый текст в окне. Перед записью проверяется снимок
файла, чтобы обнаружить внешние изменения. Запись использует временные файлы рядом,
сохраняет права/владельца и заменяет файл атомарно при поддержке окружения.

Работает через выбранное окружение файлового браузера: Termux, Ubuntu или SSH.
Нужны Bash/GNU-совместимые инструменты и право записи в папку. Ссылки и hardlinks
не редактируются. Проверка перед заменой оптимистическая, без эксклюзивной блокировки
внешних программ; одновременно изменять тот же файл другим процессом не рекомендуется.
Буфер не автосохраняется при уничтожении приложения Android.

## Команды, заметки и интерфейс

- Действия **избранное / редактировать / удалить** перенесены в окно просмотра записи;
  отдельные троеточия команд и заметок убраны. Вставка команды в терминал сохранена.
- Кнопка **▾** рядом с категорией открывает весь список при создании и редактировании.
  Существующую категорию можно выбрать, новую — вписать вручную.
- Кнопки менеджера пакетов выровнены; подписи подстраиваются в одну строку.
- Шестерёнка получила плашку как глобус, с отдельным отступом между кнопками.
- Все новые меню и сообщения доступны на **русском и английском**. Пользовательский
  текст, содержимое файлов, названия/версии пакетов и вывод APT не переводятся.

## Установка и проверки

APK: **Termux-Jobs-v1.0.4-arm64.apk**, Android **7+**, **ARM64 / arm64-v8a**.
Пакет **com.termux**, versionName **1.0.4**, versionCode **1041**; прежний сертификат.
Можно обновить предыдущий APK нашего форка с той же подписью поверх. Формат библиотеки
остаётся **v8**, миграция схемы с v1.0 не менялась. APK с другой подписью несовместим.
Ubuntu, Codex, проекты, авторизация и пользовательские ключи в APK не входят.

**254 теста прошли**, сборка release/lintVital, локализация 472 строк и проверки
ZIP/подписи/версии/ABI/SHA-256 выполнены. Пользователь одобрил сборку и публикацию;
подробный протокол всех сценариев на устройстве не предоставлен. Агент APK не
устанавливал. [Проверки и ограничения](VALIDATION-v1.0.4.md) · [Руководство](USAGE.md).

Основан на [Termux v0.118.3](https://github.com/termux/termux-app/tree/v0.118.3).
Исходники и уведомления об авторстве сохранены, [GPLv3](../../LICENSE.md).

## English

Termux Job’s v1.0.4 adds an environment-aware **APT package manager** for Termux and
Ubuntu: installed/available/upgradable lists, search, descriptions, available versions
and downgrade warnings. Confirm actions in an idle Bash session or a new session of
the same environment. Packages remain installed after closing a terminal tab.

The **file manager now includes a text editor**, including Markdown: UTF-8 up to 256 KB,
multiline input, Save/Cancel, dirty-exit confirmation, external-change checks and
same-directory atomic replacement where supported. Termux/Ubuntu/SSH use the existing
file transport; shell tools and directory permissions are required. No exclusive
lock or crash-proof unsaved buffer is promised.

Command/note actions moved into their preview dialogs. Category selection has an
explicit button and still accepts new text. Package buttons align consistently;
the settings icon uses a separate tile next to the language globe. New UI is RU/EN.

ARM64, Android 7+, com.termux, versionName 1.0.4/versionCode 1041, same certificate
for in-place updates, unchanged library schema v8. 254 tests passed; see validation
for device-test limitations. Termux attribution and GPLv3 are retained.
