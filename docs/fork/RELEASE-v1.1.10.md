# v1.1.10 — локальная сборка, не опубликована

Меню выбранного сервера упорядочено: первым пунктом теперь идут
«Настройки агента», внутри — проверка состояния, отдельное удаление и компоненты.

- «Проверить состояние агента» выполняет read-only проверку по SSH. Если агент
  найден, показывает «Агент установлен», кнопку удаления и OK. Если файл агента
  отсутствует и доступен Python3.8+, предлагает установку. Ошибка сети/неполный
  ответ не выдаются за отсутствие агента и не открывают установку.
- Известное состояние учитывается по успешному ответу агента и свежей проверке;
  перед новым предложением установить состояние проверяется. Отдельная защита
  не позволяет повторно установить известный установленный агент. Установщик
  по-прежнему не перезаписывает существующий файл на сервере.
- «Удалить агента…» остаётся отдельным пунктом настроек, а также доступно после
  проверки установленного агента. Прежнее подтверждение и блокировка активными/
  неподконтрольными задачами сохранены. Проверка состояния ничего не удаляет.
- В отсутствие агента основной экран предлагает проверку состояния вместо
  безусловной установки. Для отсутствующего агента/неподдерживаемого Python
  автопрос RPC не продолжается до рабочего подключения.
- «Отключить мониторинг» переименовано в «Отключиться». Это прекращает опрос,
  закрывает клиентское подключение/медиатуннель, но не останавливает агент,
  серверные задачи/службы или отдельные SSH-терминалы. При повторном открытии
  сервера автоподключение действует согласно настройке профиля.
- Между ! и троеточием выбранного сервера добавлен отступ8dp с отдельными
  квадратными48dp touch targets. RU/EN сохранены.

## Совместимость

Библиотекаv8, пресеты/AI/серверные профили и данные не мигрируют/не сбрасываются.
Agent.py, protocol, SFTP/editor/player/native unchanged; переустановка агента
не нужна. Нет автоустановки/удаления от открытия меню. Текущее мониторирование:

агент собирает с шагом30с и выполняет ранее запущенные задачи независимо.

[VALIDATION-v1.1.10.md](VALIDATION-v1.1.10.md).
