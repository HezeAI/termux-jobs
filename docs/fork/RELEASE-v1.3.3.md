# v1.3.3 — Обязательное обновление

Исправлена ошибка нашей сборки: несовместимые варианты Guava оставляли APK без
классов, необходимых Termux для удаления файлов. Из-за этого приложение могло
падать при очистке временной папки и обработке старого crash-log, включая повторные
вылеты при запуске. Сборка и JVM-тесты ранее не выявили проблему состава APK.

- Зависимости согласованы; восстановлена штатная библиотечная реализация.
- Добавлены проверки классов в готовом APK и регрессионные тесты файловых операций.
- **Теперь требуется Android8.0 или новее. Android7.0/7.1 больше не поддерживается.**

**Обновляйте поверх, без удаления приложения и очистки данных.** Прежние пакет
и подпись, code1086. Форматы команд, заметок, пресетов и настроек не меняются;
среды Ubuntu/Termux не переустанавливаются. Смена источника или другая подпись
не поддерживают установку поверх.

[Проверки](https://github.com/HezeAI/termux-jobs/blob/v1.3.3/docs/fork/VALIDATION-v1.3.3.md).
