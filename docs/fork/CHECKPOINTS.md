# Локальные точки возврата

Эти сохранения не являются публикацией на GitHub.

- `checkpoint/v0.2.9`: текущий исходный код с SSH-авторизацией и исправлением вложенной прокрутки. Пользователь подтвердил работу прокрутки на телефоне.
- Публичный `v0.2.6`: точный исходный код версии до добавления SSH · сервер.
- v0.2.7: первый SSH · сервер, без поля пароля и выбора файла ключа. Сохранён оригинальный APK; исходники восстановлены отдельно и обозначаются как реконструкция, а не точный исторический снимок.

Исходные APK сохраняются с исходными versionCode: 1022 (v0.2.6), 1023 (v0.2.7), 1025 (v0.2.9).
Android обычно не разрешает установить меньший versionCode поверх большего.
Для возврата нужно собрать нужный исходный код с versionCode выше установленного,
с тем же package `com.termux` и тем же ключом подписи. Название версии может
оставаться старым: Android сравнивает прежде всего числовой versionCode.

Важно: v0.2.9 использует формат библиотеки 7; оригинальная v0.2.7 — 6, v0.2.6 — 5.
Одного повышения versionCode недостаточно для сохранения доступности библиотеки:
при реальном возврате нужно отдельно подготовить совместимость формата данных.
Старые версии отказываются редактировать неизвестный формат и не стирают его.
Нельзя просто понизить номер формата или запускать SSH-профили как локальные команды.
Перед будущим возвратом следует сохранить текущую библиотеку и подготовить адаптер
с сохранением команд, заметок и обычных сессий; SSH-профили в v0.2.6 должны оставаться
недоступными для запуска. Сохранённые пароли Keystore не переносятся обычным архивом.

Ключ подписи находится в `.signing/fork-debug.jks`, дополнительная приватная локальная
копия — в `build/checkpoints/private-signing/`. Ключ не включается в публичные Git-файлы,
архивы исходников или копии для Download. Для сборки нужен этот ключ и существующие
локальные инструменты `.tools`; сами инструменты не входят в архивы исходников.

Для точного возврата к поведению оригинального APK предусмотрен скрипт
`scripts/repack-checkpoint-apk.py`: он повышает только versionCode и подписывает
прежним ключом; весь остальной код и ресурсы проверяются на совпадение.
Проверочный вызов: `python3 scripts/repack-checkpoint-apk.py 0.2.7 1026`.
Флаг `--prepare-apk` создаёт APK в `build/recovery/`, но ничего не устанавливает.
Номер должен быть выше установленного на момент возврата. Совместимость данных
готовится отдельно перед реальным откатом. Проверочная переподпись 0.2.7 успешно
пройдена; APK намеренно не включён в Download как готовое обновление.
