# v1.2.2 — обновлённая диагностика сессий и серверов

- Новая диагностика всех типов сессий: сводка, события, обычный/подробный режим без перезапуска.
- Диагностика серверов: длительности операций и очередей, результаты и передачи без дополнительных запросов.
- Остановка/возобновление журнала, копирование и экспорт отчёта в Download.
- Галочка в карточке сервера: продолжение опроса вне вкладки каждые 30 секунд. Внутри — 10 секунд; в фоне приложения пауза.

Прежний пакет и сертификат, versionCode 1073. Очистка пользовательских данных не требуется.
Новые настройки сервера необязательны; обновление агента не требуется. Выбор подробного режима в окне действует для текущего процесса сессии.

[Использование и ограничения](https://github.com/HezeAI/termux-jobs/blob/v1.2.2/docs/fork/DIAGNOSTICS.md).

[Результаты проверок](https://github.com/HezeAI/termux-jobs/blob/v1.2.2/docs/fork/VALIDATION-v1.2.2.md): 402 теста, сборка и аудит APK пройдены; проверка жестов, DPI, разрешений и реальной сети на устройстве не заменяется JVM-тестами.

### Compatibility / Совместимость

Same package and signing certificate, versionCode 1073. No data reset required. Server preferences are optional; no server agent update required. Runtime detail mode does not restart the session or change agent permissions.

APK: Android 7+, ARM64. Если установлена локальная v1.2.2, повторно скачивать этот же APK не нужно.
