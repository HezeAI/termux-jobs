# Частная v1.7.68-x11-test / code1283

## Причина и исправление

На записи экрана разработчика установка Ubuntu немедленно завершалась
ENVIRONMENT_DOWNLOAD_PermissionError. В отдельной ограниченной фоновой
команде Termux воспроизведён errno13: O_RDONLY|O_DIRECTORY на /data.
Ubuntu/proot не воспроизводила ограничение Android на чтение предков.
Это регрессия нового загрузчика67, до начала сетевого запроса.

Исправлен directory(): системные предки открываются O_PATH|O_DIRECTORY
с O_NOFOLLOW для каждого компонента, конечный приватный каталог затем
открывается O_RDONLY. Путь закреплён файловыми дескрипторами; запрет ссылок,
проверки типов, SHA-256, блокировка, отмена и защита существующего rootfs
сохранены. Дополнительных Android-разрешений не требуется.

## Проверки

- До исправления host-проба Termux: PermissionError на data. После: opened=true.
- 17 тестов загрузчика прошли в Ubuntu и отдельно нативным Python Termux.
  Включены реальные loopback HTTP Stop/Range/resume/200/206/416/503,
  сохранение одной части, SHA-256, ссылки, проверка прохода без чтения предков.
- Все восемь OCI-alias проверены на отдельные state/lock каталоги, Стоп,
  возобновление и передачу правильного image/name native CLI. Native install
  в этих тестах заменён фикстурой, системы телефона не устанавливались.
- Arch отдельно проверен на закреплённые URL/SHA и передачу открытого
  дескриптора native install. Сам механизм fetch покрыт общими HTTP-тестами.
- 20 изолированных runtime-тестов прошли: routing, legacy fallback,
  существующий/незавершённый rootfs, ошибки и недопустимые alias.
- Нативный API установленного proot-distro5 проверен с сетевыми/cache
  фикстурами внутри репозитория, без распаковки слоёв в системы телефона.

Проверка исходников: изменён только общий обход каталогов загрузчика,
версии и документация; Java/UI/остановка процессов не менялись относительно67.
Логически проверены открытие/закрытие дескрипторов, отказ на ссылках,
создание приватного каталога, сохранение состояния при остановке и очистка
после успеха. Работающие терминальные сессии не изменялись.
