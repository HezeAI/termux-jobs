# Частная v1.7.54-x11-test / code1269

## Изменение

Существующая диагностика сессий получает необязательную вкладку X11.
Обычный/Подробный находятся слева под Сводкой, X11 справа; во вкладке X11
переключатели журнала отключены. Нижние кнопки сохранены, отчёт включает X11.
Обычные окружения, включая ещё не подключённые, имеют раздел поддержки.
Агенты и ubuntu-ai исключены. Размер окна не менялся.

Сведения включают выбранный/фактический рендерер, готовность службы/подключения,
последний этап, возраст снимка, относительные времена этапов и категории ошибок.
Отсчёт начинается перед подготовкой X11 и фиксируется при готовности рабочего
стола или завершении; длительность последующей работы не прибавляется к запуску.
Предыдущий запуск сохраняется только в пределах жизни той же службы, не на диске.
После перезапуска приложения отсутствие снимка явно сообщается.

## Проверки

- 12 JVM-тестов: новые UI/области применения/отсутствие запуска службы,
  категории и границы буфера, исключение сырого личного текста,
  относительные времена/остановка отсчёта, существующая диагностика и GPU UI.
- 28 Python-тестов X11 integration/desktop/GPU прошли.
- bash -n x11-session.sh, git diff --check пройдены.
- Проверены пути: существующий/отсутствующий канал, неподключённое окружение,
  агент/Ubuntu AI, переход X11 → Сводка, свежий снимок перед Download,
  недоступная служба и сохранение последнего снимка после отключения.
- Release-сборка успешна. Финальный аудит: ZIP без ошибок/повторов, non-debuggable,
  com.termux, minSdk26, arm64-v8a, подпись APK v2 и прежний сертификат.
  JNI-контракты/определения runtime и соответствие включённых файлов исходникам
  проверены. Известные приватные маркеры отсутствуют. Остались унаследованные
  предупреждения Kotlin/vendor; чистый Lint не заявляется.

В отчёт не добавляется сырой stderr: используются ограниченные категории и
служебные этапы, без путей, имён файлов пользователя, текста полей, focus-токенов.
Существующий поток запуска обрабатывается без отдельного фонового опроса.
По открытию X11 или экспорту вызывается только state уже подключённой службы.
Действия установки, выбора GPU, остановки процессов и авторизации не менялись.
Существующие настройки и данные сохраняются, сброс/миграция не требуются.
Пакет/сертификат прежние, versionCode увеличен1268 →1269.

## Пробелы и следующая проверка

Чёрный экран Ubuntu GPU пока не исправлен и причина не подтверждена.
На устройстве требуется проверить раскладку кнопок, затем воспроизвести запуск
Ubuntu с GPU на этой сборке и сохранить Диагностика сессии → X11 → В Download
до остановки стола. Старые запуски не получают временные метки задним числом.
Mock UI не доказывает Android-отрисовку, касания или работу окон рабочего стола.
GitHub-публикация не выполнялась.
