# 2.1.5-test14 /1509 — карта и проверка

## Изменения

1. Вложенность: у каждой раскрытой записи своя линия. Группы «Проект» и
«Управление чатом», «Окружение» и «Управление сессией» не требуют раскрытия.
Обработчики получают прежний профиль; базовая Termux не имеет настроек сессии.
Остановка и DesktopStopAction не реализуются повторно; их код не изменён.
Пункт остановки X11 расположен сразу после открытия и обновляется по состоянию.
Сохранены проверки других владельцев, ожидания, ошибок и подтверждения остановки.
Доступность инструкций проекта остаётся прежней: Codex/Claude. Для Gemini/OpenCode
новая реализация инструкций этим обновлением не добавляется.

2. Меню «+»:20sp вместо24sp,24dp вместо36dp для значка,
59dp вместо88dp минимальной высоты,12dp вместо18dp отступов.
Ширина по подписи, максимум300dp и доступная ширина окна.
Сохранены ScrollView, ограничение доступной высоты и последовательная анимация.

3. Масштаб содержимого бокового меню0.8 через отдельный Context с уменьшенной
плотностью ресурсов. Глобальные ресурсы Activity не меняются.
Нет scaleX/scaleY или отдельного преобразования координат касаний.
Ширина панели определяется статическими подписями, значками и вложенными
отступами плюс небольшой запас справа. Верхний предел80% окна.
Имена чатов и пути исключены из расчёта; используются END/MIDDLE многоточия.
Шрифт для длинных имён не уменьшается. Индикатор прокрутки скрыт.
