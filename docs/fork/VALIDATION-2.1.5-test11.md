## Что установлено по снимкам и коду1505

Первый снимок: вывод ниже кнопок. Второй: строки проходят под ними. Пользователь
прямо подтвердил, что второй снимок сделан после жеста. В1505 `onDraw` включал
верхний transcript только при mTopRow<0. При обычном поступлении строк и follow
mTopRow==0, поэтому эта область оставалась пустой даже после накопления истории.

Это не margin, снимаемый первым касанием: inset сохранялся, менялась ветка paint.
Теперь число доступных строк сверху определяется transcript/visible top и измеренной
высотой header. При первом переполнении они появляются построчно и без жеста.
Основной render сохраняет прежнее начало/размер живой области и резерв composer.
Непрозрачной полосы не добавлялось. TerminalRenderer получил совместимый overload
для скрытия только off-viewport cursor; модель видимости курсора эмулятора не меняется.
Прежние вызовы renderer сохраняют обычное поведение.
