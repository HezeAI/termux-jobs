## Изменение и ревью

x11-desktop.sh передаёт фиксированный target дочерней графической сессии.
x11-session.sh выбирает --compositor=off только для ubuntu:turnip, иначе on.
Сохранённые XML/xfconf не редактируются. Новых процессов завершения, сигналов,
изменений библиотек/установленных окружений/агентских сессий нет.
Графические приложения сохраняют GPU-переменные при выключенном композиторе;
отключение касается объединения окон XFWM, а не выбора Mesa для приложений.
Новый безопасный marker on/off собирается существующим ограниченным журналом.
Данные и настройки сохраняются; сброс/миграция не требуются. Package/cert прежние,
versionCode1269 →1270. GitHub-публикация не выполняется.

## Проверки

Исполняемый shell fixture запускает реальный x11-session.sh с подставными
командами и проверяет аргументы XFWM для UbuntuGPU/off, UbuntuCPU/on,
TermuxGPU/on, DebianCPU/on и AlpineCPU/on. Отдельный JVM-тест проверяет
сохранение маркера композитинга без добавления сырого приватного вывода.
30 Python-тестов и 6 JVM-тестов прошли. bash -n и git diff --check пройдены.
Release-сборка успешна. Финальный архив без ошибок/повторов; package com.termux,
arm64-v8a, minSdk26, non-debuggable, подпись v2/сертификат проверены.
Проверены JNI/runtime-контракты и соответствие assets/изменённых классов исходникам.
Известные приватные маркеры отсутствуют; это не исчерпывающая проверка любых личных
строк. Сохраняются унаследованные Kotlin/vendor-предупреждения; чистый Lint не заявлен.

## Проверка на устройстве

Установить поверх, остановить прежний стол Ubuntu и запустить с Turnip+Zink.
Проверить видимость изображения; сохранить диагностику X11 до остановки.
Ожидаемый marker: JOBS_X11_COMPOSITOR=off. Если изображение появилось,
проверить glmark2 в терминале XFCE, затем CPU с marker on.
Shell/JVM-проверки не доказывают устранения чёрного экрана, работу жестов
или производительность настоящего рабочего стола.
