# Частная v1.7.73-x11-test / code1288

Повторное открытие рекомендуемых и установленных X11-программ использует
кэш выбранного окружения; главное меню не запускает каталог автоматически.
Ручная проверка обходит кэш, установка/удаление помечают прежние данные
устаревшими даже при частичном сбое. Кэш заменяется, без таймера/накопления.
Объём загрузки выводится после оставшегося времени в той же строке, только
при наличии измеренных байтов; счётчики файлов не превращаются в мегабайты.

В журнале openSUSE найден отказ доступа к mozilla-openh264 с сервера кодеков.
Программы устанавливаются с временным представлением репозиториев, в котором
исключён только codecs.opensuse.org/openh264. Системные .repo не меняются,
подписи/зависимости проверяются. Это не добавляет сам кодек OpenH264; покрытие
форматов зависит от штатных декодеров. Dry-run Parole/LibreOffice успешен;
реальную установку и запуск нужно проверить в новой сборке.

Пакет/сертификат прежние, code1287→1288; пользовательские данные не сбрасываются.
Рабочие столы, GPU/композитор, агенты и остановка процессов не менялись.
Импорт своего Turnip и преобразование драйверов в эту сборку не входят.
Публикации на GitHub нет.

## Проверки

Доказательства: `.verification/x11-program-cache/`. Read-only чтение журнала
openSUSE обнаружило HTTP/Curl отказ на mozilla-openh264; остальные скачивания
в показанном фрагменте успешны. Изолированный native Zypper использовал копии
rpmdb, метаданных, логов и временные пути внутри репозитория. Dry-run групп
media и office завершился кодом0; пакеты в окружение не устанавливались.
Системные определения репозиториев не изменены. Опция --reposd-dir описана
в [официальной документации Zypper](https://manpages.opensuse.org/Leap-16.0/zypper/zypper.8.en.html).

Новые проверки: повторная навигация и ручное обновление для каждого target;
сохранение статусов между экземплярами сервиса, разделение окружений,
инвалидация при неудачной установке; некорректный/неполный кэш и симлинки;
строка ETA/объёма и отсутствие неизвестных/недопустимых измерений;
временная фильтрация точного официального домена, сохранение GPG, исходных
файлов и очистка при ошибке. Завершение/отмена фоновых процессов не менялись.

Логически прослежены открытие главного меню/разделов, повторный вход,
первый вход без кэша, ручная проверка, установка/удаление с ошибкой,
проверка target/job и отсутствие автоматического цикла повторных сканирований.
Новый кэш хранит только фиксированные boolean-статусы программ, не команды,
проекты или авторизацию. Имена из .repo не исполняются через shell; точный
URL отбирается через urlsplit. Временные конфиги остаются внутри гостя и
удаляются context manager при штатном выходе/ошибке; принудительное SIGKILL
может оставить временную папку в /tmp, пользовательские .repo не заменяются.

Остаётся проверка разработчиком: повторное открытие списков на телефоне,
реальная установка и запуск Parole/LibreOffice в openSUSE, измеряемый объём
загрузки там, где пакетный менеджер передаёт байты. Dry-run и UI-тесты
не доказывают эти сценарии на устройстве.
