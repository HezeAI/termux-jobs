# Проверка v1.7.93-x11-test / code1308

Частная сборка заменяет прежний стиль на Retro XP под существующей галочкой
«Стиль Termux-job’s», только для базового Termux XFCE. Синие рамки, светлые окна,
свой фон/цветные базовые значки, увеличенные размеры. Описание ресурсов,
ограничений и восстановления: [X11-STYLE.md](X11-STYLE.md).

Дополнительно общая кнопка «Сервер + Агент» получила оформление chip, как
«Программы»: min-height34dp, wrap-content по высоте, прежнюю ширину106dp,
прежний запас112dp для соседних действий. При увеличенном системном шрифте
высота может увеличиваться ради текста. WorkspaceTransferBorder и updateTransferBorder
не меняются; LayerDrawable сохраняет бегущую линию загрузки/скачивания.
Применяется через общий renderTabs ко всем сессиям; остальные кнопки не изменены.

## Границы и совместимость

- Настройка/IPC/клавиатура/процессы/драйверы X11 и native-библиотеки прежние.
  Галочка по умолчанию выключена. Ubuntu/Ubuntu AI и другие гости тему не
  применяют; запрос для них отклоняется на существующей границе service.
- При включённом прежнем стиле известные ресурсы обновляются. Первая резервная
  запись остаётся: выключение возвращает первоначальные свойства, сохраняя
  отличающиеся ручные изменения. Порядок плагинов Menu также восстанавливается,
  включая повторное включённое применение. Чужие файлы не перезаписываются.
- Нет новых пакетов/загрузок темы. Исходные рамки/значки создаются Cairo,
  фон — встроенный image_gen, файл/промпт сохранены в design/x11-retro-xp/.
  GTK Adwaita используется из встроенного ресурса. Это не Windows и не полный
  набор иконок всех приложений. Верхняя панель с остальными плагинами сохраняется.
- Предел чтения собственного файла/архива расширен до8MiB, суммарной распаковки
  до16MiB для фотофона;192 записи, pinned SHA256, запрет ссылок/обхода путей и
  атомарные записи сохранены.
- com.termux и сертификат прежние; code1307→1308. Схема данных не меняется,
  никакого сброса данных нет. Необязательная команда подключения из v1.7.92
  сохранена; личная настройка туннеля не включена в APK. Возврат внешнего вида
  проверен в изолированных фикстурах, реальный Android update не выполнялся.

## Выполненные проверки

- 36 Python: Style15, SessionPolicy/GpuTools/Bookmarks21. В том числе off без
  записи, включение/выключение, чистый default.xml собственного PREFIX, большие
  панели/Menu, сохранение ID и порядка при повторных запусках, восстановление,
  upgrade ресурсов старого стиля с сохранением первого оригинала, изменённые
  пользователем свойства, ссылки/битый XML, чужие ресурсы, повтор после сбоя
  записи и повреждённый архив. PNG/XPM загружены настоящей GdkPixbuf без стола,
  Xcursor — настоящей libXcursor. Первоначальный тест повторного Menu выявил
  потерю applied-идентификаторов; исправлено, все36 повторно прошли.
- 49 JVM: WorkspaceDesktopStyle4, DesktopSessionBar2, Navigation1,
  X11Integration33, AgentConnection6, AgentConnectionUi3. Галочка, busy/guest
  границы, прежний запуск, paint-only border/lifecycle, одинаковая минимальная
  высота/отступы chip и сохранение LayerDrawable, старые размеры ширины/margin,
  поле подключения сессий/пресетов и отсутствие прямого fallback.
- GTK3 CSS разобран реальной библиотекой Termux после gtk_init_check с заведомо
  отсутствующим DISPLAY: cssParsed=true. Были ожидаемые headless GDK warnings
  из-за отсутствия screen. Это проверка синтаксиса/ресурса, не визуальный тест;
  пользовательский X11-сервер/стол не запускался и не останавливался.
- Ревью/логическая инспекция: старая галочка → свой новый D-Bus-сеанс → pinned
  архив → свои файлы/XML → XFCE; upgrade/повтор/ошибка/возврат. Перенос Menu
  затрагивает только массивы существующих plugin IDs. Способ остановки и
  рабочие сессии не меняются. Для server chip изменена только презентация,
  callbacks передачи и расписание анимации прежние.
- Release build, ZIP CRC, package/version, ABI/minSDK, подпись/v2, исходники
  staging и JNI-дескрипторы прошли.13552 DEX definitions,31 прежний reviewed
  unresolved type. Все native побайтно совпали с v1.7.92; в assets изменены
  только x11-style.py и x11-style.zip. Нет личных SSH-конфигов/ключей/адреса
  Selectel и проверяемых маркеров приватных токенов/ключей.

## Осталось проверить на телефоне

Остановить Termux XFCE, оставить/включить прежнюю галочку, запустить. Проверить
фон, Menu снизу, размер значков и панели, Thunar, рамки и курсоры, обе ориентации.
Выключить стиль и проверить возврат прежнего оформления. Проверить реальную
чистую установку и собственные Qt/GTK2/браузерные окна отдельно.

«Сервер + Агент»: сравнить высоту с «Программы», длинный текст/масштаб шрифта,
переходы между агентами и столом; начать передачу и проверить бегущую линию.
GUI и устройство не считаются проверенными на основании JVM/парсинга CSS.
