# v1.1.1 — выборочный бэкап (локальная проверка)

**Пока не опубликован.** APK передаётся пользователю в Download; публикация и
update.json на GitHub — после проверки. Предыдущий публичный выпуск — v1.1.0.

Через шестерёнку → Резервное копирование · бета → Создать резервную копию можно
выбрать полную копию или **выбранные данные**. Termux и каждая найденная Ubuntu
раскрываются отдельно: Codex с авторизацией/настройками/историей и найденной CLI,
другие AI-агенты, SSH/Git, оболочка и скрипты, проекты, инструменты/кеши/результаты
сборок, остальные пользовательские файлы, система и установленные зависимости.
Можно добавить подпапку HOME вручную. Показывается размер до сжатия; известные
каталоги инструментов и сборок отделены от исходников проектов.

Перед созданием — состав, предупреждения о системе/Node.js, история без проектов,
возможность добавить систему и зависимости либо оставить данные без них. Команды
установки не выполняются. SQLite Codex копируется online-backup с quick_check по
каждой базе; WAL/SHM, IPC, блокировки и временные shell snapshots не переносятся.
Это не атомарная копия всех данных приложения и не восстановление процесса.

При проверке архива повторно проверяются окружения и наличие файлов Node.js/Git/SSH на
принимающем телефоне. Это не проверка версии Node.js, входа или запуска CLI.
Выборочная Ubuntu с системой становится отдельной Ubuntu под новым alias через
штатный restore proot-distro. Без системы данные извлекаются отдельно; активация
в готовом окружении остаётся ручной. Выборочные данные Termux также не заменяют
работающий HOME/PREFIX. Бэкап содержит секреты и не шифруется.

## Совместимость

- com.termux, прежняя подпись, versionCode1058; обновление поверх v1.1.0/code1057.
- Очистка команд, заметок, пресетов, истории и рабочих окружений не требуется.
  Библиотека приложения остаётся v8; миграции пользовательских данных нет.
- Полные архивы сохраняют manifest v1. **Выборочные используют manifest v2:**
  для их импорта обновите принимающее приложение до v1.1.1 или используйте
  доверенный restore.sh из всего каталога бэкапа. Старые версии их отвергают.
- Архивы v1 и поддерживаемые чужие TAR по-прежнему читаются. Авторизация может
  потребовать повторного входа; внешние ссылки, Android Keystore и процессы
  не переносятся. Установка APK может остановить процессы — завершите задачи.
- Подготовленные update.json/SHA256SUMS должны быть опубликованы вместе с этим
  APK после одобрения пользователем. Сейчас адреса будущего релиза ещё не работают.
