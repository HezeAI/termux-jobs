# Termux Job’s — первый публичный выпуск · Beta

Неофициальный форк Termux с новым удобным интерфейсом и пресетами команд и сессий.

- **Пресеты команд:** названия, категории, избранное, копирование и вставка в выбранный терминал.
- **Сохранённые сессии:** рабочий каталог, до трёх команд запуска и выбор среды Termux или Ubuntu.
- **Последовательный запуск:** ожидание готовности Bash, остановка при ошибке и отмена оставшихся шагов.
- **Несколько терминалов:** переключение вкладками и закрытие с подтверждением.
- **Журнал последних 25 команд:** поиск, повторная вставка и сохранение в библиотеку.

Основан на [Termux v0.118.3](https://github.com/termux/termux-app/tree/v0.118.3).
Лицензия GPLv3 only с сохранением лицензий компонентов. Неофициальный проект HezeAI.

**Совместимость:** ARM64, Android 7+. Ubuntu, Codex и другие инструменты
устанавливаются отдельно. Для Ubuntu нужен proot-distro с контейнером `ubuntu`.
Следующие шаги ждут завершения интерактивной программы, а не отправляются в её чат.

Устанавливается поверх наших прежних сборок с сохранением данных.
Установка поверх обычного Termux с другой подписью не поддерживается;
параллельная установка с ним также не поддерживается (пакет `com.termux`).
Перед заменой другого Termux сделайте резервную копию его данных.
После записи хранилища v4 не откатывайтесь на версии форка 0.9 и ниже.
