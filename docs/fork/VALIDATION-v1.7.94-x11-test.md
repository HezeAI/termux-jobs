# Проверка v1.7.94-x11-test / code1309

Исправление opt-in стиля Retro XP для базового Termux после двух скриншотов
разработчика: v1.7.93 работал, но нижняя рамка была полосатой, кнопки имели
квадратную подложку и в Menu оставалась мышь XFCE.

## Изменения

- applicationsmenu получает button-icon=termux-jobs-menu; собственный цветной
  знак >_ включён в набор значков. Содержание меню, custom-menu-file,
  параметры категорий/иконок и действия не меняются.
- Нижний тайл рамки теперь1×6: не содержит чередующихся столбцов, повторение
  по ширине даёт непрерывную линию. Боковые тайлы6×1 постоянны по вертикали.
  Угловые элементы нарисованы отдельно; размер бокового resize handle6px сохранён.
- Кнопки имеют прозрачные углы и скруглённое основание, без квадратного холста.
  menu-active/inactive/prelight/pressed в заголовке прозрачны: штатный значок
  приложения показывается без дополнительной квадратной подложки.
- Обновлены только scripts/prepare-x11-style.py, x11-style.py, пакуемый ZIP и
  versionCode/versionName. Фотофон, шрифты/размеры, оформление Android, серверная
  анимация, программы/данные, другие гости и подключение агента не меняются.

## Проверки и инспекция

-38 Python: предыдущие36 и два новых сценария. Проверены отсутствие полос
  на повторяемых краях, прозрачные углы контролов и основание значка приложения;
  назначение значка Menu, отсутствие изменений пользовательского меню,
  возврат предыдущего значка после выключения. Все XPM/PNG загружены реальной
  GdkPixbuf, курсоры — libXcursor. Сохранены проверки old-style upgrade,
  повторного старта, ID плагинов/Menu, первой резервной записи, выключения,
  чужих ресурсов, ссылок, повреждённых конфигов и ошибок записи.
- Реальная GTK3 Termux в headless-процессе нашла termux-jobs-menu для56px
  через новый index.theme. Стол/пользовательские сессии не перезапускались.
- PNG нового значка и кнопки close визуально просмотрены. Это не проверка
  живой рамки XFWM, focus/hover/pressed и изменения размера на телефоне.
- Ревью/логическая инспекция: штатное свойство button-icon→своя тема значков;
  original/applied включают его для корректного возврата. Меняется только
  видимый значок, не конфигурация меню. Файлы обновляются прежним проверяемым
  механизмом известных хешей; начало/остановка процессов не меняются.
- Release build, ZIP CRC, подпись/v2, package/version/minSDK/ABI, staged sources
  и JNI-дескрипторы прошли.13552 DEX definitions,31 прежний reviewed unresolved
  type, множество definitions совпадает с v1.7.93. Native побайтно прежние;
  в assets изменены только x11-style.py и x11-style.zip. Новых приватных
  ключей/токенов/сетевой конфигурации в APK нет. DEX целиком не идентичен:
  versionName/versionCode намеренно увеличены.

Схема данных прежняя, без очистки. Сертификат и com.termux сохранены,
code1308→1309. Оформление обновится только при следующем запуске стола Termux
с прежней включённой галочкой; уже работающий стол не меняется. При выключении
восстанавливаются первоначальные свойства, отличающиеся ручные правки сохраняются.

На телефоне требуется проверить Menu, рамку окна при разных размерах,
все состояния кнопок close/minimize/maximize и значок приложения, затем
выключение темы. Установку и фактическую GUI-проверку этой версии выполняет
разработчик. После её проверки тема может быть отдельно адаптирована для
остальных XFCE-гостей; эта сборка их не переключает.
