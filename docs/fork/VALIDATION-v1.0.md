## Ревью и логическая инспекция

Локализация применяется только к явным строкам приложения, не к пользовательским данным/выводу терминала. Протокольные маркеры меню Codex остаются английскими; роли, SSH, права и остановка процессов не менялись. Язык применяется к ресурсам без recreate терминальной Activity, без Locale.setDefault и изменений окружения shell. Выбор хранится в приватных preferences; текущие процессы не останавливались. Контроллер перерисовывает подписи, сохраняя объект ввода и черновики. При следующем запуске Activity получает выбранный locale-context. Незакрываемая базовая сессия и история Codex из v0.2.18–20 сохранены.

## Минимальная проверка на телефоне

1. Установить поверх текущего APK. Проверить глобус рядом с шестерёнкой на Главной, Команды/Заметки и Терминале; плитки прежнего размера, иконки по центру.
2. English: главная, фильтры/редакторы команд и заметок, новая сессия (обычная/SSH/Codex), файловый браузер и меню папок, стандартные настройки. Проверить длинные надписи и прокрутку на текущем DPI/с клавиатурой.
3. Карточка Codex: модель → reasoning → confirmation, лимиты/статусы. Названия моделей не переводятся. Проверить обычное управление действующей сессией.
4. Набрать многострочный черновик, сменить язык и вернуться на RU; текст/курсор и другие вкладки должны сохраниться. Живой shell/Codex не должен перезапускаться.
5. При следующем запуске приложения проверить сохранённый выбор языка и библиотеку. System на русском/другом языке — русский/английский соответственно.
