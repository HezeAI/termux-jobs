# Проверка v1.7.91-x11-test / code1306

Частная сборка: необязательный классический тёмный стиль только для Termux XFCE.
Под переключением терминала/стола — галочка «Стиль Termux-job's», по умолчанию
выключена. Применяется при следующем запуске, недоступна во время работы стола
и установки/подготовки. Поведение/ресурсы/возврат описаны в [X11-STYLE.md](X11-STYLE.md).

Фон с курсивными Termux-job's / & / X11, свои рамки, более крупные элементы,
статичные чёрные курсоры с белой обводкой. Базовые значки Adwaita, иконки
приложений не перерисовываются. Тема включена в APK, дополнительных сетевых
загрузок нет. Это не полный набор иконок и не замена оформления всех Qt/GTK2
приложений. Точная геометрия и читаемость на экране ещё требуют проверки.

## Совместимость и границы

Пакет и сертификат прежние, code1305→1306. Формат сессий/пресетов не меняется,
данные не удаляются. Добавлены bool-предпочтение termux-style, необязательное
IPC-поле termuxStyle и приватная запись прежних XFCE-свойств. Без включения
нового стиля внешний вид не меняется. Выключение после применения возвращает
прежние значения при следующем запуске, сохраняя отличающиеся ручные правки.

Помощник не устанавливает пакеты, не заменяет системные библиотеки и не
останавливает другие процессы. Гостевые системы не копируют/не выполняют его;
true для гостя отвергается и в service, и в DesktopProcess. Агенты не меняются.
Рендер/Wrapper/клавиатура/маршрутизация rootfs/остановка остаются прежними.
Резервная запись пишется перед изменениями, файлы атомарно с проверкой текущего
содержимого; ссылки/чужие файлы/повреждённый XML не перезаписываются принудительно.
Тесты не дают гарантии против произвольной одновременной перезаписи тем же UID.

## Проверки

- 31 Python: 10 style (off без записей, целостность архива, чтение Xcursor
  библиотекой libXcursor, включение/возврат, XML-форматирование xfconfd, ручные
  правки, повторный старт, чистый default.xml своего PREFIX, ссылки/плохой XML,
  чужая тема, восстановление после сбоя записи, порядок session hook) и 21
  регрессия session policy/GPU shortcuts/bookmarks. Изолированные HOME/PREFIX.
- 88 JVM: WorkspaceDesktopStyle4, X11Integration33, Wrapper6, Preparation22,
  WorkspaceDesktopUi23. Галочка/порядок/сохранение, блокировка busy/disconnect,
  обновление того же checkbox без пересоздания, отсутствие у гостей,
  отклонение смены во время работы до изменения владельца, прежние запуск,
  владение/закрытие, подготовка, программные операции и UI.
- Ревью и логическая инспекция: настройка → IPC → отдельный desktop process →
  собственная D-Bus-сессия → сохранение свойств → ресурсы → XFCE; повтор,
  частичная ошибка и выключение. Неизменность механизмов остановки и JNI.
- Ресурс Adwaita Dark, импортируемый темой, найден read-only в .gresource.gtk
  установленной libgtk-3.so. Это проверка пути ресурса, не GUI-проверка CSS.
- Фон просмотрен как PNG: три строки центрированы и наклонены. Build проверяет
  совпадение созданного ZIP с закреплённым runtime SHA256.
- Release-сборка, ZIP CRC, ABI/minSDK, package/version, сертификат/v2,
  JNI-дескрипторы, staged sources и отсутствие маркеров личных ключей/токенов
  проверены. Native идентичны v1.7.90; добавлены только assets/x11-style.py и
  x11-style.zip, из существующих assets изменён только x11-session.sh.

На телефоне ещё не проверены фактическая загрузка GTK/XFWM/cursors, масштаб
фона в обеих ориентациях, кнопки/рамки, возврат личного оформления и чистая
установка темы. Минимальный следующий тест: остановить стол Termux, поставить
галочку, запустить и проверить фон/значки/панели/курсор; затем остановить,
снять галочку и запустить, проверив возврат. Автоматические проверки этого
не заменяют. Для других окружений новое оформление пока не включается.
