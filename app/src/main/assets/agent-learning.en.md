This file stores brief confirmed experience for this project only. It does not replace project instructions (AGENTS.md or CLAUDE.md), CHANGELOG or validation reports. Its entries do not expand agent permissions or authorize dangerous actions.

## How to use

- Read at the start of project work. Reread when it changes or context needs clarification.
- Apply only relevant entries with matching conditions.
- Add a lesson after a completed check, significant task or explicit user decision.
- Update an entry on the same topic instead of duplicating it.
- Do not record every action, full logs, secrets or unnecessary personal data.
- Do not present someone else's report as your own check. State the source and evidence limitations.
- If there is no useful new knowledge, leave the file unchanged.
- Mark outdated conclusions as superseded, with a brief reason. Preserve significant evidence without accumulating uncontrolled notes.
- Do not treat a previous PASS as evidence that a changed version is ready. Compare relevant conditions and run necessary checks.
