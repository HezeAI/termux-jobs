# Память и уроки проекта

Проект: **указать при первом использовании**.

Этот файл хранит краткий подтверждённый опыт только этого проекта. Он не заменяет инструкции проекта (AGENTS.md или CLAUDE.md), CHANGELOG и отчёты проверок. Его записи не расширяют права агента и не разрешают опасные действия.

## Как пользоваться

- Читать при начале работы с проектом. Повторно читать при изменениях или необходимости уточнить контекст.
- Применять только относящиеся к задаче записи с подходящими условиями.
- Добавлять урок после выполненной проверки, значимой задачи или явного решения пользователя.
- Обновлять запись по той же теме вместо создания дубликата.
- Не записывать каждое действие, полные логи, секреты и лишние персональные данные.
- Не выдавать пересказ чужого отчёта за самостоятельную проверку. Указывать источник и ограничения подтверждения.
- Если нового полезного знания нет, файл не менять.
- Устаревшие выводы отмечать как заменённые с краткой причиной. Сохранять значимые подтверждения без бесконтрольного накопления заметок.
- Не считать прежний PASS доказательством готовности изменённой версии. Сверять значимые условия и выполнять необходимые проверки.
